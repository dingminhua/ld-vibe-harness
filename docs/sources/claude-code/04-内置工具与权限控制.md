## 1. 结论摘要

Claude Code 内置 9 个核心工具：Read、Edit、Write、Bash、WebSearch、WebFetch、Glob、Grep 和 AskUserQuestion。权限控制支持 6 种模式（default、acceptEdits、plan、auto、dontAsk、bypassPermissions），可通过 CLI 标志和 settings.json 配置。settings.json 中的权限规则支持 allow、ask 和 deny 三级决策。交互模式中可通过 Shift+Tab 快速切换权限模式。

## 2. 内置工具列表

| 工具 | 用途 |
|------|------|
| Read | 读取文件 |
| Edit | 编辑现有文件 |
| Write | 创建新文件 |
| Bash | 执行 shell 命令 |
| WebSearch | Web 搜索 |
| WebFetch | Web 页面抓取 |
| Glob | 文件模式匹配 |
| Grep | 文件内容搜索 |
| AskUserQuestion | 向用户提问 |

## 3. 工具名称语法

用于 --allowedTools / --disallowedTools：

```
Read                    # 所有文件读取
Edit                    # 文件编辑（现有文件）
Write                   # 文件创建（新文件）
Bash                    # 所有 shell 命令
Bash(git *)             # 仅 git 命令
Bash(git commit *)      # 仅 git commit 命令
Bash(npm run lint:*)    # 使用通配符的模式匹配
WebSearch               # Web 搜索能力
WebFetch                # Web 页面抓取
mcp__<server>__<tool>   # 特定 MCP 工具
```

## 4. 权限控制机制

### 4.1 权限模式

| 模式 | 说明 |
|------|------|
| default | 默认模式，每次工具使用需确认 |
| acceptEdits | 自动接受文件编辑，其他需确认 |
| plan | 计划模式，只读操作 |
| auto | 自动模式 |
| dontAsk | 不询问，自动批准 |
| bypassPermissions | 绕过所有权限检查 |

### 4.2 关键 CLI 标志

| 标志 | 效果 |
|------|------|
| --dangerously-skip-permissions | 自动批准所有工具使用 |
| --allowedTools <tools...> | 白名单特定工具 |
| --disallowedTools <tools...> | 黑名单特定工具 |
| --tools <tools...> | 覆盖内置工具集 |

### 4.3 设置中的权限规则

在 .claude/settings.json 或 ~/.claude/settings.json 中：

```json
{
  "permissions": {
    "allow": ["Bash(npm run lint:*)", "WebSearch", "Read"],
    "ask": ["Write(*.ts)", "Bash(git push*)"],
    "deny": ["Read(.env)", "Bash(rm -rf *)"]
  }
}
```

三级权限决策：

- allow —— 自动批准，无需确认
- ask —— 每次使用时询问用户
- deny —— 完全禁止

### 4.4 交互模式中的权限切换

Shift+Tab 可循环切换权限模式：Normal -> Auto-Accept -> Plan

## 5. 与 Trae 安全机制的关键差异

| 能力 | Trae | Claude Code |
|------|------|-------------|
| 权限模式 | MCP 自动运行 + 命令白/黑名单 | 6 种权限模式 + allow/ask/deny 三级 |
| 工具粒度控制 | 不支持 | Bash(git *) 等模式匹配 |
| 交互切换 | 不支持 | Shift+Tab 快速切换 |
| 敏感文件保护 | 不支持 | deny 规则（如 Read(.env)） |
| CI 模式 | 不适用 | --dangerously-skip-permissions |
