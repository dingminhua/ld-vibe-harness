## 1. 定位

本文承载 06 授权的非 Codex 自助适配核对表。

## 2. 核对表

| 核对项 | 标准 |
|---|---|
| 持久入口 | 用户或维护者自行确认该环境是否存在规则、instructions、AGENTS、项目说明、配置、Hook、Skill、Command 或等价入口 |
| 薄引用 | 入口只放薄引用，不复制 LDVH 正文 |
| 入口目标 | 指向工作区入口或维护入口的真实路径，或该环境可稳定读取的等价位置 |
| 无持久入口 | 只能使用会话提示、项目 README、临时步骤或显式待确认 |
| 机制分流 | Hook、Skill、Command、自动运行和权限机制分别验证，不互相冒充 |
| 事实源边界 | 自助适配结果只说明当前用户当前环境观察结论，不写成 LDVH 官方支持声明 |
| 经验沉淀 | 自助适配经验需先形成 ADR、Spark、Pitfall 或 specs 变更，并经过 Human Gate |
