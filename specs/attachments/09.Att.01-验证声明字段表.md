字段表:

| 字段 | 要求 |
|---|---|
| 验证目标 | 说明本次验证覆盖的变更、规则或风险 |
| 验证方式 | 自动化测试、命令校验、等价验证、Human 验收或回归验证 |
| 验证入口 | 命令、测试文件、页面、API、AI 回读核对步骤、手动命令步骤或 Human 确认记录 |
| 输入范围 | 说明样例、事实源路径、对象范围、版本或环境范围 |
| 关键输出 | 说明退出状态、关键摘要、失败前表现、通过条件或 Human 观察 |
| 结论 | 通过、失败、未运行、部分覆盖或等价验证 |
| 残留风险 | 未覆盖范围、无法自动化原因、环境限制或后续补齐位置 |
| 证据回指 | 回指命令输出、测试入口、事实源、截图说明、Human 记录或提交记录 |

完整条件:

| 条件 | 内容 |
|---|---|
| 目标匹配 | 验证目标与本次变更范围匹配 |
| 入口可复现 | 验证入口可复现 |
| 输入明确 | 输入范围明确 |
| 输出明确 | 关键输出或通过条件明确 |
| 风险记录 | 未覆盖范围已经写入残留风险 |
| 证据回指 | 证据能回指命令、测试、事实源或 Human 记录 |

禁止写法:

| 写法 | 边界 |
|---|---|
| 只列命令 | 不作为验证声明 |
| 未运行测试但暗示已验证 | 不作为验证声明 |
| 局部测试通过写成完整验证 | 不作为完整验证 |
| 工具无报错写成 Human 已确认 | 不作为 Human 验收 |
| 看起来正确 | 不作为验证结论 |
