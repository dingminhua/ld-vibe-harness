## 1. 定位

本文承载 07 授权的 commit scope 推荐值。

07 正文定义 scope 最多一个、表达主承载域的规则；本文只维护推荐表，不得定义 commit type 闭集、body 必填条件、对象字段、Web 页面契约或提交流程。

## 3. 使用规则

`scope` 可选，最多一个，表示名词性的主承载域或最重要的事实源边界。scope 不是文件清单，不要求覆盖所有 touched files。一次提交可以跨多个目录完成同一闭环，但首行只选择主 scope；其它受影响范围、配套实现和文档同步写入 body。

没有合适推荐值时，可以基于项目语义选择一个简短、稳定、名词性的扩展值。扩展 scope 不得创造新的工作对象类别，不得使用斜杠、逗号或多个词拼接规避主承载域取舍。LDVH 自身反复出现的新 scope，应回补到本文推荐值和 Web 展示标签。

## 4. 辅助核对表

| 核对项 | 标准 |
|---|---|
| 单主承载 | scope 最多一个 |
| 名词稳定 | scope 是稳定名词，不是动作或文件清单 |
| 不拼接 | 未使用 `web/code`、`specs,code` 或多词拼接 |
| 不造对象 | 扩展 scope 没有新增事实模型对象类别 |
| body 补充 | 其它影响范围写入 body，而不是塞进 scope |
