## 一、本文定位

本文定义多角色思考行动模型在 Tools 辅助层的适配内容。Tools 辅助层可以为多角色思考提供确定性的读取、解析、校验、聚合、上下文包生成和回写候选检查能力。

本文不定义具体脚本、命令、API 或代码实现。具体实现应进入 `tools/`，并遵守 `specs/05.01-Tools辅助规范.md`。

---

## 二、允许能力

多角色思考 Tools 适配可包含以下能力：

1. 读取 41 主文件和 41.01-41.05 实践子文档；
2. 读取用户指定的相关事实源；
3. 生成多角色思考 Context 包；
4. 校验报告是否包含必要章节；
5. 校验角色数量和角色字段是否完整；
6. 检查 Agent 增强模式是否声明前提；
7. 检查输出是否区分过程分析和稳定事实；
8. 检查回写候选是否有明确目标事实源；
9. 检查是否需要 Change 记录。

---

## 三、禁止能力

Tools 适配不得允许以下行为：

1. 自行决定角色结论；
2. 直接调用 AI、Skill 或 Agent；
3. 自动将报告写入稳定事实源；
4. 绕过 Human Gate 写入 specs、Rules、Skill、Agent 或对象实例；
5. 将缓存、索引或派生数据作为权威事实；
6. 在校验失败时自动覆盖原始文件；
7. 将早期 Skill 输出直接升级为 LDVH 事实。

---

## 四、Context 包结构

多角色思考 Context 包建议包含：

| 字段 | 含义 |
|---|---|
| `topic` | 分析主题 |
| `trigger` | 触发原因 |
| `mode_candidate` | 候选模式：light / skill / agent |
| `source_files` | 输入事实源文件列表 |
| `rules` | 适用规范规则来源 |
| `action_model` | 41 主文件和实践子文档来源 |
| `agent_prerequisite` | Agent 前提状态 |
| `role_candidates` | 候选角色列表 |
| `gate_candidates` | 可能触发的 Gate |
| `writeback_candidates` | 可能回写的目标事实源 |

Context 包是派生数据，不是最终事实源。若 Context 包中的新信息需要长期保留，应重新判断对象类型和事实源位置。

---

## 五、报告结构校验

Tools 可检查多角色思考报告是否包含：

1. 适用性判断；
2. 分析模式；
3. Agent 前提；
4. 变更或问题概述；
5. 各角色分析；
6. 角色间一致与分歧；
7. 风险汇总；
8. 建议执行顺序；
9. 事实源回写建议；
10. Human Gate 判断。

校验失败时，只报告缺失项，不自动修改报告。

---

## 六、角色字段校验

每个角色分析至少应包含：

1. 角色名；
2. 适用性；
3. 影响范围；
4. 分析结论；
5. 风险等级；
6. 建议动作。

角色数量超过 8 个时，Tools 可提示需要精简或合并，但不得自行删除角色。

---

## 七、Agent 前提校验

当报告声明使用 Agent 增强模式时，Tools 应检查：

1. 是否声明相关 Trae 预制 Agent 已安装或可调用；
2. 是否列出参与 Agent 类型；
3. 是否说明 Agent 输入来源；
4. 是否说明 Agent 输出返回主控汇总；
5. 是否声明 Agent 输出不是最终事实源；
6. 是否说明未满足前提时的降级方式。

若报告未声明前提，不得通过 Agent 增强模式校验。

---

## 八、回写候选检查

Tools 可检查回写候选是否满足：

1. 回写类型明确；
2. 目标事实源明确；
3. 目标位置符合 03 和对应对象规范；
4. 是否触发 Human Gate 已说明；
5. 是否需要 Change 记录已说明；
6. 过程分析未被标记为稳定事实。

Tools 不得自动执行高影响写入。

---

## 九、Human Gate

以下情况必须提示 Human Gate：

1. Tools 准备写入或覆盖 Git 文件事实源；
2. Tools 建议将过程分析升级为 ADR、规范规则、规范或长期行动边界；
3. Tools 发现报告要求 Agent 增强但前提不满足；
4. Tools 发现 Skill 调度 Agent；
5. Tools 发现输出将缓存或派生数据当作事实源。

---

## 十、检查要求

| 检查项 | 标准 |
|---|---|
| 来源 | 输入来自 Git 文件事实源或用户当前输入 |
| 派生边界 | Context 包和校验结果不作为最终事实源 |
| 报告结构 | 必要章节完整 |
| 角色字段 | 每个角色字段完整 |
| Agent 前提 | Agent 增强模式声明前提或降级 |
| 回写候选 | 目标事实源和 Gate 判断明确 |
| AI 边界 | Tools 未调用 AI、Skill 或 Agent |
| 写入边界 | 未绕过 Human Gate 自动写入 |
