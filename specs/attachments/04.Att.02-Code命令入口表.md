## 2. 入口表

| 命令 | 当前用途 | 读写属性 | v2 边界 |
|---|---|---|---|
| `python3 code/bootstrap_code.py` | Code Python 依赖自举 | 环境安装 | 安装 Code 和 Code 测试所需的最小 Python 依赖 `PyYAML`、`pytest`；不安装 Web 依赖，不依赖 editable install，不声明环境完整支持 LDVH |
| `python3 code/specs_validate.py all` | active specs 综合校验 | 只读诊断 | 当前默认读取 active `specs/` |
| `python3 code/specs_validate.py v2-check` | active specs 结构诊断和只读知识地图预览 | 只读诊断 | 当前默认读取 active `specs/`；不替代完整运行时知识地图能力 |
| `python3 code/specs_validate.py knowledge-map` | 知识地图只读投影查询 | 只读投影 | 复用 `v2-check` 输入范围、层级、项目范围和来源回指；只输出知识地图投影本体，不写入缓存或事实源 |
| `python3 code/specs_validate.py v2-check --input-scope runtime_extensions` | 固定运行时扩展自描述只读投影 | 只读诊断 | 显式读取固定运行时扩展 `ldvh_asset`；不作为默认范围，不写入缓存，不决定 Rules 正文如何修改 |
| `python3 code/specs_validate.py deployment-entries` | 固定运行时扩展登记一致性检查 | 只读诊断 | 检查固定登记表与资产自描述一致性；不表示环境已安装 |
| `python3 code/specs_validate.py capability-environment` | 固定能力资产与环境保障矩阵 | 只读诊断 | 汇总固定资产来源、同步责任、验证链和环境落地边界；不写入环境入口，不声明环境已安装 |
| `python3 code/specs_validate.py knowledge-map --input-scope governed_projects` | 管辖项目事实对象知识地图投影 | 只读投影 | 读取 `LDVH-GOVERNED-PROJECTS.yaml` 和登记项目 `ldvh-base/`；节点带项目命名空间，不修改项目清单或事实对象 |
| `python3 code/specs_validate.py preflight --target-path <path>` | 受控写入前检查 | 只读诊断 | 不授权写入，不执行写入，不替代 Human Gate 或 Git 追溯 |
| `python3 code/specs_validate.py governed-projects` | 管辖项目配置检查 | 只读诊断 | 不修改 `LDVH-GOVERNED-PROJECTS.yaml` |
| `python3 code/commit_validate.py --check-message...` | commit message 预检 | 只读诊断 | 不创建 commit，不替代 Human Gate |
| `python3 code/hook_dispatch.py run git.commit-msg` | Hook 统一 dispatcher 入口 | 只读/阻断型诊断 | 不替代 Git commit records 或 CI |
