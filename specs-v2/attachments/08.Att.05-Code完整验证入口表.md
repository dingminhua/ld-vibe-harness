## 1. 定位

本文承载 08 授权的 LDVH Code 当前完整验证入口。

## 2. 入口表

| 入口 | 当前性质 | 最低要求 |
|---|---|---|
| `npm run test:code` | Code 日常完整测试入口 | 同时运行 `tests/code` 自动化测试和 `python3 code/specs_validate.py all --fail-on-diagnostics` |
| `npm run test:code:unit` | Code 快速单元测试入口 | 只覆盖 `tests/code` 时，验证声明必须说明未覆盖综合入口的风险 |
| `python3 code/specs_validate.py all --fail-on-diagnostics` | active specs 综合检查入口 | 迁移期仍以当前 active `specs/` 为默认事实源 |
| `python3 code/specs_validate.py v2-check --fail-on-diagnostics --format text` | v2 写作区只读迁移诊断入口 | 不替代 active specs 综合检查，不声明 v2 已 active |
| `git diff --check` | 空白和补丁格式检查 | 只能证明 diff 格式无空白错误，不能替代业务测试 |

## 3. 降级规则

只运行局部入口时，应在验证声明中说明未运行完整入口的原因、影响范围和残留风险。Code 关键 CLI、诊断 Schema、目录假设、写入行为或下游消费合同变化时，不得只用 smoke test 作为完整验证。
