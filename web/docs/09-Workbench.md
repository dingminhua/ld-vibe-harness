# Workbench 工作台

> 路由：`/workbench`
> 源码：`web/src/pages/Workbench.tsx`
> API：`GET /api/dashboard`

## 1. 页面目标

工作台是实验视图，用于把事实对象组织为任务、关系、证据和动作，提供人机协同执行指挥入口。它不替代仪表盘，也不作为默认首页。

## 2. 当前页面结构

```text
实验视图标签
页面标题：LDVH 工作台
返回仪表盘按钮
指标网格：任务总数 / 待推进 / 近期变更 / 校验
主面板：
  任务案卷
  关联对象
追踪链路
```

## 3. 指标网格

- 使用 `ldvh-metric-grid` 和 `MetricCard`。
- 四项指标：
  - 任务总数；
  - 待推进；
  - 近期变更；
  - 校验状态。
- 校验状态通过时使用绿色 tone，失败时使用红色 tone。

## 4. 任务案卷

- 默认选择第一个待推进 Task；没有待推进 Task 时回退到最近 Task。
- 顶部显示 `StatusBadge`。
- 主任务卡片点击跳转到 `/objects/task/{id}`。
- 主任务卡片右上提供复制完整路径图标，复制该 Task 的 YAML 文件路径；点击图标不得触发跳转。
- 内部包含三块信息：
  - 验收：当前为工作流信号占位，不读取真实 acceptance 明细；
  - 证据：展示最近变更前三条；
  - 动作：添加证据、关联任务、发起审查，当前均为 disabled 占位。

## 5. 关联对象

- 展示与当前任务不同的最近对象线索，最多 5 条。
- 每条包含类型标签、状态、标题和 ID。
- 点击条目打开右侧扩展阅读区，不离开工作台。
- 每条右侧提供复制完整路径图标，复制该对象的 YAML 文件路径；点击图标不得触发扩展阅读。

## 6. 追踪链路

- 展示固定四步：意图 → 任务 → 变更 → 证据。
- 该区是工作流提示，不是可编辑流程图。

## 7. 交互

| 操作 | 行为 |
|---|---|
| 点击返回仪表盘 | 跳转到 `/` |
| 点击任务案卷主卡片 | 跳转到 Task 详情页 |
| 点击关联对象 | 打开右侧扩展阅读区 |
| 点击复制路径图标 | 复制对象 YAML 文件完整路径，不改变当前页面 |
| 点击动作占位按钮 | 无操作，保持 disabled |

## 8. 实现约束

1. 不把工作台改成新首页；顶部必须保留“实验视图 · 不替换主页”的语义。
2. 不让占位动作产生写入副作用，除非已有后端受控写入合同。
3. 不把关联对象改成页面跳转列表；当前交互是右侧扩展阅读。
4. 不在工作台内复制对象详情页完整字段；详细阅读交给对象详情页和右侧扩展区。
5. 任务案卷主卡片和关联对象卡片必须保留复制完整路径入口。
