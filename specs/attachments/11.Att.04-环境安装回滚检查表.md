> 文件状态：active；本文只承载 11 授权的安装回滚检查项。

| 检查项 | 要求 | 证据入口 |
|---|---|---|
| `target_scope` | 明确安装影响的 repo、worktree、受管项目或外部环境范围 | install/status 命令输出 |
| `trigger_point` | 明确自动触发事件和失败处理方式 | Hook 或 adapter 文档 |
| `payload_contract` | 明确 payload 字段、缺字段处理和兼容边界 | 11.Att.03、测试 |
| `status_check` | 可重复检查安装状态、路径和是否由 V3 管理 | status 命令 |
| `rollback` | 可卸载或恢复原状态，且不会覆盖未知用户资产 | uninstall 或回滚步骤 |
| `verification` | 安装、失败阻断、成功路径和回滚均有验证命令 | tests 或手动验证记录 |
