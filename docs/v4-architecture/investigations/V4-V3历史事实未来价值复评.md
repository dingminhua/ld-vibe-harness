# V4 V3 历史事实未来价值复评

> 记录性质：本文重新评估 V3 的 92 个历史事实单元是否对 LDVH **未来**具有净价值；它不是 Human 决定、V4 事实创建授权或实施顺序。
> 评估日期：2026-07-19
> 当前状态：已完成来源级建议；尚未创建 V4 事实。每个“Spark 候选主题”仍须由 Human 决定是否建立。

## 1. 判断标准

每个来源只按以下四问判断，不按 Web 是否即将开启、旧对象是否关闭或 V4 是否存在字面相似实现判断：

1. 它能否为 LDVH 未来增加需要的能力、降低可预见风险、提供不可替代的决策依据或复用经验？
2. 当前 V4 是否已经以足够方式承接该未来价值？部分承接只能收窄问题，不能自动排除剩余价值。
3. 未承接部分能否收敛为一个边界清楚的 Spark；只有 Human 已确认目标、范围和成功标准时才考虑 WorkCase。
4. 收益是否大于恢复 V3 旧架构、兼容层、状态机或无目标建设的成本？

“Spark 候选”只说明值得保留为当前待判断议题，不表示已经获准实施。实施顺序（包括 V4 Web 只读观察）在 Human 选择后单独安排，不参与价值判断。

## 6. 覆盖性与下一步

本复评覆盖 V3 的全部 92 个来源单元：49 个进入 9 个 Spark 候选主题，20 个已由 V4 承接，14 个仅保留 archive，9 个已经失去未来净价值。

下一步不是同时创建 9 个 Spark，而是按候选主题逐个向 Human 说明净价值、最小范围、非目标、依赖与实施顺序；只有 Human 明确选择的主题才通过当前 V4 受控创建边界建立 Spark。
