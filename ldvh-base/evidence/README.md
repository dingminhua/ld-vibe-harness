# Evidence 实例目录

本目录存放 Evidence（验证证据）事实模型实例。

## 文件命名规则

```text
ev-{NNNN}-short-title.yaml
```

- 编号从 `0001` 起递增，固定 4 位
- 英文短标题使用小写短横线命名
- 每个项目独立编号

## 准入条件

当一个验证结果满足以下条件之一时，应考虑形成 Evidence：

1. 有关联的 Task 或 ADR
2. 有可追溯的验证来源（命令输出、截图、测试报告等）
3. 有明确的验证结论
