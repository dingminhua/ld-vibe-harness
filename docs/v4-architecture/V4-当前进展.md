## 3. 已实现并验证的 Code 范围

`code/ldvh/` 当前包括：

- Git worktree 内规范候选发现，含 ignore、Working Tree、符号链接和路径边界；
- Markdown/YAML 固定结构读取；
- 根规范、普通规范和授权附件的身份与结构检查；
- 规范依据、结构归属、附件授权、替代关系和影响范围检查；
- L0–L2 派生信息及来源位置回指；
- `Helper 公开操作` 声明候选读取与契约引用检查；
- 诊断对象和不完整范围表达。
- `ldvh` 进程入口、共同 JSON 请求与响应、退出码和基础诊断；
- `capabilities` 与 `call` 的基础分流，不由 Code 或 tests 补造领域公开操作；
- 从实际导入包路径定位共置 LDVH Working Tree 规则源，不从 `cwd`、隐藏环境变量、缓存或 `HEAD` 猜测。
