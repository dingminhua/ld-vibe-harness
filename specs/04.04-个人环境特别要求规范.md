# 个人环境特别要求规范

> 创建日期：2026-06-13
> 定位：定义个人或当前执行环境的特殊约束如何影响环境入口部署和适配检查
> 适用范围：个人环境特别要求、当前执行环境约束、Human 明确授权的临时执行场景
> 上位依据：`specs/04-规范落地与环境适配基础规范.md`、`specs/04.03-环境入口适配与部署规范.md`、`specs/02-术语规范.md`
> 相关规范：`specs/07-Code确定性执行实现规范.md`、`specs/09-事实源边界与承载规范.md`

本文定义个人环境特别要求的字段、查询方式、适用边界和治理规则。本文不定义 LDVH 能力资产，不定义环境入口适配方案，不记录长期安装、启用或验证状态。

---

## 1. 本文解决的问题

本文解决个人或维护者环境中的特殊约定如何约束 04.03 的部署和适配检查。

个人环境特别要求不是 LDVH 通用规范，也不自动进入所有管辖项目。具体个人环境状态不写入 specs；当前执行是否受限，应通过当前环境证据、Human 当前指令、项目 README、依赖管理说明或可查询记录判断。

---

## 2. 与 04.03 的关系

04.03 定义标准环境入口适配、部署和适配检查方法。本文定义在个人或当前执行环境中，哪些特殊约束会限制 04.03 的执行。

| 项目 | 04.03 环境入口适配与部署规范 | 本文个人环境特别要求 |
|---|---|---|
| 来源 | 环境官方资料、输入证据、当前环境证据、Human Gate | 当前个人或维护者环境约定 |
| 作用 | 定义如何接入、部署、适配检查 LDVH 能力资产 | 限制当前执行命令、路径、权限和写入方式 |
| 范围 | 环境类型和当前部署动作 | 当前个人、维护者、工作区或 Human 授权场景 |
| 是否通用 | 可作为环境类型部署方案 | 不得自动提升为通用规则 |
| 冲突处理 | 按 Human Gate 和适配检查处理 | Human 当前指令、项目 README 和依赖说明优先 |

---

## 3. 个人环境要求字段

个人环境要求实例不得写入 specs 正文。可查询记录至少应包含：

| 字段 | 必填 | 含义 |
|---|---|---|
| 编号 | 是 | 个人环境要求的稳定标识 |
| 要求 | 是 | 要求名称 |
| 内容 | 是 | 当前执行环境需要遵守的具体约束 |
| 适用范围 | 是 | 个人、维护者、当前工作区、当前环境或 Human 授权场景 |
| 默认效力 | 是 | 启用、禁用或条件启用 |
| 影响动作 | 是 | 影响部署、写入、适配检查、命令执行或 Human Gate |
| 适用位置 | 是 | 环境入口、命令入口、Code 使用说明、人工提醒或其它消费位置 |
| 风险控制 | 是 | 防止个人要求被提升为 LDVH 通用规则的约束 |
| 退出条件 | 是 | 何时取消、替换或迁移该要求 |

---

## 4. 查询与使用规则

AI 执行 04.03 的部署或适配检查前，应查询 Human 当前指令、当前项目 README、依赖管理说明、当前工作区配置、已授权的个人环境要求记录、当前环境证据和命令可用性。

未查询到可验证记录时，不得假定某个人要求启用。若 Human 当前指令与个人环境记录冲突，以 Human 当前指令优先。

---

## 5. 约束类型

| 类型 | 示例 | 对 04.03 的影响 |
|---|---|---|
| 写入约束 | 不允许自动写 IDE 配置目录 | 部署步骤必须 Human Gate 或降级为手动说明 |
| 路径约束 | 某目录不可访问或必须使用特定路径 | 适配检查需使用当前可访问路径 |
| 命令约束 | 必须使用 `python3`、`uv`、`poetry` 或特定虚拟环境 | Code 检查和部署命令需按约束执行 |
| 权限约束 | 不允许跨工作区写入 | 环境入口部署不得越界 |
| 网络约束 | 不允许联网或访问外部服务 | sources 查询或安装步骤需降级 |
| 安全约束 | 不允许写入密钥、Hook 或自动触发配置 | 相关部署必须暂停或降级 |

---

## 6. Human Gate 与检查要求

以下情况必须评估 Human Gate：

1. 将个人环境要求提升为 LDVH 通用规则；
2. 改变个人环境要求实例的默认效力或适用范围；
3. 允许个人环境约定覆盖项目自身依赖管理或命令约定；
4. 新增会影响写入位置、权限、密钥、网络、环境长期配置的个人要求；
5. 个人环境要求与 04.03 标准部署步骤冲突；
6. 删除仍被部署、适配检查、Code 或人工提醒消费的要求。

检查个人环境特别要求时，应确认：

| 检查项 | 标准 |
|---|---|
| 适用范围 | 已明确为当前个人、维护者或当前执行环境 |
| 默认效力 | 已明确启用、禁用或条件启用 |
| 项目优先 | 项目 README、依赖说明和 Human 当前指令优先 |
| 部署约束 | 已说明如何约束 04.03 的部署和适配检查 |
| 非通用化 | 未写成 LDVH 通用跨环境规则 |
| 退出条件 | 已说明何时更新、删除或迁移 |

## 7. 规范落地要求

| 落地要求 | 要求内容 | 保障机制 | 同步类型 | 触发条件 |
|---|---|---|---|---|
| 上位约束承接要求 | 个人环境特别要求必须约束当前执行但不得反向修改 04.02 或 04.03 | 本文、04.03、Human Gate | 个人环境治理 | 个人约束字段或适用边界变化时 |
| 入口可见要求 | AI 执行部署或适配检查前应能查询个人环境特别要求 | Rules 资产、人工提醒、当前环境证据 | AI 执行入口提示 | 个人环境要求影响部署或检查时 |
| 确定性执行要求 | 受个人环境影响的命令调用应可通过实际命令或等价验证确认 | 命令验证、Code、人工检查 | 命令验证 | 工具入口、解释器、依赖管理变化时 |
| Human 交互要求 | 将个人要求通用化、覆盖项目约定或影响长期配置前应暂停确认 | Human Gate、对话确认 | 个人环境治理确认 | 个人要求影响范围扩大时 |

## 8. 待补齐事项
