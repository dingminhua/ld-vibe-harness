## 1. 定位

本文承载 04 授权的 Code 诊断字段和等级。

## 2. 诊断字段

| 字段 | 含义 |
|---|---|
| `severity` | `error`、`warning` 或 `info` |
| `code` | 稳定诊断码 |
| `message` | 人类可读诊断说明 |
| `source_refs` | 来源路径、章节、对象、字段或 commit 回指 |
| `suggested_owner` | 建议归口；无法判断时可为空，但必须通过问题原因说明暴露 |

## 3. 使用规则

诊断只暴露缺口、冲突、漂移、问题原因和建议回写方向，不直接关闭问题，不替代 Human Gate。`--fail-on-diagnostics` 的失败边界由具体命令实现和测试确认。

## 4. 当前稳定诊断码

| 诊断码 | 命令或范围 | 等级 | 含义 |
|---|---|---|---|
| `PREFLIGHT_RULES_ASSET_IMPACT_REVIEW_REQUIRED` | `preflight` | `info` | 写入 specs 或运行时扩展承载物前，应评估固定 Rules 资产同步影响；该诊断不授权写入、不决定 Rules 正文如何修改 |
| `PREFLIGHT_RULES_ENTRY_SYNC_REVIEW_REQUIRED` | `preflight` | `info` | 写入 specs、附件或行动成员前，可能需要参考 planned 30 执行 Rules 入口同步审查；该诊断不授权自动修改 Rules，也不表示 30 已 active 接管 |
| `PREFLIGHT_FIELD_PATH_OWNER_IDENTIFIED` | `preflight` | `info` | preflight 已识别字段路径归口、来源规范或附件；该诊断不校验业务取舍、不授权写入 |
| `CAPABILITY_ENVIRONMENT_SOURCE_SPEC_MISSING` | `capability-environment` | `error` | 固定能力资产 `source_specs` 引用的来源规范不存在，无法形成同步责任链 |
| `CAPABILITY_ENVIRONMENT_SYNC_TRIGGER_MISSING` | `capability-environment` | `error` | 固定能力资产缺少同步触发，无法判断 specs 或环境变化后的同步责任 |
| `CAPABILITY_ENVIRONMENT_VERIFICATION_MISSING` | `capability-environment` | `error` | 固定能力资产缺少验证入口，无法形成可复查保障链 |
| `CAPABILITY_ENVIRONMENT_DEPLOYMENT_ENTRY_VERIFICATION_MISSING` | `capability-environment` | `warning` | 固定能力资产验证链未包含 `deployment-entries`，登记一致性未进入自身验证链 |
| `V2_GOVERNED_PROJECTS_CONFIG_MISSING` | `knowledge-map` / `v2-check` | `warning` | 需要管辖项目输入范围时未找到 `LDVH-GOVERNED-PROJECTS.yaml` |
| `V2_GOVERNED_PROJECTS_CONFIG_INVALID` | `knowledge-map` / `v2-check` | `warning` | 管辖项目配置无法解析或结构不符合最小要求 |
| `V2_GOVERNED_PROJECT_NOT_FOUND` | `knowledge-map` / `v2-check` | `warning` | `explicit_projects` 指定的项目 ID 不在管辖项目配置中 |
| `V2_GOVERNED_PROJECT_LDVH_BASE_MISSING` | `knowledge-map` / `v2-check` | `warning` | 已登记项目缺少 `ldvh-base/`，无法抽取事实对象关系 |
| `V2_PROJECT_FACT_GRAPH_LOAD_FAILED` | `knowledge-map` / `v2-check` | `warning` | 管辖项目事实对象文件无法解析为图谱节点 |
| `V2_PROJECT_FACT_GRAPH_TARGET_NOT_FOUND` | `knowledge-map` / `v2-check` | `warning` | 事实对象关系字段引用的对象或路径目标不存在 |
| `V2_PROJECT_PATH_OUT_OF_SCOPE` | `knowledge-map` / `v2-check` | `warning` | 事实对象关系字段引用项目根目录外路径，投影拒绝越界读取 |
| `V2_ATTACHMENT_BROAD_NAME_FORBIDDEN` | `v2-check` | `error` | 附件名称使用“附录”“补充说明”“综合表”“治理清单”等宽泛名称，可能把多个对象包装成隐性主规范 |
