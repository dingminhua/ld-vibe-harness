## 1. 定位

本文承载 06 授权的环境适配字段表。

## 2. 字段表

| 字段 | 必填 | 含义 |
|---|---|---|
| 环境类型 | 是 | 适用的 AI 开发环境类型 |
| 环境入口 | 是 | 环境实际读取、加载、调用、触发、配置、展示或执行某类能力的位置或机制 |
| 对应 LDVH 承载物 | 是 | Rules、Skill、Agent、Hook 或其它运行时扩展承载物 |
| 接入方式 | 是 | 薄引用、配置、安装、软链、受控复制、临时核对动作等 |
| 部署步骤 | 是 | AI 如何帮助用户接入该承载物 |
| 写入权限 | 是 | 是否允许 AI 代写，是否需要 Human Gate |
| 适配检查 | 是 | 如何现场判断接入已生效 |
| 成功条件 | 是 | 满足什么才能声明本次接入有效 |
| 失败处理 | 是 | 缺入口、无权限、不可读、环境不支持时如何处理 |
| 适配问题分流 | 是 | 缺少环境入口或环境能力不足时如何模拟、手动处理或登记缺口 |
| 禁止声明 | 是 | 哪些情况下不得声明完整支持、资产已部署或环境能力已覆盖 |
| 证据输出 | 是 | 应呈现给 Human 的证据 |
| 证据状态 | 是 | 已验证、待验证、仅参考、待补齐或不适用 |
