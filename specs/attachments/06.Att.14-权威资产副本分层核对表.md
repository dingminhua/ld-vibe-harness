## 1. 定位

本文承载 06 授权的权威资产与部署副本分层核对表。

## 2. 核对表

| 核对项 | 标准 |
|---|---|
| 权威路径 | 权威资产以 LDVH 仓库中的登记文件为准 |
| 部署副本 | 运行环境中的同名文件、配置片段、薄入口、软链、安装副本或 Hook 配置属于部署或适配层 |
| 不独立演化 | 环境内复制件不得长期独立演化 |
| 薄接入优先 | 环境入口优先使用薄引用、软链、安装脚本或可复查配置指向权威资产 |
| 受控复制 | 必须复制全文时，记录复制原因、来源版本、更新方式、退出方式和漂移检查方法 |
| 现场观察 | 环境接入结果只说明当前现场观察，不写成完整支持 |
| 问题分流 | 部署副本问题先判断是权威资产问题、环境适配问题还是本地配置问题 |
| 不反向改变 | 安装脚本、Hook 示例、环境配置模板和用户本地入口不得反向改变权威资产字段契约或来源规范 |
