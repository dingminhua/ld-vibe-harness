## 1. 定位

本文承载 02 授权的事实模型成员身份字段表和成员字段闭集辅助说明。

02 正文定义事实模型成员主文件的权威边界、成员身份原则、集合状态闭集、事实源边界和 Human Gate；本文只能维护成员身份字段的详细说明和字段闭集辅助信息，不得单独定义事实模型准入、集合状态原则、对象状态机、字段契约原则、事实源规则、成员骨架模板、Human Gate 或 Code 输出 Schema。

## 2. `v2_fact_model_member` 字段表

`v2_fact_model_member` 字段契约如下：

| 字段 | 出现要求 | 含义 |
|---|---|---|
| `spec_id` | 必须出现 | 两位成员编号，必须与文件名和 `v2_spec.spec_id` 一致 |
| `kind` | 必须出现 | 固定为 `fact_model` |
| `name_en` | 必须出现 | 英文名，必须与文件名英文段一致 |
| `name_zh` | 必须出现 | 中文名，必须与文件名中文段一致 |
| `collection_status` | 必须出现 | 集合状态，必须使用 02 正文定义的闭集；本文 §3 只提供字段级辅助说明 |
| `canonical_path` | 必须出现 | 成员主文件路径，必须与真实路径一致 |
| `instance_root` | 条件必填 | 默认事实实例目录；无实例目录或使用 Markdown、外部事实源等例外承载方式时必须说明 |
| `instance_carrier` | 必须出现 | 实例承载方式，必须使用 02 正文定义的闭集；本文 §3 只提供字段级辅助说明 |
| `fact_source_anchor` | 必须出现 | 事实源边界章节锚点 |
| `schema_anchor` | 必须出现 | 字段契约章节锚点 |
| `state_machine_anchor` | 必须出现 | 状态机章节锚点；不适用时指向说明不适用的章节 |
| `human_gate_anchor` | 必须出现 | Human Gate 章节锚点 |
| `code_consumption` | 必须出现 | Code 应读取的字段、章节、锚点或检查入口 |
| `supersedes` / `superseded_by` | 可选 | 重命名、迁移、废弃或替代后的追溯关系 |

## 3. 成员字段闭集

以下闭集从 02 正文承接。若本文与 02 正文冲突，以 02 正文为准；本文不得单独增删或改变集合状态和实例承载方式含义。

| 字段 | 允许值 | 含义 |
|---|---|---|
| `collection_status` | `active` | 已是当前 active 事实模型集合成员；v2 未切换前必须能回指 active v1 成员主文件 |
| `collection_status` | `candidate` | 候选事实模型；不得进入 active 实例入口、默认 Dashboard、CLI 新建入口或 Web 新建入口 |
| `collection_status` | `reserved` | 编号预留；不得被解释为已存在事实模型 |
| `collection_status` | `removed` | 已移除或清退；不得作为新写入入口 |
| `instance_carrier` | `yaml` | 事实实例以 YAML 文件或 YAML frontmatter 为主要结构化承载 |
| `instance_carrier` | `markdown` | 事实实例以 Markdown frontmatter 和正文承载 |
| `instance_carrier` | `external` | 使用外部事实源；成员主文件必须说明原因、位置和同步边界 |
| `instance_carrier` | `none` | 无事实实例目录；必须说明为什么不产生实例 |
