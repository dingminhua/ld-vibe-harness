## 1. 定位

本文承载 08 授权的 LDVH Web 当前回归入口和优先级。

## 2. 回归入口表

| 对象 | 回归入口 | 优先级 |
|---|---|---|
| Web API contract | `tests/web/api/` 或等价 API contract 检查 | 最高 |
| 高风险 API | `POST /api/sparks`、ProjectFiles、Validate、Objects 对应测试或等价验证 | 最高 |
| Web 暂停实施期间的回归线 | DTO、Spark 创建白名单、WorkCase orchestration 展示、提交记录展示、Confirm UI 边界、派生态势原因语义、测试/构建/API contract 入口 | 最高 |
| 页面空态、错误态、降级态、只读边界、来源呈现 | 页面测试、组件测试、人工降级检查 | 中 |
| Confirm UI、受控轻写入白名单 | API、组件和人工确认边界检查 | 高 |
| i18n、图标语义、Human-facing 文案 | 页面检查、截图说明或人工降级检查 | 中 |
| E2E、视觉回归、复杂浏览器流程 | Playwright 或等价浏览器流程 | 后置 |

## 3. 边界

Web v2 暂不实施时，也必须保留 DTO、API contract 或人工降级检查的回归线。Web 回归线不得反向定义事实模型、Code 输出、行动编排流程或事实源边界。
