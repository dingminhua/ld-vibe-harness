# Intent 实例目录

本目录存放 Intent（意图）事实模型实例。

## 文件命名规则

```text
intent-{NNNN}-short-title.yaml
```

- 编号从 `0001` 起递增，固定 4 位
- 英文短标题使用小写短横线命名
- 每个项目独立编号

## 准入条件

当一个意图满足以下条件之一时，应考虑形成 Intent：

1. 用户表达了明确目标，且目标尚未任务化或需要跨任务追踪
2. 影响范围超出单次操作，需要多个 Task 协同完成
3. 需要跨会话保持意图连续性
