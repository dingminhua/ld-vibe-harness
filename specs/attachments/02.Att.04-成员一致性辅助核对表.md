## 1. 定位

本文承载 02 授权的成员一致性辅助核对表。

02 正文定义事实模型成员主文件的权威边界、成员身份原则、集合状态原则、事实源边界和 Human Gate。本文只维护一致性核对项，不得单独定义成员身份字段闭集、成员骨架模板、v1-v2 双读映射、对象状态机、字段契约原则、事实源边界、Human Gate 或 Code 输出 Schema。

## 2. 成员一致性辅助核对表

成员一致性辅助核对至少包括：

| 核对项 | 标准 |
|---|---|
| 编号一致 | 文件名编号、一级标题、`v2_spec.spec_id` 和 `v2_fact_model_member.spec_id` 一致 |
| 路径一致 | `canonical_path` 与真实路径一致 |
| 类型一致 | `v2_spec.spec_kind=member_spec`，`v2_fact_model_member.kind=fact_model` |
| 状态分工 | `v2_spec.status` 不与 `collection_status` 混用 |
| active 回指 | active 成员能回指当前 active 成员主文件和必要历史来源 |
| 实例入口 | `instance_root` 和 `instance_carrier` 与事实源边界章节一致 |
| 锚点可达 | `fact_source_anchor`、`schema_anchor`、`state_machine_anchor` 和 `human_gate_anchor` 能回指真实章节 |
| 骨架完整 | `02.Att.03` 模板中的强制章节存在；不适用章节有说明 |
| 附件边界 | 字段契约、状态机、Human Gate 和事实源边界没有拆入未授权附件 |
| 派生边界 | Code、Web 和知识地图输出只作为导航、诊断或展示，不替代成员主文件 |

本核对表用于发现事实模型成员身份、路径、状态、锚点、骨架和派生边界缺口；核对结论不能替代 02 主文档规定的高影响确认。
