## 1. 结论摘要

SOLO 模式以 AI 为主导，自动规划并执行从需求理解到成果预览的全流程。支持网页版、桌面版、移动版三端形态，三端共享账号体系和任务数据实时同步。提供 Work（面向非开发人员）和 Code（面向开发工程师）双模式，以及云端智能体（Cloud Agent）统一运行时、Auto 模式智能调用模型等能力。

## 2. 官方定位

SOLO 模式以 AI 为主导，自动规划并执行从需求理解、代码生成、测试，到成果预览的全流程。用户可通过自然语言描述、语音交互或上传本地文件等方式输入需求，AI 自主拆解任务并高效执行。

## 3. 三端形态

### 3.1 网页版

- 有网络即可访问，随时随地启动任务
- 无需下载和安装，提供开箱即用的云端环境
- 任务管理简洁高效，轻量化交互不占用本地资源

### 3.2 桌面版

- 专为 AI Agent 设计的独立应用，不依赖 TRAE IDE 运行
- 支持文字、语音、附件、技能等多元输入
- 实时展示任务进度并自动总结输出内容
- 支持在对话界面内直接预览成果并完成验收
- 深度性能优化，Coding Agent 运行更稳定

### 3.3 移动版

- 默认支持"按住说话"功能，也支持文本、附件和快捷指令输入
- 统一管理云端和多台个人电脑中的 TRAE SOLO，支持并发派发任务
- 设备离线时自动切换至云端执行，确保任务不中断
- 任务状态在移动版、网页版和桌面版之间无缝同步

### 3.4 三端联动

三端共享同一套账号体系和任务数据，任务信息实时全量同步。移动版侧重任务下发，网页版和桌面版负责任务执行、深度交互和产物验收。

## 4. 双模式

| 模式 | 面向用户 | 适用场景 |
|---|---|---|
| Work 模式 | 非开发人员（产品经理、数据分析师、运营等） | 文档、数据、演示稿等 |
| Code 模式 | 开发工程师 | 编码、调试、代码库管理和 Git 工作流 |

## 5. 云端智能体（Cloud Agent）

云端智能体在云端环境中执行代码分析、运行和调试等任务，提供统一的运行时与依赖管理，避免本地环境差异带来的兼容性或性能问题。

## 6. Auto 模式

Auto 模式下，系统综合考虑问答速度、性能与资源占用情况，智能调用合适的模型，提供更流畅的 AI 问答体验。

## 7. 对话流节点自动折叠

启用后，已完成的任务将在对话框中被折叠并生成摘要，可展开查看细节。配置位置：设置 > 对话流 > 待办清单。

## 8. Diff 视图

项目变更完成后，可通过"查看变更"或"代码变更"按钮打开代码变更窗口，查看本次变更涉及的文件数量、代码行数及具体 diff。

## 9. 自定义模型

支持添加自定义模型，在 SOLO Agent 中使用。

## 10. SOLO 独立端与 IDE 版差异

- IDE 版 SOLO 模式：集成在 TRAE IDE 内，通过左上角模式切换按钮进入
- SOLO 独立端（桌面版/网页版/移动版）：独立应用，不依赖 TRAE IDE 运行，提供更完整的三端联动体验和云端智能体能力
