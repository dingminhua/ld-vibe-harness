## 1. 定位

本文拟作为所有 v2 规范的结构元规范。它先于术语和事实源规范，是因为知识地图依赖文档结构构件，所有规范都必须先具备稳定、可引用、可解析的文档结构。

本文拟回答：

1. 一篇 v2 规范如何声明文档身份、权威域和适用范围；
2. 一篇 v2 规范如何声明负责什么、不负责什么；
3. 文档之间如何引用、承接、消费和授权附件；
4. 附件、注册表、矩阵、模板和示例如何命名和受主规范约束；
5. Code 如何从文档结构抽取知识地图节点和边；
6. 事实模型、行动编排等专属文档结构如何由对应主规范继续细化。

## 2. 与 06 的分工

01 定义所有规范共同遵守的通用结构；06 定义事实模型类规范的专属结构。

具体分工候选如下：

| 问题 | 归口 |
|---|---|
| 文档身份、权威域、引用纪律、附件授权 | 01 |
| 文档结构如何被 Code 抽取为知识地图构件 | 01 |
| 事实模型是什么、字段契约如何定义 | 06 |
| 具体事实模型文档必须有哪些章节 | 06 |
| WorkCase、Spark、ADR 等具体对象字段 | 20-29 具体事实模型 |
