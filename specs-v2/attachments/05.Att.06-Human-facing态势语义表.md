## 1. 定位

本文承载 05 授权的 Human-facing 派生态势原因语义。

## 2. 态势语义表

| 态势 | 必须说明的原因 | 来源 |
|---|---|---|
| 等待前置 | 等待哪个对象或执行项关闭 | `blocked_by`、对象关系、后端聚合 |
| 待执行 | 没有未关闭前置但尚未开始 | 对象状态、执行姿态 |
| 验证中/待验证 | 等待什么验证入口或证据 | 08、WorkCase 字段、Code 输出 |
| 验证失败 | 哪个验证失败、失败摘要和回指 | 测试输出、Code 诊断、验证声明 |
| Human Gate | 需要 Human 判断什么 | Gate 触发原因、候选事项 |
| 风险 | 风险来源和影响范围 | Pitfall、WorkCase、诊断 |
| 降级 | 降级原因、不可证明范围 | Code/Web/运行时诊断 |
| 同步异常 | 哪个来源不可读或过期 | API、缓存、Git 文件、Code 输出 |

## 3. 使用规则

态势标签不得反向定义事实源状态机。同一事实源状态在不同原因下需要拆分时，应拆分为不同 Human-facing 态势；不得用“等待中”“处理中”“异常”等泛词覆盖原因。
