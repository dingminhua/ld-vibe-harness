## 1. 定位

本文承载 05 授权的 Web 能力删除核对表。

## 2. 删除前核对表

| 核对项 | 标准 |
|---|---|
| 依赖 | 没有行动编排、Rules、Skill、Agent、Hook、Code、Web 页面或用户路径继续依赖 |
| 替代入口 | 命令行、事实源、Web 替代页或人工降级路径明确 |
| 测试 | 对应测试已删除、搬移、改写或替换 |
| 文档 | `web/docs/`、README、specs 引用和页面说明已同步 |
| Human Gate | 影响确认、写入、验收或高影响判断时已暂停确认 |
| 回归线 | 不删除 05/08 要求保留的关键回归线，除非有替代验证 |
| 事实源边界 | 删除不改变事实源归口、对象字段或状态机 |

## 3. 使用规则

删除 Web 能力不是单纯代码清理。凡影响受控写入、Confirm UI、Human Gate、事实源同步、关键页面或行动编排依赖，必须回到 05 主体 Human Gate。
