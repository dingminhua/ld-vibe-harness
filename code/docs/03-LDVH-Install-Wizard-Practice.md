# LDVH Install Wizard Practice

本文是 Code 实现域文档，承接 `specs/30-LDVH安装初始化管辖项目配置行动模板.md` 的安装向导交互实践。本文不定义新的安装授权，不替代 Human Gate，不表示任何插件、Hook 或用户环境已经安装。

## 展示原则

安装向导是正常安装流程，不区分测试版和正式版。是否执行只在最终确认时由 Human 决定。

用户主流程使用普通词：

| 用词 | 用途 |
|---|---|
| 流程概览 | 展示完整步骤 |
| 安装前检查 | 只读检查当前状态 |
| 安装选项 | 收集需要 Human 决定的选项 |
| 安装方案预览 | 汇总检查结果、选择、后置项、验证和回滚 |
| 最终确认 | Human 选择执行、不执行或返回修改 |

避免把内部检查、环境接管状态等技术口径作为用户主标题。这些术语只应出现在技术细节、验证摘要或环境状态说明中。

## 状态表模板

每次展示向导时，先给流程状态表。当前步骤使用箭头，已经完成的步骤把决策或结果写进最后一列，尚未发生的步骤保持空白。

|  | 步骤 | 名称 | 决策 / 结果 |
|---|---|---|---|
| ➜ | 1/5 | 📋 流程概览 |  |
|  | 2/5 | 🔍 安装前检查 |  |
|  | 3/5 | 📝 安装选项 |  |
|  | 4/5 | 🔒 安装方案预览 |  |
|  | 5/5 | 🛠️ 最终确认 |  |

状态列不要写“待进行 / 待选择 / 待确认”。空白已经表示尚未发生。

## 信息分类

安装向导必须分开展示三类信息：

| 类型 | 来源 | 是否问 Human |
|---|---|---|
| 系统检查事实 | 只读检查、Code 输出、目录回读 | 不问 |
| 用户决策 | Human 需要取舍的安装选项 | 问 |
| 本次后置 | 当前不支持、未授权或需要单独 Gate 的事项 | 不作为主选项 |

示例：

| 内容 | 分类 | 表达 |
|---|---|---|
| `ldvh-base/` 已存在 | 系统检查事实 | 写入安装前检查结果，不再询问是否创建 |
| 配置文件放工作区根目录还是当前项目根目录 | 用户决策 | 放入安装选项 |
| 用户级配置目录 | 本次后置 | 说明当前 Code 不支持稳定解析，不放入主选项 |
| 用户环境插件安装 | 本次后置 | 说明需要单独 Human Gate |

## 选择表模板

需要 Human 选择时，每次只问一个问题。配置位置选项必须给出配置文件完整路径和建议。

| 选项 | 位置 | 配置文件完整路径 | 含义 | 限制 | 建议 |
|---|---|---|---|---|---|
| 1 | 工作区根目录 | `<workspace-root>/LDVH-GOVERNED-PROJECTS.yaml` | 一个工作区管理多个项目 | 配置不在当前项目根里 | 多项目管理时推荐 |
| 2 | 当前项目根目录 | `<project-root>/LDVH-GOVERNED-PROJECTS.yaml` | 当前项目单独管理 | 不适合多个项目共用 | 单项目或最小变更时推荐 |

如果当前界面支持选择框 / 单选控件，优先使用 UI 控件；不可用时使用等价编号二选一。

## 最终确认

最终确认前不得写入。安装方案预览必须列出：

1. 将写入或修改的文件；
2. 将不会执行的事项；
3. 本次后置项；
4. 验证命令和预期结果；
5. 回滚方式；
6. 残留风险。

最终确认至少提供三类选择：

| 选项 | 含义 | 结果 |
|---|---|---|
| 1 | 执行 | 按方案执行并验证 |
| 2 | 不执行 | 停止，不写入 |
| 3 | 返回修改 | 回到安装选项 |
