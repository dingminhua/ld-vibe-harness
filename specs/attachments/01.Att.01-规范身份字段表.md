# 规范身份字段表

```yaml
v3_attachment:
  attachment_id: "01.Att.01"
  title: "规范身份字段表"
  status: "candidate"
  authority: "candidate"
  canonical_path: "specs/attachments/01.Att.01-规范身份字段表.md"
  parent_spec: "specs/01-规范体系基础规范.md"
  relation: "identity_contract"
```

> 文件状态：candidate；本文只定义 `v3_spec` identity block 字段，不定义规范正文规则。

## 字段表

| 字段 | 必填 | 说明 | Code 消费 |
|---|---|---|---|
| `spec_id` | 是 | 稳定编号，例如 `00`、`01`、`03`、`31` | 节点 ID、排序、关系 |
| `spec_kind` | 是 | `spec`、`member_spec`、`attachment_spec` 等闭集 | 类型判断 |
| `title` | 是 | 规范标题，应与 H1 一致 | 展示和诊断 |
| `status` | 是 | `candidate`、`active`、`deprecated`、`archived` | 可用性判断 |
| `authority` | 是 | `candidate`、`active`、`deprecated`、`archived` | 权威判断 |
| `canonical_path` | 是 | 当前 Markdown 事实源路径 | source_refs |
| `parent_spec` | 否 | 直接父规范路径 | 父子关系 |
| `relation` | 否 | 与父规范的关系，例如 `refines`、`member_of` | 关系边 |
| `positioning` | 是 | 本规范定位 | Action Guide 摘要 |
| `scope` | 是 | 适用范围和排除范围 | 影响判断 |
| `basis` | 是 | 上位依据和来源回指 | P0/P1 read_plan |
| `related_specs` | 是 | 相关规范、附件或 schema | 关系和展开查询 |
| `code_consumption` | 是 | Code 可消费类别 | 检查和投影 |

## 状态规则

| 状态 | 含义 | Action Guide 行为 |
|---|---|---|
| `candidate` | 候选规范，尚未成为正式规则 | 可生成 limited guide，不可作为 active authority |
| `active` | 正式规范事实源 | 可生成 usable guide |
| `deprecated` | 已废弃或被替代 | 只可生成追溯 guide |
| `archived` | 归档历史 | 默认不进入行动导航 |

## 约束

1. `status` 与 `authority` 不得互相冲突；
2. `canonical_path` 必须指向当前 Markdown 文件；
3. `basis` 和 `related_specs` 不得用来制造第二事实源；
4. `code_consumption` 只能声明 Code 可消费类别，不授权 Code 改写规范。
