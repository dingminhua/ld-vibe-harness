## 一、本文定位

本文是 `specs/21-ADR-决策记录.md` 的附件型实践子文档（编号 21.01），承接 Rules 入口实践。本文不是独立事实模型，不得重新定义 ADR 的对象定位、准入条件、状态机、对象关系、Human Gate、字段契约、事实源回写或证据留存。发生冲突时，以 21 主文档和上位基础规范为准。

---

## 二、实践目标

让 AI 在可能需要读取 ADR、创建 ADR、编辑 `ldvh-base/adrs/` 下 YAML 文件或调用 ADR Tools 写入命令前，自动识别 ADR 读取入口、准入条件、状态机约束、Human Gate 要求和 Tools 授权边界，减少遗漏已 accepted 决策、违规创建、非法状态流转和未授权写入。

Rules 入口是安全带和高频提醒，不是 ADR 完整流程。ADR 读取、创建、升级、推翻和废弃的流程由 21.02-Skill.md 承接，ADR Tools 命令、参数和能力边界由 21.04-Tools.md 承接。

---

## 三、适用场景

1. AI 修改 specs、Rules、Tools、事实模型边界或处理影响长期执行方式的判断前，需要检查是否存在相关 ADR 时；
2. AI 判断某个决策是否应创建 ADR 时；
3. AI 编辑 ADR YAML 实例的状态字段时；
4. AI 调用 ADR Tools 执行写入命令时；
5. AI 尝试推翻、废弃或升级已 accepted ADR 时。

---

## 四、实践边界

1. 本实践只约束 Rules 层对 ADR 的读取提醒、准入入口、写入提示和禁止承载内容；
2. ADR 的完整准入条件、状态机、Human Gate 和字段契约由 21 主文档定义；
3. ADR 的读取、创建、升级、推翻和废弃流程由 21.02-Skill.md 承载；
4. ADR Tools 只读查询、契约校验、受控写入命令、参数和执行边界由 21.04-Tools.md 承载；
5. 本实践不替代 21 主文档的任何章节。

---

## 五、实践内容

### 5.1 读取提醒

Rules 入口应提醒 AI 在以下场景检查是否需要读取 ADR：

1. 修改 specs、Rules、Tools、Web、事实模型边界或行动模型边界前；
2. 用户询问某项长期设计、规则归属、事实源边界或协作机制为什么这样决定时；
3. AI 准备提出影响长期执行方式、Human Gate、事实源归属或机制分工的方案时；
4. AI 发现当前任务可能与既有长期决策冲突时。

读取提醒只要求 AI 回到 21 主文档、21.02-Skill.md 或 21.04-Tools.md 执行读取与适用判断，不在 Rules 中复制读取流程。

### 5.2 写入提醒

Rules 入口应提醒 AI 在以下场景停下并评估 Human Gate：

1. 创建 ADR；
2. 将 `proposed` ADR 变更为 `accepted` 或 `rejected`；
3. 将 `accepted` ADR 变更为 `deprecated` 或 `superseded`；
4. 修改已 accepted ADR 的 `decision` 字段；
5. 将 ADR 升级为 specs 或 Rules；
6. 调用 ADR Tools 写入命令。

调用 ADR Tools 写入命令前，应确认 Human Gate 已由用户明确给出，并按 21.04-Tools.md 的命令边界传入显式授权参数。Tools 不生成授权。

### 5.3 禁止承载内容

Rules 入口不得承载以下内容：

1. ADR 完整准入条件列表；
2. ADR 状态机完整定义；
3. ADR 字段契约；
4. ADR 对象关系转化规则；
5. ADR 读取、创建、升级、推翻和废弃完整流程；
6. ADR Tools 命令清单和参数说明；
7. ADR 事实源回写规则；
8. ADR 证据留存要求。

以上内容分别由 21 主文档、21.02-Skill.md、21.04-Tools.md 和 21.06-Contract.md 承载。

---

## 六、Human Gate

1. 将 ADR 相关读取提醒、准入入口或写入 Human Gate 提示从 Rules 中移除时，应经 Human Gate 确认；
2. ADR 准入条件、状态机或读取适用规则变更影响 Rules 入口时，应经 Human Gate 确认。

---

## 七、检查项

检查 ADR Rules 入口是否合规时，应确认：

1. Rules 是否只保留 ADR 读取提醒、准入入口和写入 Human Gate 提示；
2. Rules 是否未复制 21 主文档的完整准入条件、状态机或字段契约；
3. Rules 是否未复制 21.02-Skill.md 的读取、创建、升级、推翻和废弃流程；
4. Rules 是否未复制 21.04-Tools.md 的命令清单和参数说明；
5. AI 编辑 ADR YAML 时是否自动检查状态流转合法性；
6. AI 调用 ADR Tools 写入命令前是否确认 Human Gate，并传入显式授权参数；
7. AI 是否未将 `proposed` 状态 ADR 或 ADR Tools `draft` 输出作为执行依据。
