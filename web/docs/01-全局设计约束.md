# LDVH Web 页面设计规范

> 版本：1.0
> 更新：2026-06-05
> 范围：web/ 前端所有页面的设计基线

## 1. 全局设计约束

### 1.1 技术栈

| 层 | 技术 |
|---|---|
| 框架 | React 18 + TypeScript |
| 样式 | Tailwind CSS（darkMode: class） |
| 构建 | Vite（端口 5173，strictPort: true） |
| 后端 | Express 4（端口 3001） |
| 路由 | React Router v6 |
| 图标 | lucide-react |
| Markdown | react-markdown + remark-gfm |
| 代码高亮 | react-syntax-highlighter（Prism + oneDark） |

### 1.2 主题系统

- 三态切换：system / light / dark
- CSS 变量使用 RGB 通道值（如 `248 249 251`），支持 Tailwind 透明度修饰符
- 所有颜色通过 `ldvh-*` 命名空间引用

### 1.3 国际化

- React Context 轻量实现，localStorage 持久化
- 所有 UI 文案通过 `useI18n()` 的 `t()` 获取
- 状态文本通过 `getStatus()` 获取
- 标题通过 `getLocalizedTitle()` 获取（优先 title_en/title_zh，回退 title）
- 字段名通过 `FIELD_LABEL_LOCALES` 映射
- 类型标签通过 `TYPE_LOCALES` 映射
- 最小相对时间：1分钟前（不用"刚刚"）

### 1.4 布局

- 两种布局：侧边栏（默认）、顶部导航（?layout=topnav）
- 页面最小宽度：360px
- 设计基准：390px / 412px
