骨架中的章节均为强制要求。某章节暂不适用时，必须保留章节并说明不适用原因、替代承载位置或待补齐事项。

模板中的 `collection_status` 不得直接复制为 `active`。只有能回指 v1 历史 成员主文件，或存在 Human Gate 记录说明新增 active 授权、可执行锚点完整且必要检查通过时，才能填写 `active`；否则应按 03 正文状态闭集选择 `planned`、`candidate`、`reserved`、`removed` 或 `deprecated`。

成员主文件的 `规范保障要求` 章节写法以 03 主文 §6.2 为准。本文只给骨架提示：该章节应回指来源要求，并承载行动进入、执行、Gate、验证、证据、问题分流和能力映射；不得把本附件解释为新的规范保障要求来源。

## 3. 骨架模板辅助核对表

骨架模板辅助核对至少包括：

| 核对项 | 标准 |
|---|---|
| 身份块完整 | 同时包含 `v2_spec` 和 `v2_action_member` |
| 上位依据完整 | `basis` 包含 00、01、03 |
| 必要章节完整 | 保留 01 和 03 要求的行动编排成员必要章节 |
| 锚点可回指 | `v2_action_member` 中的锚点能回指本文正文章节 |
| 分流章节存在 | 包含执行中问题分流与失败暂停章节，且不把分流闭集改写成成员私有闭集 |
| 不适用有说明 | 不适用章节保留标题并说明理由、替代承载位置或待补齐事项 |
| 不越界 | 模板未定义具体流程、Gate、事实源回写规则、能力资产自描述或测试实现 |

本核对表用于发现骨架模板缺失和模板越界；核对结论不能替代 03 主文档规定的高影响确认。
