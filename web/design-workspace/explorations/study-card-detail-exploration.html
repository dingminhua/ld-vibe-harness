◒摘要
⌄
  • 单 Agent 适合低耦合、小范围修改。
  • 并行子 Agent 适合研究、验证、设计分支并发探索。

◆建议
⌄

默认保留轻量单 Agent 路径；当任务天然可分支时开放并行；当结果会影响治理、文件归口或用户外部动作时强制 Human Gate。
