## 1. 定位

本文承载 04 授权的 Code 需求记录字段表。

## 2. 字段表

| 字段 | 出现要求 | 含义 |
|---|---|---|
| 来源 | 必须出现 | 来源规范、事实源、行动编排成员或 Human Gate 记录 |
| 输入范围 | 必须出现 | Code 应读取、解析、校验或聚合的对象范围 |
| 输出形式 | 必须出现 | stdout、JSON、DTO、诊断、索引、preflight 或测试结果 |
| 写入行为 | 必须出现 | 只读、写入前检查、受控写入候选或禁止写入 |
| 验证方式 | 必须出现 | 自动化测试、命令校验、等价验证或临时核对动作 |
| 问题分流 | 必须出现 | Code 不可用、输入缺失、权限不足或诊断不完整时的处理 |
| Human Gate | 条件出现 | 高影响写入、长期能力缺口或边界变化时的确认要求 |

## 3. 使用规则

Code 需求记录只用于说明需求是否适合进入 Code 实现，不得把未确认候选规则实现为默认判断。
