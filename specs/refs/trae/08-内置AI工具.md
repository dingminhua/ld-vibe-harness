## 1. 结论摘要

Trae 内置 AI 工具是平台为 AI 智能体提供的原生能力接口，定义于系统提示中，智能体通过函数调用（function call）方式使用。核心工具包括：AskUserQuestion（交互式问询，1-4 个结构化问题）、RunCommand（终端命令执行，支持阻塞/非阻塞和批准机制）、Schedule（cron 周期性定时任务管理）、NotifyUser（单向用户通知），以及 Read/Write/Edit/Glob/Grep/SearchCodebase/WebSearch/WebFetch/TodoWrite 等文件操作与搜索工具。

## 2. 概述

Trae 内置 AI 工具是平台为 AI 智能体提供的原生能力接口。这些工具在 AI 系统提示中定义，智能体可通过函数调用（function call）方式使用。工具涵盖终端执行、用户交互、定时任务、文件操作、代码搜索、网页访问等能力。

## 3. AskUserQuestion

### 3.1 用途

交互式问询工具，用于在关键决策点暂停 AI 执行，向用户提出结构化问题并等待用户选择后继续。

### 3.2 参数

- `questions`：问题数组，包含 1–4 个问题对象
  - 每个问题对象包含：
    - `question`：问题文本
    - `header`：问题标题，最多 12 个字符
    - `multiSelect`：是否允许多选
    - `options`：选项数组，包含 2–4 个选项
      - 每个选项包含：
        - `label`：选项标签，1–5 个词
        - `description`：选项描述

### 3.3 约束

- 一次调用最多 1–4 个问题
- 每个问题 2–4 个选项
- header 最长 12 个字符
- label 最长 1–5 个词

### 3.4 返回值

用户选择结果以 tool message 形式返回给 AI。

### 3.5 取消行为

用户取消时返回"暂停"，AI 应停止当前执行流程。

### 3.6 与 RunCommand requires_approval 的关系

AskUserQuestion 用于需要用户做选择的场景；RunCommand 的 `requires_approval` 参数用于需要用户批准命令执行的场景。两者机制不同：AskUserQuestion 提供结构化选项，requires_approval 提供批准/拒绝二元选择。

## 4. RunCommand

### 4.1 用途

在终端会话中执行命令。

### 4.2 关键参数

| 参数 | 说明 |
|---|---|
| `command` | 要执行的终端命令 |
| `blocking` | 是否阻塞等待命令完成；`false` 用于 web_server 或 long_running_process 类型 |
| `requires_approval` | 用户是否需要在执行前批准 |
| `command_type` | 命令类型分类：`web_server`、`long_running_process`、`short_running_process`、`other` |
| `cwd` | 工作目录（绝对路径） |
| `target_terminal` | 目标终端 ID；不指定则自动复用空闲终端或创建新终端 |

### 4.3 批准机制

- `requires_approval=true`：命令执行前需用户批准
- `requires_approval=false`：命令直接执行，无需用户确认
- 安全操作（如读写文件、创建项目、安装依赖、运行开发服务器）可设为 `false`
- 潜在风险操作应设为 `true`

### 4.4 终端状态

终端是状态化的，工作目录、环境变量和状态在同一个终端的多次调用之间持久保持。

## 5. Schedule

### 5.1 用途

管理基于 cron 的周期性定时任务，支持创建、更新、暂停、恢复、删除、查询和手动触发。

### 5.2 操作类型

| 操作 | 说明 | 必需字段 |
|---|---|---|
| `create` | 创建定时任务 | `message`、`cron_expression` |
| `update` | 更新定时任务 | `scheduled_task_id`（仅需变更的字段） |
| `pause` | 暂停定时任务 | `scheduled_task_id` |
| `resume` | 恢复定时任务 | `scheduled_task_id` |
| `delete` | 删除定时任务 | `scheduled_task_id` |
| `list` | 列出所有定时任务 | 无 |
| `get` | 获取定时任务详情 | `scheduled_task_id` |
| `trigger` | 立即触发一次执行 | `scheduled_task_id` |

### 5.3 Cron 表达式格式

使用标准 5 字段 Unix cron 格式：`minute hour day-of-month month day-of-week`

- 字段 3（day-of-month）和字段 5（day-of-week）默认为 `*`
- 当两个字段同时指定具体值时，关系为 OR（并集），而非 AND

### 5.4 约束

- 仅支持 cron 周期性任务，不支持一次性定时执行
- 最小执行间隔为 10 分钟
- 不支持秒级粒度

### 5.5 关键字段

- `message`：任务内容，从用户视角描述要完成的工作
- `name`：任务短标签（可选）
- `timezone`：IANA 时区字符串（可选，如 `Asia/Shanghai`）

## 6. NotifyUser

### 6.1 用途

通知用户审阅某项内容或结果。

### 6.2 与 AskUserQuestion 的关系

- NotifyUser：单向通知，不提供选项，仅告知用户
- AskUserQuestion：双向交互，提供结构化选项供用户选择

## 7. 其他内置工具简述

| 工具 | 用途 |
|---|---|
| Read | 读取本地文件内容 |
| Write | 写入文件到本地文件系统 |
| Edit（SearchReplace） | 基于搜索/替换模式编辑文件 |
| Glob | 按文件名模式匹配查找文件 |
| Grep | 基于 ripgrep 的内容搜索 |
| LS | 列出目录内容 |
| SearchCodebase | 语义代码搜索，按含义而非精确文本查找代码 |
| WebSearch | 搜索互联网获取实时信息 |
| WebFetch | 获取指定 URL 的网页内容（只读） |
| TodoWrite | 创建和管理结构化任务列表 |
| AskUserQuestion | 交互式问询（详见上文） |
