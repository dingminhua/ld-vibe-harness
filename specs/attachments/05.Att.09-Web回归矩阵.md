## 2. 回归矩阵

| 对象 | 回归要求 | 优先级 |
|---|---|---|
| API contract | `tests/web/api/` 或等价检查 | 最高 |
| `POST /api/sparks` | 成功、字段错误、冲突、写后验证失败 | 最高 |
| ProjectFiles | 空态、错误态、只读边界、来源呈现 | 高 |
| Validate | 诊断、问题原因、来源命令、不得自动修复 | 高 |
| Objects/ObjectDetail | 字段来源、关联提交、只读边界 | 高 |
| Gate | 候选状态、确认字段、不得自动回写 | 高 |
| Changelog | commit body、文件列表、复制上下文 | 中 |
| KnowledgeMap | source refs、diagnostics、legacy `degraded` 兼容字段、no-store | 中 |
| E2E/视觉回归 | 复杂浏览器流程 | 后置 |

## 3. 边界

Web 回归矩阵不定义测试治理本体。验证声明、等价验证和测试证据边界回到 08。
