## 2. 回归入口

| 入口 | 用途 | 边界 |
|---|---|---|
| `npm run test:code` | LDVH Code 当前日常完整测试入口 | 必须同时覆盖 `tests/code` 自动化测试和 `python3 code/specs_validate.py all --fail-on-diagnostics` |
| `python3 -m pytest -q tests/code` | Code 单元/集成测试 | 不替代 specs 全量校验 |
| `python3 code/specs_validate.py all --fail-on-diagnostics ...` | active specs 综合校验 | v2 未 active 前不默认跑 v2-check |
| `python3 code/specs_validate.py v2-check --fail-on-diagnostics --format text` | specs-v2 迁移诊断 | 不替代 active 校验 |
| `git diff --check` | 空白和补丁格式检查 | 不验证业务规则 |

## 3. 使用规则

只跑局部测试时，必须说明残留风险。不得用 `python3 -m pytest -q tests/code`、`v2-check` 或 `git diff --check` 静默替代 `npm run test:code` 的完整入口语义。v2-check 通过只说明 v2 写作区结构可解析，不等于迁移完成或 active 切换完成。
