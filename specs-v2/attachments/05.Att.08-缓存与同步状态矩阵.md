## 1. 定位

本文承载 05 授权的缓存与同步状态矩阵。

## 2. 状态矩阵

| 状态 | 含义 | 展示要求 |
|---|---|---|
| fresh | 当前响应来自最新可读事实源或 Code 输出 | 可显示同步时间和来源 |
| stale | 当前数据可能过期 | 显示过期原因和刷新入口 |
| degraded | 部分输入不可用或能力降级 | 显示不可证明范围 |
| error | 读取、解析、同步或 API 出错 | 显示错误来源和修复线索 |
| conflict | Web 派生结果与事实源或 Code 输出冲突 | 退回事实源和诊断，不以页面覆盖事实源 |
| no-store | 知识地图等查询不得持久化缓存 | 不使用浏览器持久化缓存 |

## 3. 边界

缓存只能改善性能和交互体验，不得成为事实实例、决策、状态、审计或验收的唯一来源。

## 4. 待补齐事项

2. 知识地图运行时推进前，应复核 no-store 语义。
