# 附件身份字段表

```yaml
ldvh_attachment:
  attachment_key: "attachment-identity-fields"
  attachment_id: "04.Att.05"
  title: "附件身份字段表"
  status: "active"
  canonical_path: "specs/attachments/04.Att.05-附件身份字段表.md"
  parent_spec: "specs/04-规范体系基础规范.md"
  relation: "authorized_by"
  supersedes: []
```

> 文件状态：active；本文只承载 `ldvh_attachment` 身份块字段闭集和状态枚举。

| 字段 | 目标结构必填 | 作用 | 边界 |
|---|---|---|---|
| `attachment_key` | 是 | 跨改名、改号和路径迁移保持不变的附件职责标识 | 不包含附件编号、路径、状态或版本；一经分配不得用于其他附件职责 |
| `attachment_id` | 是 | 当前附件集合中的唯一编号标识 | 可随整体编号迁移变化 |
| `title` | 是 | 当前正式标题 | 与 H1 标题一致 |
| `status` | 是 | 附件生命周期状态 | `active` 附件仍必须通过父规范授权才进入规则源 |
| `canonical_path` | 是 | 当前 Markdown 路径 | 必须与实际文件一致；迁移时可变 |
| `parent_spec` | 是 | 授权该附件的唯一父规范路径 | 不得为空或指向多个父规范 |
| `relation` | 是 | 附件与父 Spec 的关系 | 固定为 `authorized_by` |
| `supersedes` | 是 | 被本附件实质替代的旧 `attachment_key` 列表 | 改名、改号或移动同一职责时为空；目标必须满足父规范 §8.3 的替代图约束 |

| `status` | 含义 | 是否作为当前规则依据 | 允许转入的下一状态 |
|---|---|---|---|
| `candidate` | 候选附件 | 否 | `active`、`archived` |
| `active` | 已启用附件 | 仅在同时满足父规范 §5 所列当前规则依据条件时是 | `deprecated`、`archived` |
| `deprecated` | 已被替代或正在退出 | 否 | `archived` |
| `archived` | 历史归档 | 否 | 无，终态 |
