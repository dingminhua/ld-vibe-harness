## 1. 定位

本文承载 05 授权的 Web DTO 与 API 契约。

## 2. 契约表

| 契约对象 | 来源 | 必须保留 | 不得承载 |
|---|---|---|---|
| 事实对象 DTO | Git 文件事实源、02 字段契约、成员主文件 | 对象 ID、类型、状态、来源路径、可追溯字段 | 新字段契约、状态机 |
| 对象列表 API | 事实对象 DTO、Web 原生读取或 Code DTO | 来源回指、空态、错误态、筛选依据 | 第二事实源 |
| 对象详情 API | 事实源原文、字段契约、关联提交派生 | 字段来源、关联对象、验证/风险摘要 | 字段写入授权 |
| `POST /api/sparks` | 05.Att.03、20 Spark | 白名单字段、错误分类、写后验证 | 通用 YAML 编辑 |
| Validate API | Code 诊断、测试状态、临时核对动作 | 诊断来源、问题原因、修复线索 | 自动修复、自动关闭 |
| Changelog API | Git history、07 派生规则 | commit token、body、文件列表、来源 | 手写 change 对象 |
| 知识地图 API | 04 知识地图投影 | source refs、diagnostics、excluded inputs、legacy `degraded` 兼容字段 | Web 补写节点或边 |

## 3. 使用规则

Web DTO 与 API 契约只服务 Human-facing 展示和受控交互。字段契约、状态机、Human Gate 条件、测试治理和 Git 提交契约分别回到 02、03、08 和 07。
