判断 LDVH 在多 Agent 协作时，应默认采用哪种执行编排，并明确 Human 何时介入。

  • 单 Agent 适合低耦合、小范围修改。
  • 并行子 Agent 适合研究、验证、设计分支并发探索。
  • Human Gate 应放在方案确认、外部动作、收口判断前。
