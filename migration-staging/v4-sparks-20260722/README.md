# V4 Spark 迁移暂存快照

本目录在 2026-07-22 曾暂存从 `ldvh-base/sparks/` 移出的 25 个 V4 Spark 载体，用于随后与 V3 Spark 逐对象比较、合并和重建。经确认，25 个原 V4 对象已经恢复到 `ldvh-base/sparks/`，本目录只保留迁移对照材料。

暂存期间的对象不是当前 canonical Spark，也不得被 Web、Helper、测试或迁移结论当作当前事实源。恢复后，`ldvh-base/sparks/` 中的 25 个对象重新成为当前事实源；本目录中的对照材料不是第二事实权威。

重建时必须先为每个 V3 与暂存 V4 对象形成迁移对照：保留内容、失效内容、承接或合并结论、来源及未决事项。不得按同号、标题相似或 Git 历史自动覆盖、复用身份或批量重建。
