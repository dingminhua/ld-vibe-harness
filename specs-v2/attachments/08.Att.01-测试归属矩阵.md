## 2. 归属矩阵

| 对象 | 归属 | 不承载 |
|---|---|---|
| 上层测试治理 | `specs-v2/08-测试基础规范.md` 和对应构成要素规范 | 当前参考实现的命令细节 |
| Code 测试细则 | `code/docs/` | specs 稳定规则、Web 测试规则 |
| Web 测试细则 | `web/docs/` | specs 稳定规则、Code 测试规则 |
| Code 测试实现 | `tests/code/` | Web API、页面或组件测试 |
| Web 测试实现 | `tests/web/` | Code CLI、解析器或校验器测试 |
| 行动编排可测试性锚点 | 30-59 active 成员主文件 | 统一测试实现入口、inactive 流程恢复 |
| 测试缓存、覆盖率、截图、trace、报告 | 临时验证产物或诊断线索 | 稳定事实源、规范规则、验收事实 |
