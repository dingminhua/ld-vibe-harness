# Trae 自动运行与安全机制

> 创建日期：2026-06-04
> 来源：Trae 官方文档
> 定位：外部资料引用，不直接成为 LDVH 强制规则
> 官方地址：https://docs.trae.cn/ide/auto-run-and-security

---

## 1. 结论摘要

Trae 自动运行分为"自动运行 MCP"和"自动运行命令"两个子功能。自动运行 MCP 启用后智能体自动运行已授权的 MCP Server 工具；自动运行命令支持 4 种模式（始终手动运行、使用白名单、使用黑名单、始终自动运行），默认所有终端命令需用户手动批准。启用自动运行存在提示词注入等安全风险，建议仅在可信环境中使用。

## 2. 官方定位

"自动运行"功能作用于所有智能体，分为"自动运行 MCP"和"自动运行命令"两个子功能。

## 3. 自动运行 MCP

启用"自动运行 MCP"后，智能体将自动运行为其添加的 MCP Server 及其中包含的工具，无需用户逐次手动确认。

- 所有外部 MCP Server 连接均需用户首次明确授权。
- 不建议在未验证来源或不受信任的环境中启用此功能。

## 4. 自动运行命令

"自动运行命令"支持以下四种模式：

| 模式 | 描述 |
|---|---|
| 始终手动运行 | 始终手动运行终端命令，即禁用"自动运行命令"功能 |
| 使用白名单 | 仅自动执行前缀匹配白名单的命令；需在"白名单作用于 IDE"处添加命令前缀 |
| 使用黑名单 | 前缀匹配黑名单的命令需用户确认后执行；需在"黑名单作用于 IDE"处添加命令前缀 |
| 始终自动运行 | 始终自动运行所有命令，跳过所有安全检查 |

## 5. 安全性说明

启用"自动运行"功能后，系统可能面临外部提示词注入等潜在安全风险。请在开启前充分评估风险，并仅在可信环境中使用。

### 5.1 自动运行 MCP 安全须知

- 所有外部 MCP Server 连接均需用户首次明确授权。
- 不建议在未验证来源或不受信任的环境中启用此功能。

### 5.2 自动运行命令安全须知

- 默认情况下，所有终端命令均需用户手动批准。
- 白名单功能仅提供基础防护，并不能完全避免潜在的绕过风险；建议在启用前逐条审查命令内容，确认其行为安全且符合预期。
- 建议非必要不启用"始终自动运行"模式；该模式会跳过所有安全检查，可能导致高风险操作在无提示的情况下被执行。

## 6. 配置位置

设置 > 对话流 > 自动运行
