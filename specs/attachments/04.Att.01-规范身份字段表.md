# 规范身份字段表

```yaml
ldvh_attachment:
  attachment_key: "spec-identity-fields"
  attachment_id: "04.Att.01"
  title: "规范身份字段表"
  status: "active"
  canonical_path: "specs/attachments/04.Att.01-规范身份字段表.md"
  parent_spec: "specs/04-规范体系基础规范.md"
  relation: "authorized_by"
  supersedes: []
```

> 文件状态：active；本文只承载 `ldvh_spec` 身份块字段闭集和枚举。

| 字段 | 目标结构必填 | 作用 | 边界 |
|---|---|---|---|
| `spec_key` | 是 | 跨改名、改号和路径迁移保持不变的规范职责标识 | 不包含编号、路径、状态或版本；一经分配不得用于其他职责 |
| `spec_id` | 是 | 当前规范集合中的唯一编号标识 | 可随整体编号迁移变化，不表示依赖层级 |
| `spec_kind` | 是 | 标识正文结构类型 | 使用本表定义的目标结构闭集；不表示成员关系、功能归属或构成要素归属 |
| `title` | 是 | 当前正式标题 | 与 H1 标题一致 |
| `status` | 是 | 规范生命周期状态 | 使用本表定义的状态闭集 |
| `canonical_path` | 是 | 当前 Markdown 路径 | 必须与实际文件一致；迁移时可变 |
| `parent_spec` | 条件必填 | 直接结构父 Spec | 根规范为空；存在直接结构归属时必填；不替代 `basis` |
| `relation` | 条件必填 | 说明与 `parent_spec` 的结构关系 | `parent_spec` 为空时为空 |
| `positioning` | 是 | 用一句话表达本规范的唯一定位 | 不复制章节目录或实现清单 |
| `scope` | 是 | 用一句话概括适用对象和行动 | 不替代正文的适用范围判断 |
| `basis` | 是 | 直接上位语义依赖路径列表 | 只保留必要直接依赖，全图无环 |
| `authorized_attachments` | 是 | 本 Spec 明确授权的附件路径列表 | 只承载附件授权，不收纳普通相关规范或反向消费关系 |
| `supersedes` | 是 | 被本 Spec 实质替代的旧 `spec_key` 列表 | 改名、改号或移动同一职责时为空；不替代迁移证据 |
| `code_consumption` | 是 | 本规范向 Code 提供的稳定解析入口 | 不列举 Code 文件，不声明能力已实现 |
| `role_sections` | 标准规范：是 | 信息角色到当前 H2 章节标题的解析索引 | 必须符合正文 §7.3 的键、值和 H2 唯一映射约束；可在 Code 能稳定派生后转为派生字段 |

| `spec_kind` | 含义 |
|---|---|
| `root` | 根规范结构 |
| `standard` | 根规范之外的受治理 Spec 所采用的结构 |

| `status` | 含义 | 是否作为当前规则依据 | 允许转入的下一状态 |
|---|---|---|---|
| `candidate` | 候选规范 | 否 | `active`、`archived` |
| `active` | 已启用的受治理 Spec | 仅在同时满足父规范 §5 所列当前规则依据条件时是 | `deprecated`、`archived` |
| `deprecated` | 已被替代或正在退出 | 否 | `archived` |
| `archived` | 历史归档 | 否 | 无，终态 |
