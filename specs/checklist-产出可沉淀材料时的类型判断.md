# 产出可沉淀材料时的类型判断检查清单

## 用途

AI 在话题漂移、产出实质性内容或即将写入持久文件时，用本清单快速判断产出是否应沉淀为受控事实对象，避免材料直写 `docs/` 遗漏类型判断。

## 1. 触发条件

**以下任一成立时，暂停写入，执行本清单：**

- [ ] 话题从原始请求明显漂移，产出内容已超出原问题范围
- [ ] 即将写入 `docs/` 或其它非 `ldvh-base/` 的持久路径，且内容包含发现、证据、分析、结论或建议
- [ ] 当前产出是一个独立完整的信息单元，可被后续会话单独引用

**三项均不成立** → 无需判断，继续普通写入。

---

## 2. 三步类型判断

### 第一步：是否已完成、有独立价值？

- [ ] 产出已经完成（不是进行中的搜索、调查或草稿）
- [ ] 存在一个可独立引用的对象与核心问题
- [ ] 具有跨行动复读或反复引用的现实价值

**任一否** → 不对象化，保持普通文件或聊天上下文。

### 第二步：归入哪个事实类型？

按优先级从高到低判断：

| 顺序 | 类型 | 一句话判断 | 准入依据 |
|------|------|-----------|----------|
| 1 | **ADR** | 是否作出了一个**有长期取舍的决策**，而非仅调研或分析？ | 22 §4 |
| 2 | **Pitfall** | 是否记录了**一个已发生、已解决、可复用的失败经验**？ | 23 §4 |
| 3 | **Study** | 是否完成了一份**调研、审计、评估或比较报告**，有发现和建议？ | 24 §4 |
| 4 | **Spark** | 是否是一个**需要进一步判断、未完成或不适合归入前三类**的议题？ | 20 §4 |

**都不符合** → 不对象化，普通文件直写。

### 第三步：已查重、无冲突？

- [ ] 已召回相邻同类对象，不存在可无损更新或重复的现有对象
- [ ] 现有规范、规则或文档没有已覆盖该内容
- [ ] 对象化收益（减少重复研究/误判）高于维护成本

---

## 3. 各类型准入条件速查

### ADR（22 §4）

- [ ] 决策问题清楚，一个方向已实际被选择
- [ ] 存在真实、可说明的长期取舍，跨行动影响
- [ ] 适用对象、范围、理由和预期后果可稳定表达
- [ ] 决定已实际形成，不是事后补造
- [ ] 已有相邻对象，无重复

**排除：** 未决方案、偏好、纪要、日志、已由规范覆盖的内容。

### Pitfall（23 §4）

- [ ] 存在实际发生的失败或误判
- [ ] 问题已实际解决，根因与症状相容
- [ ] 解决方式已实际采用并观察到结果
- [ ] 存在现实复发概率或迁移价值
- [ ] 已有相邻对象，无重复

**排除：** 未解决的故障、一次性日志、bug backlog、情绪复盘、最佳实践。

### Study（24 §4）

- [ ] 一轮报告已完成
- [ ] 存在可独立引用的对象与核心问题
- [ ] 输入、方法、观察时点、适用边界清楚
- [ ] 有发现、建议和后续分流
- [ ] 具有跨行动复读价值
- [ ] 已有相邻对象，无重复

**排除：** 临时搜索结果、聊天摘要、未完成调查、运行日志、一次性笔记。

### Spark（20 §4）

- [ ] 存在需要进一步判断的未决问题
- [ ] 不满足 ADR/Pitfall/Study 的准入条件
- [ ] 保留该议题可避免后续重复定位与重新分析

---

## 4. 操作指引

| 判断结果 | 行动 |
|----------|------|
| 符合 ADR / Pitfall / Study | 走 **31 号模板**（事实对象判定与受控创建） |
| 符合 Spark | 创建 Spark，记录问题与背景 |
| 都不符合 | 直写 `docs/` 或其它普通路径 |

---

## 5. 常见误判

- **"含建议 → 不是 Study"** → Study 可以含建议分流，建议不等于行动授权
- **"还在改 → 不是完成"** → 完成指一轮调研结束，不表示结论不可更新
- **"只是普通笔记"** → 如果包含发现、分析、结论且可独立引用，应检查 Study 条件
- **"话题只是聊到了"** → 话题漂移后应重新确认规则适用，不能默认继续普通对话
