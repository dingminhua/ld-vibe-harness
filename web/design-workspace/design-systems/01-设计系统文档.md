- ✅ Accent (`#3b82f6`) on white: 对比度 4.5:1+ (WCAG AA 合规)

- ⚠️ 需要验证：所有颜色组合在 dark mode 下的对比度

```
Page Title (20px / 600) ← 最高层次
  ↓
Section Title (14px / 600)
  ↓
Card Title (14px / 500)
  ↓
Body (14px / 400) ← 主要内容
  ↓
Caption (12px / 400) ← 说明、提示
  ↓
Meta (12px / 400 monospace) ← 技术元数据
```

## 📏 间距系统

### 基于 4px 的间距尺度

| Token | 值 | 用途 |
|-------|-----|------|
| `space-1` | 4px | 最小间距、图标与文本间距 |
| `space-2` | 8px | 紧凑布局、相关元素间距 |
| `space-3` | 12px | 表单元素间距、卡片内间距 |
| `space-4` | 16px | 标准间距、区块内间距 |
| `space-6` | 24px | 区块间距、卡片间距 |
| `space-8` | 32px | 大区块间距、页面段落间距 |
| `space-12` | 48px | 页面区块间距 |
| `space-16` | 64px | 页面顶部/底部间距 |

### 布局规则

- 页面最小宽度：375px（移动端优先）
- 容器最大宽度：1280px（居中）
- 网格：使用 `auto-fit + minmax()` 实现自适应
- 响应式断点：640px、768px、1024px、1280px

## 🧩 组件库

### 已确认的组件契约

#### Tab 组件
- 容器：`ldvh-tab-list`（flex, min-h-7, gap-1.5）
- 按钮：`ldvh-tab-button`（inline-flex, gap-1.5, rounded-md, border, px-2, py-1, text-xs）
- 状态：
  - Active: `ldvh-tab-button-active`（accent 色）
  - Idle: `ldvh-tab-button-idle`（border + hover effect）
- 计数：使用 `ldvh-tab-count`（继承父级字体）

#### Card 组件
- 基础卡片：白色背景、0.5px border、rounded-lg、padding
- 悬停效果：shadow-md + translateY(-2px)
- 状态：default、hover、active、selected、disabled

#### Identity Header 组件
- 对象类型图标 + 对象标题
- 元数据行（路径、状态、时间）
- 操作按钮组

#### Reading Node 组件
- 用于 ObjectDetail 的语义阅读
- 支持折叠/展开
- 节点类型：Study、ADR、Spark、Pitfall、Changelog、WorkCase

#### Reference Row 组件
- 引用行（对象间关系）
- 显示引用类型和目标对象

## 📱 响应式设计

### 断点策略

| 断点 | 宽度 | 布局调整 |
|------|------|---------|
| Mobile | 375px - 639px | 单列、底部抽屉 |
| Tablet | 640px - 1023px | 双列、侧边栏折叠 |
| Desktop | 1024px - 1279px | 三列、完整功能 |
| Large Desktop | 1280px+ | 四列、优化大屏 |

### 响应式行为

- **App Shell**：
  - Desktop: 左侧主导航（240px）+ 中间内容 + 右侧阅读区（320px）
  - Mobile: 顶部导航 + 内容 + 底部抽屉（右侧阅读区）

- **Grid 布局**：
  - 使用 `grid-template-columns: repeat(auto-fit, minmax(280px, 1fr))`
  - 确保最小列宽 280px

- **Typography**：
  - 移动端：减小页面标题（18px → 16px）
  - 桌面端：保持标准尺寸

## ♿ Accessibility 标准

### WCAG AA 合规目标

- [ ] 颜色对比度：4.5:1 for normal text, 3:1 for large text
- [ ] 键盘导航：所有交互元素可聚焦
- [ ] Focus Indicator：清晰的焦点指示器
- [ ] Touch Target：最小 44px
- [ ] 文本缩放：支持 200% 缩放
- [ ] Motion Sensitivity：尊重 `prefers-reduced-motion`
