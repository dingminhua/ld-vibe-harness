## 1. 定位

## 2. 边界清单

| 文档位置 | 可承载 | 不得承载 |
|---|---|---|
| `code/docs/` | Code 参考实现说明、命令用法、实现细节、调试说明和局部测试说明 | 正式规范规则、字段契约、事实源边界、Human Gate |
| README 或命令帮助 | 快速入口、参数说明、示例命令 | 替代 specs、替代测试治理 |
| 测试夹具说明 | 正反样例、失败条件、预期输出 | 规范本体规则 |

## 3. 使用规则
