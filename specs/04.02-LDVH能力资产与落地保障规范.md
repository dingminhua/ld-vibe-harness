# LDVH 能力资产与落地保障规范

> 创建日期：2026-06-13
> 所属主文档：`specs/04-规范落地与环境适配基础规范.md`
> 关系：专题子文档
> 定位：定义 LDVH 如何用能力资产和能力组合保障正式规范提出的落地要求
> 适用范围：LDVH 能力资产、能力保障池、要求到能力的默认映射、能力边界、缺口分流、运行纪律
> 上位依据：`specs/04-规范落地与环境适配基础规范.md`、`specs/04.01-规范落地声明规范.md`、`specs/02-术语规范.md`

本文定义 LDVH 能力保障关系及其依据的 LDVH 能力资产。本文不定义具体环境入口、部署步骤、适配检查结果或个人环境特殊限制。

---

## 1. 本文解决的问题

04.01 说明正式规范提出了什么落地要求；本文说明 LDVH 用哪些能力资产和能力组合保障这些要求落地。

本文解决：

1. LDVH 有哪些能力资产；
2. 落地要求默认映射到哪些能力资产或能力组合；
3. 各能力资产的职责和边界；
4. 能力缺口和环境接入缺口如何分流；
5. 哪些能力边界变化必须 Human Gate。

环境入口如何接入、部署和检查这些能力资产由 04.03 定义。

---

## 2. LDVH 能力资产

LDVH 能力资产是 LDVH 自己定义和维护、用于保障规范落地的能力内容。能力资产不是环境入口，不表示用户本地已经部署、启用或验证。

| 能力资产类型 | 当前固定资产 | 适合保障 | 不适合保障 | 边界 |
|---|---|---|---|---|
| Rules 资产 | `../rules/LDVH-AI-ENTRY.md` | AI 可见、硬约束摘要、事实源边界、STOP 点、最小读取顺序 | 完整规范正文、长期状态、用户本地安装状态 | 只做统一入口和导航，不是事实源 |
| Skill 资产 | `../skills/ldvh-spec-change-check/SKILL.md` | 流程复用、多步骤 SOP、检查步骤、失败处理、交还方式 | 稳定规则正文、Human Gate 判断本身、默认调度 Agent | Skill 不能替代正式规范 |
| Agent 资产 | `../agents/ldvh-spec-semantic-review.md` | 独立上下文、专项审查、复杂争议、并行视角 | 简单问答、直接生效结论、绕过主控 | 输出必须回主控或 Human |
| Hook 资产 | `../hooks/ldvh-lifecycle-check.md` | 生命周期检查入口、提醒、阻断提示、降级提示 | 规范正文、语义判断本身、无授权写入 | 触发不等于检查通过 |
| Code 能力资产 | `../code/`、测试目录、CI 或命令验证 | 解析、校验、聚合、受控写入前检查、漂移检查 | Human 授权、价值判断、复杂语义结论 | 按 07 Code 规范实现 |
| Web 能力资产 | `../web/`、Human Gate 流程 | Human-facing 态势、确认、授权、验收、派生展示 | 第二事实源、绕过 Code 校验的后台 | 按 08 Web 规范实现 |

Command、CLI、CI、MCP 和文档可以支撑能力保障、适配措施或检查执行，但不得被写成与 Rules、Skill、Agent、Hook 同级的 LDVH 文本能力资产类型。

---

## 3. 要求到能力资产的默认映射

| 规范落地要求 | 默认能力资产或能力组合 | 常见补充 |
|---|---|---|
| 上位约束承接要求 | Rules 资产、规范引用、索引、Code 引用检查 | Human Gate、ADR、Task |
| 入口可见要求 | Rules 资产、AI 可见摘要、薄引用 | Web 展示、Command 提示 |
| 流程复用要求 | Skill 资产、工作流程、Command 包装 | Code wrapper、Web 表单、Task 模板 |
| 子 Agent 思考要求 | Agent 资产、主控多视角审阅 | Human Gate、审阅清单 |
| 确定性执行要求 | Code、测试、CI、命令验证 | Web 展示、Command 包装 |
| Human 交互要求 | Human Gate、Web、结构化问询、对话确认 | diff、预览、风险说明 |
| 生命周期触发要求 | Hook 资产、CI、命令检查、人工降级检查 | Skill 提醒、入口 STOP 点 |

默认映射只是落地保障起点。具体环境如何接入这些能力资产，由 04.03 根据环境入口定义部署和适配检查方式。

---

## 4. 能力资产边界

### 4.1 Rules 资产

Rules 资产允许承载入口摘要、事实源边界、STOP 点、权威引用和场景路由。Rules 资产不得复制完整 specs 正文、字段契约全文、状态机正文、长期过程状态或 Agent 结论。

### 4.2 Skill 资产

Skill 资产允许承载可复用流程、标准化输入输出、检查步骤、失败处理、STOP 点和交还方式。Skill 资产不得新增稳定规则、字段、状态、Human Gate 条件或默认调度 Agent。

LDVH 自建 Skill 的稳定标识应使用 `ldvh-` 前缀，前缀后使用小写字母、数字和连字符，不绑定具体业务项目名、个人名、环境名或临时阶段名。

### 4.3 Agent 资产

Agent 资产允许承载独立上下文分析、专项审查、并行视角、复杂争议和权限边界差异判断。Agent 输出不得直接生效，必须回到主控或 Human，经必要验证和回写后才成为稳定事实。

### 4.4 Hook 资产

Hook 资产允许承载生命周期检查入口、提交前后检查提示、工具调用前后检查提示、会话停止检查提示和降级提示。Hook 触发不等于检查通过，Hook 输出必须受 Code、Human Gate、事实源边界和降级记录约束。

---

## 5. 能力提供原则

1. 要求先行：先读取 04.01 或正式规范中的落地要求，再选择能力资产；
2. 组合优先：重要要求通常需要 Rules、Skill、Code、Human Gate、Hook 或人工降级组合保障；
3. 资产清晰：能力资产由 LDVH 维护，不与环境入口混同；
4. 薄接入优先：能力资产进入环境入口时应优先薄引用、配置、安装或软链；
5. 确定性外移：能机械判断的规则应优先进入 Code、测试或 CI；
6. 授权前置：高影响写入、长期配置、权限扩大和完整支持声明必须 Human Gate；
7. 证据回写：过程输出中的稳定事实必须分流回 Git 文件事实源。

## 6. 缺口分流

| 缺口类型 | 含义 | 分流位置 |
|---|---|---|
| 能力资产缺口 | LDVH 缺少保障该要求的能力资产或能力组合 | Task、ADR、Memo、Code/Web 需求、正式规范 |
| 环境入口接入缺口 | 环境不能接入现有 LDVH 能力资产 | 04.03 环境入口适配与部署规范 |
| 个人环境约束 | 当前用户或维护者环境限制部署、检查或命令执行 | 04.03 环境入口适配与部署规范 |
| 适配检查失败 | 当前部署或接入未通过现场检查 | Code 输出、Human Gate、Task、Memo、Pitfall |

不得通过删除正式规范中的落地要求、把弱环境限制写成 LDVH 全局限制、把人工降级写成完整支持、或把工具输出写成事实源来解决缺口。

## 7. 规范落地要求

| 落地要求 | 要求内容 | 保障机制 | 同步类型 | 触发条件 |
|---|---|---|---|---|
| 上位约束承接要求 | LDVH 能力资产与落地保障应承接 04.01 的落地要求声明 | 本文、04.01、Human Gate | 能力治理 | 能力资产、能力边界或默认映射变化时 |
| 入口可见要求 | AI 判断落地保障时应能定位本文 | Rules 资产、04 父规范、人工降级检查 | AI 执行入口提示 | 本文文件名、标题、能力资产表变化时 |
| 流程复用要求 | 能力资产维护和缺口分流应形成可复用流程 | Skill、Command、人工检查 | 流程复用 | 新增能力资产或处理能力缺口时 |
| 确定性执行要求 | Code 应能检查能力资产存在、边界和引用关系 | Code、测试样例 | 校验实现 | 能力资产字段稳定后 |
| Human 交互要求 | 新增稳定能力资产、改变能力边界或声明完整支持前应暂停确认 | Human Gate、Web、对话确认 | 能力治理确认 | 高影响能力建设或边界变化时 |

---

## 8. Human Gate 与检查要求

以下情况必须评估 Human Gate：

1. 新增、删除或改变 LDVH 能力资产类型；
2. 改变 Rules、Skill、Agent、Hook、Code、Web、Command 或 Human Gate 的能力边界；
3. 允许能力资产直接成为最终事实源；
4. 允许 Skill 新增稳定规则、字段、状态或 Human Gate 条件；
5. 允许 Agent 输出直接生效；
6. 声明 Hook 或人工降级具有原生完整支持；
7. 删除、重命名或移动当前固定能力资产。

能力资产检查至少包括：

| 检查项 | 标准 |
|---|---|
| 要求来源 | 能力保障来自正式规范落地要求 |
| 资产存在 | 当前固定能力资产路径存在且职责明确 |
| 资产边界 | Rules、Skill、Agent、Hook 未互相替代或越权 |
| 非事实源 | 能力资产未替代 specs、事实源、Code 校验或 Human Gate |
| 环境分流 | 环境接入、部署和适配检查由 04.03 承接 |
