## 1. 定位

本文承载 07 授权的典型事实类型与权威位置矩阵。

07 正文定义最终事实源、单一事实源、历史记录提取和回写原则；本文只提供常见事实的归属查找表，不得单独定义新的事实源原则、目录职责、迁移流程、Code 输出 Schema 或 Web 页面契约。

本文以“事实归属矩阵”为单一信息对象。若后续事实归属与目录登记、字段注册、运行时资产登记或测试入口矩阵出现独立授权，应分别回到对应父规范或附件承接。

## 3. 使用规则

AI 使用本文时，应先按事实类型定位候选权威位置，再回到 07 正文、对应 v2 主规范、v1 历史 原文和目标事实源原文确认。

矩阵不能替代以下判断：

1. 不能替代 07 的最终事实源和单一事实源原则；
2. 不能替代 01 的当前目录登记和附件授权；
3. 不能替代 02 与 20-29 的字段契约和状态机；
4. 不能替代 06 的运行时扩展承载物自描述；
5. 不能替代 Human Gate。

## 4. 辅助核对表

| 核对项 | 标准 |
|---|---|
| 单一归属 | 同一稳定事实只有一个权威位置 |
| 回到正文 | 归属判断能回到 07 正文或对应主规范 |
| 不反向授权 | 矩阵没有把非事实源升级为事实源 |
| 不扩展目录 | 矩阵没有新增目录职责或写入规则 |
| 不替代 active | active 判断仍回到 `specs/` |
