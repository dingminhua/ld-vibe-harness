## 1. 定位

本文承载 06 授权的能力缺口分流核对表。

## 2. 分流表

| 缺口类型 | 含义 | 分流位置 |
|---|---|---|
| 运行时扩展缺口 | 缺少 Rules、Skill、Agent、Hook 或等价承载物 | WorkCase、Spark、06、对应承载物 |
| 能力组合缺口 | 某保障要求缺少稳定运行时扩展组合，或需要其它构成要素补齐能力 | WorkCase、ADR、Spark、06、对应承载物；涉及 Code、Web、行动编排或测试时回到对应构成要素规范 |
| 环境入口接入缺口 | 环境不能接入现有承载物，或非 Codex 环境需要自助适配 | 06、适配核对、WorkCase、Spark |
| 个人环境约束 | 当前用户或维护者环境限制部署、检查或命令执行 | 当前过程输出、Human Gate、WorkCase/Spark |
| 适配检查失败 | 当前部署或接入未通过现场检查 | Code 输出、Human Gate、WorkCase、Spark、Pitfall |
| Code 覆盖缺口 | 运行时扩展或适配规则无法被 Code 检查 | 04、Code WorkCase、临时核对动作 |
| 测试覆盖缺口 | Hook、Skill、入口或部署检查无正反样例 | 08、测试 WorkCase、临时核对动作 |

## 3. 禁止事项

不得通过删除正式规范中的保障要求、把弱环境限制写成 LDVH 全局限制、把临时核对动作写成完整支持、或把工具输出写成事实源来解决缺口。

2. Web v2 展示确认后，应检查缺口是否可被 Human-facing 展示。
