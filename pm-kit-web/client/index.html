项目总览

Trae PM Kit

版本：v2.0

通用产品管理套件（规范 + 工具），为 vibeCoding 项目提供产品管理规范和任务管理工具。

规范层：定义 vibeCoding 场景下的产品管理对象与协作边界

工具层：基于 Git 文件事实源（零依赖、无数据库）的任务管理工具

行动

展示从目标分解、沟通生成、审计发现、规则触发和计划变更中分流出的可推进事项。支持在合法状态之间状态流转，结果受控写回 task-base 事实源。
