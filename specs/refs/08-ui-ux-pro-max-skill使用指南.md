## 1. 技能概述

`ui-ux-pro-max-skill` 是一个 UI/UX 美化增强技能，专门用于优化网页界面、应用程序界面的视觉设计和用户体验。

### 主要功能
- **智能设计系统生成** - 根据需求自动生成完整的定制化设计系统
- **67种UI风格** - Glassmorphism、Claymorphism、Minimalism、Brutalism、Neumorphism、Bento Grid、Dark Mode、AI-Native UI等
- **161种调色板** - 与161种产品类型1:1匹配的行业特定调色板
- **57种字体组合** - 精心策划的Google Fonts字体组合
- **25种图表类型** - 仪表板和分析图表推荐
- **15种技术栈** - React、Next.js、Vue、Flutter、HTML+Tailwind等
- **99条UX准则** - 最佳实践、反模式和无障碍规则
- **161条推理规则** - 行业特定设计系统生成（v2.0新特性）

## 2. 适用场景

### 场景 1：新建网页项目
当需要从零创建生产级别的网页界面时，使用此技能确保高质量的视觉设计和用户体验。

```
使用 ui-ux-pro-max-skill 创建一个 [项目描述] 网页界面
```

### 场景 2：现有界面优化
对已有的网页或应用界面进行视觉和用户体验优化。

```
使用 ui-ux-pro-max-skill 优化 [文件路径] 的界面设计
```

### 场景 3：设计规范应用
确保界面符合设计系统和视觉规范。

```
使用 ui-ux-pro-max-skill 应用 [设计规范描述] 到界面
```

## 3. 使用说明

### 调用方式
在对话中直接提及 `ui-ux-pro-max-skill` 或使用「ui美化技能」等关键词，系统会自动识别并调用该技能。

### 工作流程
1. **需求理解**：分析用户的 UI/UX 优化需求
2. **设计方案**：提供视觉设计和交互方案
3. **代码实现**：生成或修改相关代码文件
4. **验证检查**：确保改动符合设计规范

---

## 4. 注意事项

1. **项目范围**：本技能适用于任何需要 UI/UX 优化的项目
2. **设计一致性**：确保修改与项目现有设计风格保持一致
3. **可访问性**：优化时考虑无障碍设计原则
4. **性能影响**：避免引入过多影响页面加载性能的资源
