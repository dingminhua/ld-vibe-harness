## 基本用法

Context7 提供两个工具：

1. **resolve-library-id**：将库名解析为 Context7 兼容的 ID
2. **get-library-docs**：根据 ID 拉取文档，可指定主题和 token 数

在对话中用 `use context7` 触发，或直接描述需求让 AI 自动调用。

---

## 模板1：前端框架 API 查询

适用场景：前端项目开发时查组件、状态管理、路由等最新用法。

```
use context7
查 {框架名} 最新文档，主题：{如 "组件生命周期" / "状态管理" / "路由配置"}
```

示例：

```
use context7
查 React 最新文档，主题：useEffect 清理函数与依赖数组
```
