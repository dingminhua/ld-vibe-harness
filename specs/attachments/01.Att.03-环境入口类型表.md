| 入口类型 | 判定条件 | 当前示例 |
|---|---|---|
| `automated_hook` | 环境真实自动触发、失败可阻断、安装状态可复现的通用自动入口 | `git.commit-msg` |
| `git_hook_shim` | 安装在具体 Git repo 中的薄引用，只调用 LDVH，不承载规则本体 | `git.commit-msg` shim |
| `environment_hook` | AI 环境、编辑器、Agent 平台或插件生命周期事件入口，只指向 LDVH runtime / adapter；Codex 中应由 LDVH 插件承载 | LDVH Codex plugin 的 `SessionStart`、`PreToolUse`、`Stop` hook |
| `manual_entrypoint` | 可由 AI、Human 或外部包装手动调用，没有自动触发证明 | `manual.session_start`、`manual.pre_tool_use`、`manual.completion_claim` |
| `external_adapter_candidate` | 可被外部环境或插件接入，但缺真实触发、安装、失败处理或回滚证据 | `runtime.adapter.auto`、`codex.ldvh-plugin` |
| `repo_instruction_candidate` | repo 级指令文件或插件配置可见，但不能证明生命周期 Hook 已接入 | `codex.repo-instructions` |
| `removed_top_level` | V3 已取消的顶层机制，只保留 legacy 或外部包装候选身份 | `rules.top_level_mechanism`、`skills.top_level_mechanism` |
| `absent` | 未发现可识别入口、资产或候选文件 | 空 |
