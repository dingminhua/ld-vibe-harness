# Changelog 变更日志

> 路由：`/changelog`
> 源码：`web/src/pages/Changelog.tsx`
> API：`GET /api/changelog?limit=50`、`GET /api/changelog/:hash`

## 1. 页面目标

让用户查看项目的 Git 提交记录，了解每次变更的详细信息。

## 2. 布局结构

```
┌─────────────────────────────────────────┐
│ 变更 / Changes                           │
│ Git 提交记录，点击查看详情               │
├─────────────────────────────────────────┤
│ 提交列表                                 │
│ ┌─────────────────────────────────────┐ │
│ │ ▶ abc123f 提交消息标题              │ │
│ │          作者  2026-06-05 10:30     │ │
│ └─────────────────────────────────────┘ │
│ ┌─────────────────────────────────────┐ │
│ │ ▼ def456a 提交消息标题              │ │
│ │          作者  2026-06-05 09:15     │ │
│ │ ─────────────────────────────────── │ │
│ │ 变更详情（git diff --stat）          │ │
│ │ 2 files changed, 15 insertions(+)  │ │
│ │ - src/file1.ts | 10 ++++++----     │ │
│ │ - src/file2.ts |  5 ++---          │ │
│ └─────────────────────────────────────┘ │
│ ...                                     │
└─────────────────────────────────────────┘
```

## 3. 区域详细设计

### 3.1 页面标题

- 主标题：`变更 / Changes`
- 副标题：`Git 提交记录，点击查看详情`

### 3.2 提交列表

- 每条提交一个卡片
- 折叠状态：
  - 左侧：ChevronRight 箭头
  - shortHash（等宽 accent 色）
  - 提交消息（truncate）
  - 作者 + 格式化日期（本地化）
  - 右侧：GitCommit 图标
- 展开状态：
  - 箭头变为 ChevronDown
  - 底部分隔线后显示 `git diff --stat` 输出
  - 详情加载中显示旋转动画

### 3.3 日期格式

- 中文：`2026-06-05 10:30`（zh-CN locale）
- 英文：`06/05/2026, 10:30 AM`（en-US locale）

## 4. 交互

| 操作 | 行为 |
|---|---|
| 点击提交条目 | 展开/收起该提交的变更详情 |
| 再次点击 | 收起 |
| 语言切换 | 页面标题、副标题、日期格式跟随切换 |

## 5. API 数据结构

```typescript
interface ChangelogEntry {
  hash: string;
  shortHash: string;
  message: string;
  description: string;
  category: string;
  author: string;
  date: string;
  relativeTime: string;
}
```
