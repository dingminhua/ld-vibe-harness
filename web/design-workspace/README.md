# LDVH v3 Web 设计工作区

> 这是 UI Designer（像素君）的专属工作区域，用于维护和推进 v3 web 项目的设计工作。
> 所有设计探索、组件设计、设计系统文档都放在这里，不影响主代码库。

## 📁 目录结构

```
web/design-workspace/
├── design-systems/      # 设计系统文档（颜色、排版、间距、组件库）
├── components/          # 组件设计与状态图谱
├── explorations/        # 设计探索（Dashboard 优化、信息架构等）
├── assets/             # 设计资源（图标、图片、导出文件）
└── README.md           # 本文件
```

## 🎯 工作区用途

这个工作区用于：

1. **设计系统维护** - 创建设计系统的可视化文档，确保设计与实现一致
2. **设计探索** - 在动手实现前，先用画布探索不同的设计方案
3. **组件设计** - 设计组件的所有状态（default、hover、active、disabled 等）
4. **信息架构** - 探索导航、页面结构、用户 flow
5. **设计-代码同步** - 定期对比设计文档和实现，发现不一致

## 🚫 不影响代码库

- ✅ 所有设计文件都在 `design-workspace/` 下
- ✅ 不修改 `web/src/` 下的任何代码
- ✅ 不修改 `web/docs/` 下的设计文档
- ✅ 设计探索完成后，再决定是否将成果合并到主代码库

## 🎨 使用画布的工作流

1. 在设计工作区创建设计文档（Markdown + 设计规范）
2. 使用环境里的画布功能（Visualizer）创建可视化设计
3. 将画布输出保存为设计参考
4. 与实现代码对比，确保设计-代码一致性
