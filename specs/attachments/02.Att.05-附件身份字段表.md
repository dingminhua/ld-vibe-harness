# 附件身份字段表

```yaml
ldvh_attachment:
  attachment_id: "02.Att.05"
  title: "附件身份字段表"
  status: "candidate"
  canonical_path: "specs/attachments/02.Att.05-附件身份字段表.md"
  parent_spec: "specs/02-Specs基础规范.md"
  relation: "authorizes_attachment"
```

> 文件状态：candidate；本文只承载 `ldvh_attachment` 字段闭集。

| 字段 | 必填 | 作用 |
|---|---|---|
| `attachment_id` | 是 | 稳定附件编号 |
| `title` | 是 | 附件标题 |
| `status` | 是 | 当前状态 |
| `canonical_path` | 是 | 当前 Markdown 路径 |
| `parent_spec` | 是 | 授权父规范 |
| `relation` | 是 | 与父规范的关系 |

状态闭集：

| 状态 | 含义 |
|---|---|
| `candidate` | 候选附件 |
| `active` | 随父规范生效的正式附件 |
| `deprecated` | 已废弃或被替代 |
| `archived` | 历史归档 |
