> 文件状态：active；本文只承载 01 授权的 runtime payload 字段最小闭集。跨环境 payload、receipt 和验收输出中的 LDVH canonical event 必须带 `ldvh.` 前缀；表内兼容枚举仍可作为 Code 内部消费时机键使用。

| 字段 | 要求 | 说明 |
|---|---|---|
| `event` | 必填枚举 | 使用 `01.Att.01` 的消费时机闭集作为内部键；跨环境表达必须映射为带 `ldvh.` 前缀的 canonical event。环境 adapter lifecycle payload 对外只应暴露 `ldvh.session_start`、`ldvh.pre_tool_use`、`ldvh.completion_claim` 等带 `ldvh.` 前缀的 LDVH canonical event；未加前缀的内部兼容键仅可在 Code 内部枚举、表格键、adapter 内部映射层或兼容输入解析中使用，不得作为跨环境 payload、receipt、验收卡或 Human-facing lifecycle event 输出。`ldvh.acknowledge_read_plan` 由 LDVH 手动 CLI / validator runtime / receipt bridge 承接，不要求目标环境原生 Hook 支持 |
| `trigger_source` | 必填字符串 | `manual`、`git.commit-msg`、外部 adapter 或环境来源 |
| `session_id` | 可选字符串 | 会话或外部调用标识 |
| `cwd` | 条件字符串 | 环境 Hook、外部 adapter 或无法只靠 `target_path` 判定工作对象时必须填写真实当前工作目录；不得用 LDVH 本体根目录替代外部项目 cwd |
| `config_root` | 条件字符串 | 外部 adapter 已知目标工作区根目录或管辖项目配置根时填写；用于定位 `LDVH-GOVERNED-PROJECTS.yaml`，不得替代 target-first 判定 |
| `target_path` | 条件字符串 | 涉及工作对象、写入、提交或事实源回写时填写 |
| `target_paths` | 条件列表 | 一次操作涉及多个显式 target、staged paths、tool payload 多路径或 adapter 可提取多目标时填写；用于管辖/非管辖混合、多项目和歧义判断 |
| `operation` | 条件枚举 | `read`、`write`、`edit`、`apply_patch`、`commit` 或等价操作 |
| `task` | 条件字符串 | 会话入口或行动指南需要当前任务时填写 |
| `acknowledged_paths` | 条件列表 | 写入前检查需要的已读路径集合 |
| `verification_evidence` | 条件字符串 | 完成声明检查需要的验证证据、未验证范围或残留风险 |
| `source_refs` | 可选列表 | payload 自带来源回指 |

| runtime receipt cache 字段 | 要求 | 说明 |
|---|---|---|
| cache 边界 | 必填 | runtime receipt cache 只用于同一环境会话内桥接 `ldvh.acknowledge_read_plan` 与后续 `ldvh.pre_tool_use`，不是事实源、授权、验证结论、Human Gate 或长期状态，也不是目标环境原生 Hook 事件。cache 文件不得写入项目 repo、`specs/`、`ldvh-base/`、Spark、受管项目或工作树隐藏目录 |
| Linux / Unix desktop 首选目录 | 条件 | `$XDG_RUNTIME_DIR/ldvh/codex-hook/receipts/` |
| Linux / Unix desktop 兜底目录 | 条件 | `$XDG_CACHE_HOME/ldvh/codex-hook/receipts/` 或 `~/.cache/ldvh/codex-hook/receipts/`；runtime 目录优先，cache 兜底必须强制 TTL 清理 |
| macOS 首选目录 | 条件 | `$TMPDIR/ldvh-codex-hook/receipts/` |
| macOS 兜底目录 | 条件 | `~/Library/Caches/LDVH/CodexHook/receipts/`；只放可重建短期 cache，不放 Application Support、Documents、Desktop 或 repo |
| Windows 首选目录 | 条件 | `GetTempPath2` / `GetTempPath` 等价临时目录下私有子目录 |
| Windows 兜底目录 | 条件 | `%LOCALAPPDATA%\LDVH\CodexHook\receipts\`；不用 RoamingAppData；机器级 ProgramData 只允许服务场景并需严格 ACL |
| `schema_version` | 必填整数 | cache schema 版本；不匹配时不得采信 |
| `event` | 必填枚举 | 仅允许 `acknowledge_read_plan` 内部键或等价 `ldvh.acknowledge_read_plan` canonical event |
| `session_id` | 必填字符串 | 与后续 `pre_tool_use` session 匹配；缺失或不匹配不得采信 |
| `workspace_root` | 必填字符串 | 生成 receipt 的 LDVH workspace/root 绝对路径；仅用于匹配和诊断 |
| `workspace_hash` | 必填字符串 | workspace/root 摘要；后续读取必须匹配，避免跨 repo 复用 |
| `trigger_source` | 必填字符串 | 生成 receipt 的触发来源 |
| `acknowledged_paths` | 必填列表 | 已消费的 read_plan 路径；必须至少覆盖 00、01、02；若后续 `ldvh.pre_tool_use` / preflight 已按 target 生成 `required_read_plan`，还必须覆盖该 target-specific required read plan，才可支撑写前检查 |
| `created_at` | 必填时间 | ISO 8601 时间戳 |
| `expires_at` | 必填时间 | ISO 8601 过期时间；过期即删除或不采信 |
| `boundary` | 必填字符串 | 必须声明 cache 不是事实源、授权、验证结论或 Human Gate |
| 默认 TTL | 限制 | 默认 TTL 不得超过 30 分钟；需要更短生命周期时以当前 session / turn 结束为准 |
| 目录权限 | 限制 | Unix-like 目录权限必须为 `0700`，文件权限必须为 `0600`；Windows 必须使用当前用户可读写 ACL |
| 写入方式 | 限制 | 写入必须使用同目录临时文件后原子替换；不得部分写入目标文件 |
| 过期清理 | 限制 | 每次写入或读取 cache 时应顺手清理过期 receipt；不得只依赖操作系统清理 |
| 读取校验 | 限制 | 读取时必须同时校验 schema、event、session、workspace、过期时间和 `acknowledged_paths`；任一不满足时不得采信 |
| 内容最小化 | 限制 | cache 内容必须最小化；不得保存聊天全文、文件正文、完整 transcript、完整 tool payload 或敏感环境变量 |
