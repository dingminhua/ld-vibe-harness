## 1. 定位

本文承载 06 授权的 Codex Hook 事件候选矩阵。

## 2. 候选矩阵

| Hook 事件 | 典型能力意图 | LDVH 使用边界 | 禁止声明 |
|---|---|---|---|
| `SessionStart` | 会话启动或恢复时注入上下文 | 候选承接入口加载和恢复摘要 | 未实测前不得声明稳定加载 |
| `UserPromptSubmit` | Prompt 提交前检查或补充上下文 | 候选承接输入澄清和风险提示 | 不得假定可改写所有用户输入 |
| `PreToolUse` | 工具调用前检查、阻断或改写部分输入 | 候选承接危险命令、路径越界和权限检查 | 不得声明覆盖所有 shell、Web 或非 MCP 工具 |
| `PermissionRequest` | 权限请求前自动决策或交回审批 | 候选承接审批策略辅助 | 不得绕过 Human Gate 或环境审批 |
| `PostToolUse` | 工具调用后审查输出或反馈 | 候选承接校验结果审查 | 不得声明能撤销已发生副作用 |
| `Stop` | 回合停止前决定是否继续 | 候选承接最终验收、失败测试续跑 | 不得替代任务验收事实源 |
| `SubagentStart` | 子 Agent 启动前补上下文 | 候选承接 Agent 输入契约 | 不得声明未验证 Agent 能力 |
| `SubagentStop` | 子 Agent 结束后要求收口或继续 | 候选承接 Agent 输出审查 | 不得让子 Agent 输出直接生效 |
| `PreCompact` | 上下文压缩前处理 | 候选承接压缩火花、Spark / WorkCase / Git 回写提醒 | 不得把压缩火花写成聊天记忆长期事实源 |
| `PostCompact` | 上下文压缩后恢复处理 | 候选承接恢复摘要读取 | 不得声明恢复内容完整或替代事实源 |

## 3. 适配检查

Codex Hook 适配必须同时检查配置层级、项目 trust、命令来源、权限范围、事件覆盖范围和失败输出。未确认当前 Codex App 版本支持时，只能标注候选或待确认。

## 4. 待补齐事项

1. Codex App 当前版本 Hook 返回语义、matcher、权限和失败处理仍需证据复核；
2. Hook 与统一 dispatcher 的接入边界应在 Code 和测试规范中补正反样例。
