## 1. 用途

本附件只承载长表、矩阵和机器可消费元数据，不定义字段原则。字段原则、公共字段语义、采用规则和 Human Gate 归 06。

候选注册列包括：

| 列 | 候选用途 |
|---|---|
| `field_path` | 字段名或重要嵌套路径 |
| `scope` | `common`、具体模型或嵌套结构范围 |
| `meaning` | 字段回答什么问题 |
| `format_kind` | Narrative、Checklist、Evidence、Decision、Reference、Log、Structured 等内容格式 |
| `value_shape` | string、markdown、datetime、object、list_object、list_string 等值形态 |
| `ref_kind` | object_ref、doc_path、commit_ref、url_ref、enum、local_id 等引用类型 |
| `enum_owner` | 枚举归口 |
| `schema_owner` | 结构约束归口 |
| `code_check_kind` | Code 可机械检查维度 |
| `web_render_kind` | Web 派生展示语义 |
| `status` | active、deprecated、removed、alias |
| `replacement` | 废弃、别名或替代关系 |

## 2. 字段矩阵

Code v2 可从 06 和本附件生成“字段 x 模型”矩阵。矩阵用于检查：

1. 模型身份基线是否完整；
2. 采用字段是否已注册；
3. 同名字段语义和值形态是否一致；
4. 必填性和状态条件是否由具体模型声明；
5. 废弃字段是否被新模型继续采用；
6. Code/Web 消费字段是否可回到同一注册来源。
