---
## 1. 本目录解决的问题

本目录用于在不直接修改正式 `docs/specs/04*` 的前提下，按“规范提出落地要求、LDVH 建设或选择能力保障、LDVH 基于平台客观能力清单主动环境投射”的主轴，重写一版 04 系列草案。

本目录内文档只作为后续正式改写的设计稿。正式吸收时，应重新检查 refs、现有 04.06 / 04.07 / 04.08 迁移、42 消费口径和 Code 校验契约。

## 3. 平台口径

本草案使用“平台”口径，不再沿用旧环境分类。当前平台矩阵只覆盖：

1. Trae Work CN；
2. Codex App。

如果后续需要新增 Cursor、OpenCode、Gemini、Zed、Qwen 或其他平台，应由 AI 先基于本草案读取平台 refs、官方资料和当前环境证据，形成平台客观能力清单，再按 `04.03-环境能力清单与投射规范.md` 的字段追加平台列或平台卡片。新增平台不得凭聊天记忆或平台印象直接声明完整支持。

## 4. 草案边界

1. 本目录不是正式规范事实源；
2. 本目录不得直接作为 42 LDVH 落地与检查的通过依据；
3. 正式吸收前必须重新运行文档校验、引用校验和 diff 校验；
4. 正式吸收前应确认 04.06、04.07、04.08 的迁移路径；
5. 正式吸收前应确认 Code 校验是否需要同步更新。
