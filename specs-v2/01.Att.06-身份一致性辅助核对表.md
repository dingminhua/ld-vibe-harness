## 1. 定位

本文承载 01 授权的规范身份与附件身份一致性辅助核对表。

规范身份字段表由 `01.Att.04-规范身份字段表.md` 承载；附件身份字段表由 `01.Att.05-附件身份字段表.md` 承载。本文只维护身份一致性辅助核对项，不得单独增删身份字段、状态值、必要章节、附件授权规则、active 切换规则或 Code 输出 Schema。

## 2. 身份一致性辅助核对表

身份一致性辅助核对至少包括：

| 核对项 | 标准 |
|---|---|
| 文件名一致 | 规范编号或附件编号与文件名一致 |
| 标题一致 | 身份块 `title` 与一级标题一致 |
| 路径一致 | `canonical_path` 与真实路径一致 |
| 日期有效 | 规范身份块中的 `updated` 不早于 `created` |
| 状态闭集 | 规范状态字段属于 `01.Att.04` 闭集；附件状态字段属于 `01.Att.05` 闭集 |
| 父级关系 | `parent_spec`、`relation` 与父规范或附件授权关系一致 |
| 来源边界 | `migration_sources` 和 `active_fact_source` 不被解释为 active 权威 |
| 消费提示 | `code_consumption` 只表达消费类别，不定义 Code 输出 Schema 或命令入口 |

本核对表用于发现身份字段缺失、路径漂移、状态误写和附件授权漂移；核对结论不能替代 01 主文档规定的高影响确认。

## 3. 典型诊断分流

| 诊断 | 分流 |
|---|---|
| 规范身份字段缺失、状态非法或路径不一致 | 回到规范主文件修正，并核对 `01.Att.04` |
| 附件身份字段缺失、状态非法或路径不一致 | 回到附件文件修正，并核对 `01.Att.05` |
| `migration_sources` 或 `active_fact_source` 被解释为 active 权威 | 回到 01 主文档和 07 事实源边界修正 |
| `code_consumption` 被写成输出 Schema 或命令入口 | 回到 04 Code 规范或对应实现域处理 |
