## 3. 双读映射辅助核对表

双读映射辅助核对至少包括：

| 核对项 | 标准 |
|---|---|
| 来源回指 | v2 成员能回指 active v1 成员主文件 |
| 编号一致 | v1/v2 规范编号和成员编号一致或有明确迁移说明 |
| 状态一致 | v1/v2 集合状态一致，或有 Human Gate 记录说明变化 |
| 锚点一致 | 字段契约、状态机和 Human Gate 锚点可回指 |
| 不越界 | 本文未定义 active 切换流程、Code 实现细节或 Human Gate 条件 |

本核对表用于发现 v1-v2 成员身份映射缺口；核对结论不能替代 02 主文档规定的高影响确认。
