```yaml
  attachment_key: "source-reference-enumerations"

  positioning: "承载 type/scope/trigger 枚举闭集与信息作用边界表"
```

> 文件状态：`active`。当前工作树中的本附件及父规范同时满足 `specification-model-foundation` §6.2 和 §11 的其余条件时，在父规范授权范围内进入当前规则源。它只承载父规范已经定义并授权的结构化字段契约，不单独定义规则、Human Gate 或 Stop Conditions，也不表示相应 Code、tests 或入口已经实现。

## 信息作用与消费边界

| 当前信息 | 可以承担的作用 | 不得自动承担的作用 |
|---|---|---|
| 当前规则源中的规范正文与授权附件 | 提供规则含义、适用边界和机器契约 | 不作为项目事实对象或证明具体工作已经完成 |
| 当前事实源文件中的有效内容 | 提供项目当前稳定事实、状态、证据、决策或经验 | 不重新定义事实模型、规则或 Human Gate |
| Human 当前指令 | 约束或授权当次明确范围内的行动和决定 | 不自动成为跨会话项目事实，不替代事实源文件写入、回读与技术验证 |
| 当前文件、环境或外部来源的可观察信息 | 支持当次判断，并作为事实源写入或更新的候选输入 | 不因被观察到就取得长期稳定性或事实源身份 |
| AI、命令、测试、Code、评审和其它工具产生的信息 | 提供候选结论、诊断、验证输入或当前反馈 | 不替代事实源、规则源、Human Gate 或完成声明 |
| 缓存、索引、摘要、聚合和 Web 视图 | 加速定位、压缩上下文或辅助展示 | 不成为第二事实源，不覆盖其输入来源 |
| `LDVH-GOVERNED-PROJECTS.yaml` 和其它明确配置 | 按来源规范作为直接配置输入 | 不因可被 Code 读取而变成项目事实源或规则源 |
| Working Tree、Index、`HEAD` 和 Git history 信息 | 分别说明当前内容、待提交内容和历史版本关系 | 不单独证明语义正确、验证通过、风险已接受或工作完成 |

## type 枚举

| type | 语义 |
|---|---|
| `feat` | 增加或扩展对使用方可观察的能力 |
| `fix` | 修复不符合既有预期或契约的行为 |
| `docs` | 只改变说明、指南或非规则性文档 |
| `style` | 只改变格式、排版或不影响语义的样式 |
| `refactor` | 重组实现而不意图改变外部行为 |
| `perf` | 以可观察性能改进为主要目的 |
| `test` | 只增加或修正测试与测试资产 |
| `build` | 改变构建、打包或依赖生成链 |
| `ci` | 改变持续集成或自动检查配置 |
| `chore` | 不属于其它 type 的维护变化，不得作为混合多个目的的兜底 |
| `release` | 标记对外发布：更新版本号、变更日志与版本声明，并按发布纪律打 tag |
| `revert` | 撤销已识别的既有变化 |

## trigger 枚举

| trigger_key | mechanical | 成立条件 | 必需结构 |
|---|---|---|---|
| `all-commits-minimum-body` | `true` | 形成任何受 03 §9 约束的新 commit | 唯一 `关键变更:` 及至少一个从行首开始的非空 `- ` 列表项 |
| `breaking-marker` | `true` | header 使用 `!` | 在普遍最低 body 之外，唯一 `影响边界:` 及至少一个从行首开始的非空 `- ` 列表项 |
| `high-impact` | `false` | 变化涉及规则边界、公开契约、事实对象、运行时、Code、Web、tests、config 或其它高影响内容 | AI 按实际影响补充动机、影响、验证或风险上下文，不以最低 body 已存在替代充分说明 |
| `insufficient-header` | `false` | 共同目的、验证范围、影响边界、复核处置或风险不能由 header 充分表达 | AI 使用适用的固定小标题补足 header 无法承载的上下文 |
| `project-required` | `false` | 项目正式来源要求更完整的说明 | 按项目正式来源增加与 03 不冲突的正文要求 |

## footer trailer 枚举

提交消息 footer 中允许且受 Git Gate 校验的 trailer token 闭集如下。未列出的 trailer 名称不得出现；出现时按对应取值要求校验。

| trailer | 语义 | 取值要求 | 缺失处置 |
|---|---|---|---|
| `Session-ID` | 本次会话标识 | 非空 string | Git Gate 机械失败 |
| `Agent-ID` | 执行本次变更的 AI 标识 | 非空 string | Git Gate 机械失败 |
| `Host-Environment` | 宿主开发环境标识 | 非空 string | Git Gate 机械失败 |
| `Human-Gate` | Human Gate 授权记录 | 非空 string，指向本次 Human 决定（授权说明或决策提请标识）；仅当提交新增 `specs/<id>-*.md` 独立规范文档或将其 `status` 转为 active 时强制要求 | 命中强制条件时 Git Gate 机械失败；其余情况可选 |
| `Platform-Affected` | 改动是否触及平台相关面 | 非空 string，只允许 `macos`、`windows`、`both` 或 `unaffected`；Index 含平台相关面文件时强制要求 | 命中强制条件时 Git Gate 机械失败；其余情况可选 |
| `Platform-Verified` | 跨平台再验证声明 | 非空 string，只允许 `macos`、`windows`、`both` 或 `none`；Index 含平台相关面文件时强制要求 | 命中强制条件时 Git Gate 机械失败；其余情况可选 |
