## 1. 定位

本文承载 07 授权的 commit scope 允许枚举。

07 正文定义 scope 最多一个、表达主承载域的规则；本文只维护 scope 允许枚举，不得定义 commit type 闭集、body 必填条件、对象字段、Web 页面契约或提交流程。

## 3. 使用规则

`scope` 可选，最多一个，表示名词性的主承载域或最重要的事实源边界。scope 不是文件清单，不要求覆盖所有 touched files。一次提交可以跨多个目录完成同一闭环，但首行只选择主 scope；其它受影响范围、配套实现和文档同步写入 body。

提交首行不得使用本文 §2 表格之外的 scope。没有合适枚举时，应选择最接近的已有 scope 完成本次提交，并在提交后显式告知 Human：当前枚举无法精确覆盖本次主承载域，建议评估是否通过 07 Human Gate 补充本文 scope 枚举和 Web 展示标签。

## 4. 辅助核对表

| 核对项 | 标准 |
|---|---|
| 单主承载 | scope 最多一个 |
| 名词稳定 | scope 是稳定名词，不是动作或文件清单 |
| 不拼接 | 未使用 `web/code`、`specs,code` 或多词拼接 |
| 闭集命中 | 若填写 scope，则命中本文 §2 允许枚举 |
| body 补充 | 其它影响范围写入 body，而不是塞进 scope |
