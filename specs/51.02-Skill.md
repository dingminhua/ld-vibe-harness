## 1. 本文定位

本文是 `specs/51-multi-role-thinking-多角色思考.md` 的附件型实践子文档（编号 51.02），承接 Skill 契约式行动实践。本文不是独立工作流程，不得重新定义多角色思考的行动定位、准入条件、Context、Scenario、Gate、执行流程、事实源回写、证据留存或 Human Gate。发生冲突时，以 51 主文档和上位基础规范为准。

---

## 2. 不创建 LDVH 版 Skill 的理由

多角色思考不需要创建 LDVH 版 Skill，理由如下：

1. **触发判断由 Rules 承接**：进入多角色思考的触发判断由 L0 工作区规则入口摘要提醒，AI 读取 51 主文档后按流程执行，不需要 Skill 作为入口；
2. **执行流程由规范承载**：多角色思考的完整执行流程、角色选择、输出格式和 Human Gate 判断由 51 主文档和 51.06-Contract.md 承载，不需要 Skill 重复承载；
3. **两种模式均不需要 Skill**：主上下文轻量模式由 AI 在主上下文中按角色分析；多角色子 Agent 模式由 Rules 入口触发后，由主控使用当前运行环境提供的可调用 Agent 容器并注入角色参数，两种模式均不依赖 Skill 机制；
4. **避免体系膨胀**：创建 Skill 会增加维护成本但不提升可控性，违反价值与要素审查原则。

---

## 3. 检查项

检查 Skill 不创建决策是否合规时，应确认：

1. 多角色思考的触发判断是否由 Rules 承接，而非 Skill；
2. 多角色思考的执行流程是否由 51 主文档承载，而非 Skill；
3. 主上下文轻量模式和多角色子 Agent 模式是否均不依赖 Skill 机制；
4. 是否未由 Skill 直接触发、编排或启动多角色子 Agent 流程；
5. 是否未创建 LDVH 版多角色思考 Skill。
