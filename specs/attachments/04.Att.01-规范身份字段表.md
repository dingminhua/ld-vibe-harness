# 规范身份字段表

```yaml
ldvh_attachment:
  attachment_id: "04.Att.01"
  title: "规范身份字段表"
  status: "active"
  canonical_path: "specs/attachments/04.Att.01-规范身份字段表.md"
  parent_spec: "specs/04-Specs基础规范.md"
  relation: "authorizes_attachment"
```

> 文件状态：active；本文只承载 `ldvh_spec` 字段闭集。

| 字段 | 必填 | 作用 |
|---|---|---|
| `spec_id` | 是 | 稳定编号 |
| `spec_kind` | 是 | 规范类型 |
| `title` | 是 | 标题 |
| `status` | 是 | 当前状态 |
| `authority` | 是 | 权威状态 |
| `canonical_path` | 是 | 当前 Markdown 路径 |
| `parent_spec` | 否 | 直接父规范 |
| `relation` | 否 | 与父规范的关系 |
| `positioning` | 是 | 本规范定位 |
| `scope` | 是 | 适用范围 |
| `basis` | 是 | 上位依据和来源 |
| `related_specs` | 是 | 显式相关规范或附属材料 |
| `code_consumption` | 是 | Code 可消费结构 |
| `role_sections` | 当前是 | 信息角色到正文章节标题的过渡索引映射；不得覆盖正文规则 |

状态闭集：

| 状态 | 含义 |
|---|---|
| `candidate` | 候选规范 |
| `active` | 正式规范 |
| `deprecated` | 已废弃或被替代 |
| `archived` | 历史归档 |
