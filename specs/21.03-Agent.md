## 一、本文定位

本文是 `specs/21-ADR-决策记录.md` 的附件型实践子文档（编号 21.03），承接 Agent 上下文隔离实践。本文不是独立事实模型，不得重新定义 ADR 的对象定位、准入条件、状态机、对象关系、Human Gate、字段契约、事实源回写或证据留存。发生冲突时，以 21 主文档和上位基础规范为准。

---

## 二、不创建专用 Agent 的理由

ADR 当前不需要创建专用 Agent，理由如下：

1. ADR 创建、升级、推翻和废弃流程可由主上下文读取 21 主文档、21.02-Skill.md、21.04-Tools.md 和 21.06-Contract.md 后执行；
2. ADR 判断需要 Human Gate，专用 Agent 不能替代人类确认；
3. ADR 实例字段、状态校验和受控写入可由 Tools 辅助能力承接，不需要 Agent 独立维护判断逻辑或写入逻辑；
4. 创建专用 Agent 会增加维护成本，但不会提升 ADR 事实源回写的可控性；
5. Tools 已承接 ADR 的确定性读写和校验能力，进一步降低创建专用 Agent 的必要性。

---

## 三、检查项

检查 ADR Agent 不创建决策是否合规时，应确认：

1. 是否未创建 ADR 专用 `.trae/agents/` 实体；
2. ADR 创建、升级、推翻和废弃是否仍由主上下文依据 21 主文档及相关子文档执行；
3. ADR Human Gate 是否未被 Agent 替代；
4. ADR 字段、状态校验和受控写入是否未由 Agent 维护第二套规则；
5. ADR 确定性读写动作是否由 Tools 承接，而不是由 Agent 自行维护写入逻辑。
