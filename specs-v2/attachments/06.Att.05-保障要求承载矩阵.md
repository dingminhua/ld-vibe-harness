## 1. 定位

本文承载 06 授权的保障要求到承载方向的默认矩阵。

## 2. 承载矩阵

| 保障要求 | 默认承载方向 | 常见补充 |
|---|---|---|
| 上位约束承接要求 | Rules、规范引用、Code 引用检查 | Human Gate、ADR、WorkCase |
| 入口可见要求 | Rules、AI 可见摘要、薄引用 | Web 展示、命令提示 |
| 流程复用要求 | 行动编排、Skill、命令包装、人工降级检查 | Code wrapper、Web 表单、WorkCase 模板 |
| 工作流程接管要求 | active 行动编排、成员自描述、Code 派生集合索引 | Skill、Agent、Hook、Code、Web、CI 作为保障手段 |
| 子 Agent 思考要求 | 主控多视角审阅、环境 Agent 能力或人工降级审查 | 已登记 Agent、Human Gate、审阅清单 |
| 确定性执行要求 | Code、测试、CI、命令验证 | Web 展示、命令包装 |
| Human 交互要求 | Human Gate、Web、结构化问询、对话确认 | diff、预览、风险说明 |
| 生命周期触发要求 | CI、命令检查、入口 STOP 点、人工降级检查 | 已登记 Hook、已登记 Skill 提醒 |

## 3. 使用规则

默认矩阵只是保障机制起点和能力类型选择参考，不是具体资产清单、部署状态或行动编排接管事实。

具体保障要求一旦由 active 行动编排接管，执行责任、验证责任、证据位置、Human Gate、缺口分流和能力资产映射应回到对应行动编排主文件及能力资产自身自描述。
