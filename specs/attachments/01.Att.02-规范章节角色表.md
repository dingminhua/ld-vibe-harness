## 章节角色

| 角色 | 常见标题 | 必须性 | Action Guide 消费 |
|---|---|---|---|
| `problem` | 本文解决的问题 | 必须 | 生成目标摘要和负担说明 |
| `basis` | 上位依据 | 必须 | 生成 P0/P1 read_plan 和 relationships |
| `value` | 构成要素归属与价值判断 | 必须 | 生成 impact_judgment |
| `local_rules` | 本地规则 / 对象规则 / 行动规则 | 必须 | 生成本地 delta 和执行边界 |
| `code_consumption` | Code / Action Guide 消费边界 | 条件必需 | 生成验证和投影字段 |
| `human_gate` | Human Gate | 必须 | 生成 stop_conditions |
| `todo` | 待补齐事项 | 必须 | 生成 next_queries |

## 去冗余规则

1. 章节角色稳定比章节标题完全一致更重要；
2. 子规范可以保留统一骨架，但正文只写本地 delta；
3. 通用 doctrine 应由父层规范承载，Code 可以在行动指南中展开；
4. 重复检查清单不应手写到每个子规范，应由 Code 从章节角色和附件契约生成。

## 停止条件

Code 遇到以下情况应输出诊断或 limited guide：

1. 缺少身份块或 H1；
2. 无法识别 `basis`、`value`、`human_gate` 或 `todo` 角色；
3. 章节内容只有父层复述，没有本地 delta；
4. 本地 Human Gate 被删除或无法回指来源。
