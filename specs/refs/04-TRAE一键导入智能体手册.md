# TRAE 一键导入智能体手册

> 日期：2026-05-23
> 来源：Trae 官方文档
> 定位：外部资料引用，不直接成为 LDVH 强制规则

## 概述

针对项目开发中的不同场景，TRAE 提供了一系列可直接导入并使用的自定义智能体示例。这些智能体可以被单独调用；或在开发流程的相应阶段由 SOLO Agent 自动调用，以完成特定任务。同时，这些自定义智能体也可以作为参考模板，你可以根据实际需求调整现有配置。

你可以通过点击下表中相应的链接，将这些智能体快速导入 TRAE 中并使用。

---

## 智能体列表

### 一、UI 设计师（UI Designer）

#### 定位
UI Designer 是一个专业的 UI/UX 设计智能体，用于创建界面、设计组件、搭建设计系统和提升视觉美感。

#### 核心能力
- 可访问性设计
- 用户体验优化
- 组件一致性保障
- 跨平台适配支持

#### 使用场景
- **组件库设计**：设计统一按钮、表单等组件，包含多种状态和变体
- **界面优化**：改善布局和视觉层级，提升可用性
- **设计系统建设**：标准化颜色、排版、间距等设计 token，保证跨产品一致性
- **跨平台适配**：确保界面在不同屏幕和设备上表现一致

#### 一键导入
[点击导入 UI Designer](https://s.trae.com.cn/a/8fdcb7)

---

### 二、前端架构师（Frontend Architect）

#### 定位
Frontend Architect 是一个专业的前端架构智能体，擅长构建高性能、可扩展的前端界面，涵盖 React、Vue 和 Angular 等主流框架。

#### 核心能力
- 响应式设计与可访问性
- 组件架构与生命周期管理
- 状态管理方案选型与实现
- 性能优化与工程质量保障

#### 使用场景
- **界面开发**：实现响应式、可访问的 UI，确保与设计系统一致，并支持动画和交互优化
- **组件架构**：设计可复用、可维护的组件体系，管理生命周期和组件接口
- **状态管理**：处理复杂状态逻辑，选型并实现 Redux、Vuex、NgRx 等状态管理方案
- **性能优化**：通过代码拆分、懒加载、虚拟滚动等技术提升渲染和加载效率
- **前端工程**：配置构建工具、CI/CD、测试体系，确保代码质量、安全性和可维护性

#### 一键导入
[点击导入 Frontend Architect](https://s.trae.com.cn/a/3fbe5a)

### 三、后端架构师（Backend Architect）

#### 定位
Backend Architect 是一个专业的后端架构智能体，擅长设计高性能、可扩展且安全的服务器端系统。

#### 核心能力
- RESTful/GraphQL API 设计
- 业务逻辑与服务层架构
- 数据库设计与查询优化
- 系统性能与安全保障

#### 使用场景
- **API 设计**：设计 RESTful 或 GraphQL 接口，规范请求/响应、认证和版本管理
- **业务逻辑实现**：构建可扩展的服务层，处理复杂业务规则、异步任务和缓存策略
- **数据库架构**：设计高效数据库结构，优化查询性能，选择合适的数据存储方案
- **系统扩展性**：实现负载均衡、自动扩容、高可用和监控告警体系
- **安全运维**：保证认证授权、数据加密、合规性，配置 CI/CD、容器化和基础设施管理

#### 一键导入
[点击导入 Backend Architect](https://s.trae.com.cn/a/441a24)

### 四、API 测试工程师（API Test Pro）

#### 定位
API Test Pro 是一个专业的 API 测试智能体，擅长功能验证、性能测试、负载测试和契约合规检查。

#### 核心能力
- 契约测试与规范验证
- 功能测试与边界分析
- 性能测试与瓶颈识别
- 安全测试与漏洞检测

#### 使用场景
- **契约测试**：验证 API 与 OpenAPI/Swagger 规范一致，确保请求/响应符合设计
- **功能测试**：检测各接口的有效/无效输入处理、边界情况、错误处理和业务逻辑正确性
- **性能测试**：评估接口响应时间、识别瓶颈、验证性能 SLA
- **负载测试**：模拟并发用户、压力场景，检查系统在高负载下的稳定性和降级策略
- **安全测试**：发现常见漏洞，如 SQL 注入、XSS、认证绕过等

#### 一键导入
[点击导入 API Test Pro](https://s.trae.com.cn/a/1ea8bb)

### 五、AI 集成工程师（AI Integration Engineer）

#### 定位
AI Integration Engineer 是一个专业的 AI/ML 集成智能体，擅长将人工智能功能整合到应用中。

#### 核心能力
- 语言模型集成与应用
- 推荐系统设计与实现
- 智能自动化与决策系统
- 模型部署与性能优化

#### 使用场景

- **推荐系统开发**：构建基于协同过滤、内容或混合算法的个性化推荐引擎
- **智能自动化**：实现动态定价、流程自动化或决策系统，结合规则与 ML 预测提升效率
- **模型部署**：容器化部署、蓝绿/金丝雀发布、性能优化和监控
- **数据安全**：设计可扩展数据管道、隐私保护机制、偏差检测与合规性措施

#### 一键导入

### 六、DevOps 工程师（DevOps Architect）

#### 定位
DevOps Architect 是一个专业的 DevOps 智能体，擅长构建自动化基础设施、CI/CD 流水线和监控系统。

#### 核心能力
- CI/CD 流水线设计与实现
- 云基础设施配置与管理
- 系统监控与可观测性
- 部署自动化与安全合规

#### 使用场景
- **CI/CD 流水线**：设计和实现自动化构建、测试和部署，支持回滚与多分支策略
- **云基础设施**：搭建可扩展、高可用、安全的云环境（AWS/Azure/GCP）
- **监控可观测性**：配置系统监控、告警、日志聚合和分布式追踪
- **部署自动化**：实现蓝绿、金丝雀、滚动部署策略，自动化数据库迁移
- **安全合规**：管理权限、密钥、加密和审计，确保符合 SOC2、HIPAA、PCI-DSS 等标准

### 七、性能优化师（Performance Expert）

#### 定位
Performance Expert 是一个专业的性能优化智能体，擅长系统、应用和数据库的性能分析与优化。

#### 核心能力
- 性能测试与基准建立
- 性能分析与瓶颈诊断
- 代码与数据库优化
- 基础设施调优与报告

#### 使用场景
- **性能测试**：设计和执行负载、压力和耐久性测试，建立性能基准
- **性能诊断**：对代码、数据库、前端和基础设施进行多层级分析
- **系统优化**：从应用代码、数据库查询到基础设施配置，提供端到端改进建议
- **代码优化**：改进算法、数据结构、查询效率、缓存策略和 ORM 使用
- **基础设施优化**：调整线程池、容器配置、操作系统参数、负载均衡和 CDN 策略

#### 一键导入
[点击导入 Performance Expert](https://s.trae.com.cn/a/7bb287)

### 八、合规审查员（Compliance Checker）

#### 定位
Compliance Checker 是一个专业的法律合规模拟智能体，擅长审查法律文件、隐私政策和服务条款。

#### 核心能力
- 法律文件审查与分析
- 法规合规评估与建议
- 风险识别与缓解策略
- 最佳实践指导

#### 使用场景
- **文件审查**：检查服务条款、隐私政策等法律文档，识别缺失条款、歧义或过时内容
- **法规合规评估**：根据 GDPR、CCPA、PIPEDA、COPPA 等法规分析文档合规性
- **风险识别**：发现可能带来法律责任的条款、消费者保护问题、知识产权风险
- **最佳实践建议**：提供标准条款示例，优先级整改清单，并给出实施时间表

#### 一键导入
[点击导入 Compliance Checker](https://s.trae.com.cn/a/7a3bf7)

## 导入方法

1. 点击上表中的「点击导入」链接
2. 根据浏览器引导打开 TRAE IDE
3. TRAE IDE 中弹出智能体信息展示窗口
4. 点击「立即获取」按钮完成导入

---

## 智能体使用提示

### 单独调用
在 AI 对话输入框中输入 `@`，然后在智能体列表中选择你想用的智能体。

### SOLO Agent 自动调用
SOLO Agent 在处理复杂任务时，会自动识别并调用相应的专业智能体来完成特定阶段的任务。

### 自定义修改
导入的智能体可以作为参考模板，你可以根据实际需求调整配置，包括：
- 修改提示词（Prompt）
- 调整工具权限
- 更新触发条件
