| 入口类型 | 判定条件 | 当前示例 |
|---|---|---|
| `automated_hook` | 环境真实自动触发、失败可阻断、安装与接入证据可复核的通用自动入口 | `git.commit-msg` |
| `git_hook_shim` | 安装在具体 Git repo 中的 Git Hook shim，只调用 LDVH，不承载规则本体 | `git.commit-msg` shim |
| `hook_protocol_entry` | LDVH 仓库 `hooks/` 下的 Runtime Protocol 可见入口，只写入口身份、权威回指和当前 Code 入口；不写接入判定分类，不证明自动触发 | `hooks/LDVH-RUNTIME-PROTOCOL.md` |
| `environment_hook` | AI 环境、编辑器、Agent 平台或插件生命周期事件入口，只指向 LDVH runtime / adapter；LDVH 仅支持具备可安装、可验证、可阻断 AI lifecycle Hook 的协作环境，正式环境入口必须由对应 LDVH 插件、扩展包或 package 承载 | 目标环境 LDVH 插件的 lifecycle hook；Codex 目标环境下的 `SessionStart`、`PreToolUse`、`Stop` hook |
| `external_adapter_candidate` | 可被外部环境、插件、扩展包或 package 接入，但缺真实触发、安装、失败处理或回滚证据 | `runtime.adapter.auto`、`environment.ldvh-plugin`、目标环境专属 `*.ldvh-plugin` |
| `removed_top_level` | V3 已取消的顶层机制，只保留 legacy 或外部包装候选身份 | `rules.top_level_mechanism`、`skills.top_level_mechanism` |
| `absent` | 未发现可识别入口、资产或候选文件 | 空 |
