## 1. 定位

本文承载 04 授权的 Code 通用结构化输出字段。

## 2. 通用字段

| 字段 | 含义 |
|---|---|
| `tool` | 工具或命令名称 |
| `schema_version` | 输出 Schema 版本 |
| `generated_at` | 生成时间 |
| `input_scope` | 输入范围 |
| `project_namespace` | 项目命名空间 |
| `degraded` | legacy 兼容标记，不作为 active 正式问题概念 |
| `diagnostics` | 诊断列表 |
| `source_refs` | 来源回指 |
| `data` | 命令主体结果 |

Hook dispatcher 类输出应在适用时包含 `cwd`、`target_paths`、`target_resolutions`、`governed_subject`、`governed_via`、`governed_project_id`、`governed_project_path`、`blocked`、`required_paths` 和 `next_action`。`target_resolutions` 应逐 target 记录 normalized path、Git common-dir、project_id、governance status、source 和 unknown reason，用于审计多目标、worktree 和混合目标写入边界。

dispatcher receipt 输出增强字段（06 runtime extension 范畴，服务于 AI 运行时行动感知，不属于 04.Att.06 知识地图投影核心 Schema）：

| 字段 | 含义 | 输出时机 |
|---|---|---|
| `attention_points` | 3-5 条中文项目健康提醒（pending 工作对象、diagnostics、receipt 状态） | session-start |
| `tool_plan` | 基于 task_type/action_hint 的建议 CLI 命令列表 | session-start、acknowledge-read-plan |
| `skill_plan` | 匹配 trigger_conditions 的建议 Skill ID 列表 | pre-tool-use、acknowledge-read-plan、session-start |
| `skill_plan_hint` | skill_plan 非空时的中文指引"读取 skills/<id>/SKILL.md" | 与 skill_plan 同时输出 |
| `post_read_action` | 确定性模板字符串，基于 task_type 给出读后行动建议 | acknowledge-read-plan |
| `deep_read_plan` | acknowledge 阶段展开 next_queries 后的深层读取计划 | acknowledge-read-plan |

## 3. 使用规则

具体命令可以输出字段子集，但必须能说明哪些字段未实现、问题原因、来源回指是否完整。`v2-check` 当前输出 active specs 诊断和只读知识地图预览子集，不得伪装成所有 Code 命令统一 Schema 或完整知识地图运行时已经完成。
