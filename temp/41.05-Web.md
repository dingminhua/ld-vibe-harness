## 一、本文定位

本文是 `specs/41-multi-role-thinking-多角色思考.md` 的附件型实践子文档（编号 41.05），承接 Web 呈现实践。本文不是独立行动模型，不得重新定义多角色思考的行动定位、准入条件、Context、Scenario、Gate、执行流程、事实源回写、证据留存或 Human Gate。发生冲突时，以 41 主文档和上位基础规范为准。

---

## 二、不创建 Web 呈现的理由

多角色思考不需要创建 Web 呈现，理由如下：

1. **输出在对话中呈现即可**：多角色思考的角色结论、分歧点、风险汇总、回写建议和 Human Gate 待确认项，均以 Markdown 格式在对话中直接呈现，不需要 Web 页面承载；
2. **Human Gate 在对话中确认**：多角色思考的 Human Gate 通过对话暂停并请求用户确认，不需要 Web UI 作为确认入口；
3. **两种模式均不需要 Web**：主上下文轻量模式在对话中按角色分析并汇总；多系统子 Agent 模式由主控汇总后输出到对话，两种模式均不依赖 Web 基础设施；
4. **避免体系膨胀**：创建 Web 呈现会增加基础设施依赖和维护成本，但不提升多角色思考的可控性，违反价值与要素审查原则。
