## 一、本文定位

本文定义多角色思考行动模型在 Skill 层的执行内容。Skill 可以作为多角色思考的轻量执行入口，用于承接可复用、标准化、可在主上下文完成的多角色分析流程。

本文不创建 Skill 实体，不修改 `/Users/dmh2002/trae_projects/.trae/skills/pm-kit-multi-role-analysis`，不直接迁移 Skill。创建、重命名、迁移或替换 Skill 实体必须另行评估 Human Gate。

---

## 二、Skill 准入

多角色思考 Skill 只有在满足以下条件时才应创建或启用：

1. 41 主行动模型已稳定；
2. Skill 只承接轻量模式或标准化报告输出；
3. Skill 可在主上下文中执行；
4. Skill 不调度 Agent；
5. Skill 输出不作为最终事实源；
6. Skill 的输入、输出和回写建议明确；
7. Skill 命名和部署符合 `specs/04.02-Skill机制规范.md`。

---

## 三、命名与部署建议

若未来创建 LDVH 版多角色思考 Skill，建议：

| 项目 | 建议 |
|---|---|
| 目录名 | `.trae/skills/ldvh-multi-role-thinking/` |
| YAML `name` | `ldvh-multi-role-thinking` |
| 定位 | 多角色思考行动的轻量执行入口 |
| 部署位置 | 工作区顶层 `.trae/skills/` |
| 维护状态 | planned，待 Human Gate 确认后创建 |

早期 `pm-kit-multi-role-analysis` 只作为迁移参考，不作为 LDVH 版 Skill 的权威定义。

---

## 四、输入要求

Skill 输入至少应包含：

1. 分析主题；
2. 用户目标和约束；
3. 相关文件、对象或事实源路径；
4. 期望输出深度；
5. 是否允许建议 Agent 增强；
6. 是否需要判断事实源回写。

若输入不足，Skill 应要求主控或用户补充，不得自行猜测关键事实。

---

## 五、执行流程

多角色思考 Skill 的建议执行流程：

1. 判断是否满足多角色思考准入；
2. 读取 41 主行动模型和必要事实源；
3. 判断是否适合 Skill 辅助模式；
4. 识别变更类型；
5. 选择 3-8 个相关角色；
6. 按角色分别分析影响范围、结论、风险和建议动作；
7. 汇总一致结论、分歧、风险和执行顺序；
8. 判断是否建议 Agent 增强；
9. 判断是否触发 Human Gate；
10. 输出事实源回写建议。

Skill 发现主上下文难以承载、需要结论隔离、并行委派或不同权限边界时，只能建议使用 Agent 增强模式，不得自行调度 Agent。

---

## 六、输出格式

Skill 输出应遵循 41 主文件的多角色思考报告结构，并额外声明：

1. Skill 输入来源；
2. 读取的事实源；
3. 当前模式为 Skill 辅助模式；
4. 是否建议 Agent 增强；
5. 哪些结论只是建议；
6. 哪些内容需要回写才成为稳定事实；
7. 是否触发 Human Gate；
8. 若发生写入，是否需要 Change 记录。

---

## 七、迁移方案

从早期 `pm-kit-multi-role-analysis` 迁移到 LDVH Skill 时，应按以下步骤处理：

1. 比对早期 Skill 与 41 主行动模型；
2. 删除或改写绑定 PM Kit 旧路径、旧术语和旧事实源的内容；
3. 将角色矩阵定位为参考输入，不作为 LDVH 当前权威规则；
4. 使用 `ldvh-` 前缀重新命名；
5. 明确 Skill 不调度 Agent；
6. 明确 Skill 输出不是事实源；
7. 经 Human Gate 确认后创建 Skill 实体；
8. 创建后记录 Change。

迁移不得直接覆盖早期 Skill，除非用户明确要求并确认影响范围。

---

## 八、Human Gate

以下情况必须暂停确认：

1. 创建 LDVH 版多角色思考 Skill；
2. 修改、删除、重命名或替换早期 Skill；
3. 改变 Skill 部署位置或命名前缀；
4. 允许 Skill 调度 Agent；
5. 将 Skill 输出提升为稳定事实；
6. 让 Skill 修改规则、Agent、跨项目契约或高影响资产。

---

## 九、检查要求

| 检查项 | 标准 |
|---|---|
| 准入 | Skill 只承接轻量、可复用、主上下文可执行流程 |
| 命名 | 使用 `ldvh-` 前缀 |
| 边界 | 不替代 41 主行动模型 |
| Agent | 不调度 Agent，只建议升级 |
| 输出 | 明确事实、建议、回写和 Human Gate |
| 迁移 | 早期 PM Kit 内容未直接成为 LDVH 规则 |
| Change | Skill 实体变更已记录 Change |

---

## 十、待补齐事项

3. Skill 与程序辅助报告校验的衔接待 `41.04-程序.md` 定义。
