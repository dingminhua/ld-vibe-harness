## 1. 定位

本文承载 02 授权的字段 x 模型矩阵诊断目标、判断标准和辅助核对表。

02 正文定义字段契约原则、字段注册边界和具体模型采用规则；`attachments/02.Att.01-字段注册表.md` 承载字段注册表。本文只能维护字段矩阵诊断对象，不得单独定义字段注册表本体、具体模型字段存在性、必填性、状态条件、关闭条件、完整 schema、事实源边界、Code 输出 Schema 或 Web 页面契约。

## 2. 字段矩阵诊断目标

Code 和人工降级检查可以依据 02 正文、字段注册表和具体事实模型字段契约生成字段 x 模型矩阵。矩阵只用于诊断和最小读取，不替代具体模型字段契约。

字段矩阵至少用于发现：

| 诊断目标 | 判断标准 |
|---|---|
| 基线字段缺失 | 每个具体事实模型是否声明 `id`、`type`、`title`、`status`、`created`、`updated` |
| 未注册字段 | 具体模型采用字段是否能回到公共字段、模型特有字段或注册项 |
| 同名漂移 | 同名字段是否出现公共语义、值形态或消费方式冲突 |
| 必填性缺失 | 具体模型是否声明字段必填性和状态条件 |
| 废弃字段复用 | `deprecated`、`removed` 或 `alias` 字段是否被新模型继续作为写入入口 |
| 消费回指缺失 | Code/Web/知识地图消费字段是否能回到同一注册来源和具体模型字段契约 |
| 注册表越界 | 注册表是否被错误用于反推具体模型字段存在性、状态条件或完整 schema |

## 3. 字段矩阵辅助核对表

字段矩阵辅助核对至少包括：

| 核对项 | 标准 |
|---|---|
| 来源回指 | 矩阵诊断能回指 02、字段注册表和具体模型字段契约 |
| 不替代契约 | 未把矩阵结果写成字段存在性、必填性或状态条件的权威来源 |
| 清退联动 | 废弃字段复用诊断能回指 `02.Att.07` 或字段注册表生命周期状态 |
| 消费边界 | 未定义 Code 输出 Schema、Web 页面契约或运行时适配方式 |

本核对表用于发现字段矩阵越界、来源缺失和诊断漂移；核对结论不能替代 02 主文档规定的高影响确认。
