# V4 Code 与 tests 存量膨胀后续问题

> 记录性质：本文只记录一个待独立调查的问题，不是规则源、审计登记或当前实施计划。
> 记录日期：2026-07-16。

## 问题

当前存量 Code/tests 已出现规模、重复模式和维护负担信号，需要在独立后续事项中判断模块责任、重复测试、失败价值、读取成本和可安全收敛范围。

## 本轮边界

本轮不展开存量 Code/tests 审计、重构或批量删改，只保留与规范语义越权直接相关且具有独立失败价值的最小新增测试，并修复全量测试暴露的日期夹具缺陷。生产 Code 继续保持不变。

后续处理必须另行确认范围，先建立存量基线和来源边界，再区分真正重复、独立失败覆盖与必要集成证据；不得用文件数量、行数或表面相似直接决定删除或重构。
