## 1. 定位

本文承载 08 授权的测试证据边界清单。

## 2. 边界清单

| 内容 | 可以作为 | 不得作为 |
|---|---|---|
| 测试代码 | 验证实现行为的可执行入口 | 规范规则、字段契约、状态机 |
| 测试夹具 | 最小输入样例 | 事实模型样例的唯一来源 |
| 命令输出 | 验证证据或诊断线索 | 稳定事实源本体 |
| 覆盖率 | 覆盖情况参考 | 质量完成结论 |
| 截图、浏览器 trace | Web 观察证据 | Web 页面事实源或 Human Gate 记录 |
| Mock 数据 | 边界样例或失败复现输入 | 真实对象事实源 |
| 缓存、构建产物、临时报告 | 过程产物 | 规范、对象或 Git 记录 |
| Human 验收记录 | 授权和确认的证据 | 测试自动通过证明 |

## 3. 回指要求

测试证据应能回指测试入口、输入范围、关键样例、关键输出、命令退出状态、Human 验收记录或对应事实源。无法回指时，只能作为诊断线索，不得作为关闭、验收或事实源回写依据。
