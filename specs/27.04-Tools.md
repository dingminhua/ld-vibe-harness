> 关系：事实模型附件型实践子文档

## 1. 本文定位

本文是 `specs/27-Task-任务.md` 的附件型实践子文档，记录 Task 事实模型当前由通用 PyTools 承接的校验、创建、状态流转和删除能力。本文不是独立事实模型，不重新定义 Task 字段契约、状态机语义、Human Gate、关闭条件或子任务规则。

Task 的字段、状态、文件命名、引用关系和消费者接口以 `specs/27.06-Contract.md` 为权威位置；Task 行为规则以 `specs/27.01-Rules.md` 为权威位置。

## 2. Tools 实体

| Tools 实体 | 能力 | Contract 来源 | 测试入口 |
|---|---|---|---|
| `tools/ldvh_fact_validate.py` | 校验 Task YAML 文件命名、ID、type、status、必填字段、列表字段、closed 条件必填 | `specs/27.06-Contract.md` | `python3 -m pytest tests/tools/test_check_fact_model.py` |
| `tools/ldvh_fact_cli.py` | 创建 Task、执行合法状态流转、删除允许删除的 Task | `specs/27.06-Contract.md`、`specs/27.01-Rules.md` | `python3 -m pytest tests/tools/test_fact_model_cli.py` |

## 3. 消费关系

| 消费项 | `ldvh_fact_validate.py` | `ldvh_fact_cli.py` |
|---|---|---|
| 对象类型 | 识别 `task` | 支持 `task` create / transition / delete |
| 文件命名 | 校验 `task-{NNNN}-short-title.yaml` | 创建时生成符合命名规则的文件 |
| ID 格式 | 校验 `task-{NNNN}` | 创建时递增生成 `task-{NNNN}` |
| 状态枚举 | 校验 Task 标准状态 | 校验目标状态合法性 |
| 状态流转 | 不执行流转 | 校验合法流转矩阵 |
| 必填字段 | 校验 `id`、`type`、`title`、`status`、`created`、`updated`、`description`、`source`、`acceptance` | 创建时校验必填字段输入 |
| 条件必填 | 校验 `closed_at`、`closure_evidence` | 关闭时校验 acceptance 全勾选和 closure_evidence |
| 引用关系 | 当前仅做列表字段类型校验，深度引用校验待补齐 | 当前不执行跨对象引用完整性校验 |

## 4. 同步要求

以下变化发生时，必须同步检查 Task Tools 实现和测试：

1. `specs/27.06-Contract.md` 修改字段、状态枚举、文件命名、条件必填或状态流转矩阵；
2. `specs/27.01-Rules.md` 修改关闭条件、Human Gate 场景、子任务深度限制或状态变更规则；
3. `tools/ldvh_fact_validate.py` 修改 Task 校验范围、错误代码、输出格式或 exit code；
4. `tools/ldvh_fact_cli.py` 修改 Task 创建、状态流转、删除或写入前校验行为；
5. Web 或 Skill 新增依赖 Task Tools 的受控写入能力。

## 5. 测试与验证

Task Tools 变更后至少运行：

```bash
python3 -m pytest tests/tools/test_check_fact_model.py tests/tools/test_fact_model_cli.py -q
python3 tools/ldvh_fact_validate.py ldvh-base/
```

若本轮变更只修改 Contract 或 Tools 子文档、未修改 PyTools 实现，仍应运行上述命令确认现有消费关系未失效。

## 6. 待补齐事项

1. Fact Validator 待补齐 `source_intent`、`parent_task`、`sub_tasks`、`related_adrs`、`related_changes` 的跨对象引用校验；
2. Gate Detector 待补齐 Task 状态流转 Human Gate 判断；
3. PyTools 文件命名待按 `specs/12.01-Tools辅助规范.md` 统一命名规则迁移，并保留兼容 wrapper。
