## 2. 回归入口

| 入口 | 用途 | 边界 |
|---|---|---|
| `npm run test:code` | LDVH Code 当前日常完整测试入口 | 必须同时覆盖 `tests/code` 自动化测试和 `python3 code/specs_validate.py all --fail-on-diagnostics` |
| `python3 -m pytest -q tests/code` | Code 单元/集成测试 | 不替代 specs 全量校验 |
| `python3 code/specs_validate.py all --fail-on-diagnostics ...` | active specs 综合校验 | 当前默认读取 active `specs/` |
| `python3 code/specs_validate.py v2-check --fail-on-diagnostics --format text` | active specs 诊断和只读知识地图预览 | 不替代完整运行时知识地图能力 |
| `python3 code/specs_validate.py knowledge-map --format text` | active specs 知识地图只读投影专项回归 | 只验证默认输入范围投影，不覆盖管辖项目或 raw 原文层 |
| `python3 code/specs_validate.py v2-check --input-scope runtime_extensions --fail-on-diagnostics --format text` | 固定运行时扩展自描述只读投影回归 | 不替代 active specs 默认诊断，不写入缓存，不决定 Rules 正文如何修改 |
| `python3 code/specs_validate.py capability-environment --format text` | 固定能力资产与环境保障矩阵回归 | 只验证固定资产到环境落地边界的只读矩阵；不写入环境入口，不声明环境已安装 |
| `python3 code/specs_validate.py knowledge-map --input-scope governed_projects --format text` | 管辖项目事实对象图谱投影回归 | 输出可能暴露事实对象缺失引用诊断；不修改 `LDVH-GOVERNED-PROJECTS.yaml`、`ldvh-base/` 或项目 docs |
| `python3 code/specs_validate.py knowledge-map --layer raw --start-node <node> --format text` | raw 原文片段层回归 | 只返回受控片段，不作为全文事实源缓存 |
| `python3 -m pytest -q tests/code/specs_validate_checks/test_preflight.py` | 受控写入 preflight 专项测试，覆盖 Rules 入口同步审查提示 | 不替代完整 Code 回归或事实源写入授权；Rules 同步提示不授权自动修改 Rules |
| `python3 -m pytest -q tests/code/test_hook_dispatch.py` | LDVH Hook dispatcher 回归 | 覆盖 target-first 管辖判定、Hook/Rules parity、unknown target 写入阻断、worktree/Git identity 和 read_plan 门禁；不替代完整 Code 回归 |
| `python3 -m pytest -q tests/code/specs_validate_checks/test_v2.py tests/code/specs_validate_checks/test_preflight.py tests/code/specs_validate_checks/test_deployment_entries.py tests/code/specs_validate_checks/test_capability_environment.py` | 知识地图 active specs、runtime_extensions、governed_projects、raw、preflight 字段归口和 Rules 入口同步审查提示、固定运行时扩展登记和能力环境矩阵联合回归 | 不替代完整 Code 回归 |
| `git diff --check` | 空白和补丁格式检查 | 不验证业务规则 |

## 3. 使用规则

只跑局部测试时，必须说明残留风险。不得用 `python3 -m pytest -q tests/code`、`v2-check`、`runtime_extensions` 范围或 `git diff --check` 静默替代 `npm run test:code` 的完整入口语义。`v2-check` 通过只说明 active specs 结构诊断和当前只读知识地图预览无诊断；`runtime_extensions` 范围通过只说明固定运行时扩展自描述投影无诊断；二者均不等于完整知识地图运行时、Web 接入或 Git 原生命令历史追溯已经完成。Git 历史追溯使用 Git 原生命令，不属于 `v2-check` 覆盖范围。
