## 1. 定位

本文承载 08 授权的等价验证适用边界。

## 2. 适用表

| 场景 | 可用等价验证 | 最低说明 |
|---|---|---|
| 自动化测试暂不可行 | 最小样例、人工检查、现有工具输出 | 为什么不可自动化、替代步骤、残留风险 |
| Web 浏览器流程暂不可运行 | API contract、组件静态检查、截图说明或人工降级检查 | 未覆盖的交互、浏览器限制、后续补齐位置 |
| 环境依赖缺失 | 本地可复现子集、配置检查或只读诊断 | 缺失环境、影响范围、不能证明的内容 |
| active specs 只读诊断 | `v2-check` 只读诊断、原文审查、关系回指 | 不替代完整运行时知识地图能力、Web 接入验证或 Git 原生命令历史追溯 |
| 高影响 Human 判断 | Human Gate 记录、影响范围说明、候选方案对比 | Human 是否已确认、确认对象和约束 |

## 3. 禁止写法

以下写法不得用于等价验证结论：

1. “看起来没问题”；
2. “应该通过”；
3. “未运行但等同通过”；
4. “只检查了局部，所以整体完成”；
5. “工具无报错，所以 Human 已确认”。
