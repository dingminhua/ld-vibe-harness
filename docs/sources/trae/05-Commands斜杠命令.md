# Trae Commands 斜杠命令

> 定位：外部资料引用，不直接成为 LDVH 强制规则

## 1. 结论摘要

Trae Commands（斜杠命令）是一种快捷方式，用于在对话中快速执行重复性任务。通过自定义命令可将常用 Prompt 封装、规范输出格式、自动化常见开发流程。内置命令包括 `/plan`、`/spec`、`/browser_use`。自定义命令通过命令名称、描述和说明三个字段定义，可与 `#File`、`#Folder`、`#Rule` 等上下文工具组合使用实现精准任务执行。SOLO 独立端支持本地/云端运行环境区分，命令与技能在同一管理面板统一管理。

## 2. 官方定位

命令是一种快捷方式，用于在对话中快速执行重复性任务。通过创建自定义命令，可以将常用的指令或操作封装起来，从而简化工作流程，提高与 AI 协作的效率。

## 3. 使用场景

- **复用常用 Prompt**：将经常使用的提示词封装为命令，避免重复输入（如总结 PR 变更、生成文档摘要、整理会议记录）
- **规范输出格式**：通过命令固定 AI 的输出结构或模板，确保生成内容符合团队规范（如 Conventional Commits 规范的 commit message）
- **自动化常见开发流程**：将多步骤或复杂的指令封装为一个命令，一次触发即可执行（如代码审查、性能分析、安全检查）

## 4. 内置命令

| 命令 | 描述 |
|---|---|
| /plan | 调用计划模式 |
| /spec | 调用规范模式 |
| /browser_use | 使用 browser_use 工具操作内置浏览器，获取上下文，辅助智能体进行功能验证 |

## 5. 自定义命令配置字段

| 字段 | 描述 | 示例 |
|---|---|---|
| 命令名称 / Command Name | 命令的唯一标识，用于在对话中触发该命令。仅支持小写字母、数字和短横线（-） | summarize-pr-info |
| 描述 / Description | 对命令用途的简要说明 | 总结 PR 信息 |
| 说明 / Instructions | 定义触发命令时 AI 应执行的具体操作。建议清晰描述执行步骤、上下文来源以及输出内容 | 查看当前 Pull Request 的代码变更内容，对比修改前后的代码，并总结本次 PR 的主要变更 |

## 6. 使用命令

在对话框中，输入 `/` 或点击左下方的命令图标，然后从菜单中选择一个命令。输入与该命令作用相关的指令后发起对话即可。

## 7. 上下文工具

命令可结合以下上下文工具使用，为 AI 提供更精准的信息：

| 工具 | 描述 |
|---|---|
| #File | 引用项目中特定文件作为上下文 |
| #Folder | 引用项目中特定文件夹作为上下文 |
| #Doc | 引用文档集作为上下文 |
| #Problems | 引用当前工作区的报错信息作为上下文 |
| #Web | 将线上网页内容作为上下文 |
| #Code | 将函数或类的相关代码作为上下文 |
| #Workspace | 引用整个工作空间作为上下文 |
| #Rule | 引用规则文件作为上下文 |
| #PastChats | 引用历史对话作为上下文 |

## 8. 命令与上下文组合模式

命令可与上下文工具组合使用，实现更精准的任务执行。例如：

- `/spec` + `#File config.yaml` — 对指定文件执行规范工作流
- `/plan` + `#Folder src/` — 对指定目录制定计划
- 自定义命令 + `#Web` — 结合网页内容执行命令

## 9. 命令的运行环境

| 环境类型 | 适用任务 | 适用客户端 |
|---|---|---|
| 本地 | 仅对本地任务生效 | SOLO 桌面版 |
| 云端 | 仅对云端任务（及从 GitHub 拉取的项目）生效 | SOLO 网页版、桌面版 |

## 10. SOLO 独立端特性

- 创建自定义命令时，桌面版可选择命令的运行环境（本地 / 云端）
- 进入命令管理面板的方式：头像 > 设置 > 命令，或对话框内点击命令图标 > 管理技能与命令
- 命令与技能在同一管理面板中统一管理
