## 1. 结论摘要

Trae Agent 是面向不同开发场景的编程助手，支持内置智能体和自定义智能体。智能体具备自主运行、完整工具访问权限、上下文理解和多步骤规划能力，工作流涵盖需求分析、代码调研、方案设计、实施变更和交付验收五个阶段。内置智能体包括 Chat、Agent 和 SOLO Agent，其中 SOLO Agent 支持多智能体编排协同工作和 Plan/Spec 两种规划模式。自定义智能体可配置提示词、工具集，并支持被其他智能体调用。

## 2. 官方定位

智能体（Agent）是面向不同开发场景的编程助手。Trae 提供内置智能体，同时支持创建自定义智能体，通过灵活配置提示词和工具集，使其更高效地完成复杂任务。

## 3. 智能体能力

- **自主运行**：独立探索代码库，识别相关文件并进行必要修改
- **完整的工具访问权限**：使用所有可用工具进行搜索、编辑、创建文件及运行终端命令
- **上下文理解**：建立对项目结构和依赖关系的全面理解
- **多步骤规划**：将复杂任务拆分为可执行步骤，并按顺序逐一处理

## 4. 智能体工作流

1. **需求分析**：深入理解任务目标及代码库上下文
2. **代码调研**：检索代码库、文档及网络资源，定位相关文件并分析现有实现
3. **方案设计**：根据分析结果拆解任务步骤，动态优化调整修改策略
4. **实施变更**：按计划进行代码变更，可能涉及新增依赖、执行终端指令、手动操作指引
5. **交付验收**：完成验证后移交控制权，同步汇总所有修改内容

## 5. 内置智能体

| 智能体 | 描述 |
|---|---|
| Chat | 快速响应用户的各类技术咨询和问题解答 |
| Agent | 从 0 到 1 开发完整项目，调用分析代码、编辑代码、运行命令等工具。所有 MCP Server 默认添加至 Agent，可在编辑页面启用或禁用 |
| SOLO Agent | 面向复杂项目开发的智能体，支持智能任务规划与精准执行、多智能体编排协同工作 |

## 6. 自定义智能体配置字段

| 参数 | 说明 |
|---|---|
| 头像 | （可选）上传图片作为智能体头像 |
| 名称 | 输入智能体名称 |
| 提示词 | 规范和指导智能体完成任务的方式，可规定人设、回答口吻、工作流程、工具使用时机和需遵守的规范 |
| 可被其他智能体调用 | 开启后可被其他智能体调用完成模块化任务，被调用时拥有独立上下文。需配置：英文标识名（唯一英文标识，如 `project-analyzer`）、何时调用（描述调用场景和时机）。目前仅 SOLO Agent 可调用自定义智能体 |
| 工具 | 配置可调用的工具，包括 MCP Server 和内置工具 |

## 7. 内置工具

| 工具 | 描述 |
|---|---|
| 阅读 | 对文件进行检索和查看 |
| 文件系统 | 对文件进行增删改查 |
| 终端 | 在终端运行命令，并获取运行状态和结果 |
| 联网搜索 | 搜索和用户任务相关的网页内容 |
| 预览 | 在生成可预览的前端结果后提供预览入口 |

## 8. 创建方式

1. **智能生成（推荐）**：在创建智能体面板点击"智能生成"，描述功能、使用场景、使用时机，系统自动生成智能体，然后按需修改参数
2. **手动创建**：依次配置头像、名称、提示词、可被其他智能体调用、工具等参数

## 9. 使用方式

在 AI 对话输入框中输入 `@` 或点击 `@智能体`，然后在智能体列表中选择目标智能体。

## 10. 分享与导入

- **分享**：直接通过 Trae IDE 将自定义智能体分享至掘金社区，或复制链接分享至更多渠道。分享前建议对提示词和 MCP Server 配置进行脱敏
- **导入**：点击他人分享的链接，浏览器引导打开 Trae IDE，点击"立即获取"导入智能体配置

## 11. SOLO Agent 特性

SOLO Agent 是面向复杂项目开发的智能体，具有以下特性：

### 11.1 任务规划与执行

- 确认计划后自动推进开发进度
- 可为 SOLO Agent 配置可调用的自定义智能体、MCP Server 和内置工具

### 11.2 多智能体编排

- SOLO Agent 作为主控智能体，可自动调用自定义智能体，将任务拆分与隔离
- 不同智能体在独立上下文中专注处理各自任务，提升执行效率与结果质量
- 内置 Search 智能体用于检索和查看文件，帮助 SOLO Agent 更精准地自动调用其他智能体
- 也可在提示词中明确指定需调用的智能体

### 11.3 Plan 模式

适用于中小型功能开发和模块级重构。SOLO Agent 收到需求后分析并规划任务，生成规划文档，待确认后一一执行。若计划不符合预期，可手动编辑或发送修改需求。

启用方式：对话输入框输入 `/`，选择 `/Plan`。

### 11.4 Spec 模式

面向更复杂的系统级任务。SOLO Agent 根据需求生成三阶段文档组：

- **大纲**（spec.md）
- **任务列表**（tasks.md）
- **验收清单**（checklist.md）

文档存储在项目根目录下 `.trae/specs/` 目录中，按任务名称分组。首次创建时暂停执行等待确认，确认后任务列表和验收清单随执行进度自动更新。

适用场景：从零搭建新系统/模块、大规模重构、多人协作项目、高质量/高稳定性项目开发、需长期维护的项目。

启用方式：对话输入框输入 `/`，选择 `/Spec`。
