> 文件状态：`active`。当前工作树中的本附件及父规范同时满足 `specification-model-foundation` §6.2 和 §11 的其余条件时，在父规范授权范围内进入当前规则源。本附件只承载 08 §5.5 已定义的 Web 内容预览结构；不定义 FileAsset 字段、事实状态、Helper 精确读取、下载、编辑、执行或内容证明能力。

## 适用边界

本附件只适用于 Web 在次级阅读面板中按需预览当前所选管辖项目内一个 `active` FileAsset 的固定 `payload`。对象列表和详情 API 继续只返回 manifest 元数据，不得为方便前端把 payload bytes、data URL、本地绝对路径或临时文件路径加入对象 DTO。

预览成立只表示：Web 在当次读取中取得一个稳定普通 payload，实际长度与 SHA-256 精确匹配 manifest，并且内容通过本附件对相应预览类别的确定性检查。它不表示内容真实、正确、适用、安全于其它消费者、具有证明力、已经审批或能够执行。

## 首批预览类别

| preview kind | manifest `media_type` | 必须同时成立的内容识别 | Web 呈现 |
|---|---|---|---|
| `markdown` | `text/markdown` | 完整 bytes 可按 UTF-8 严格解码；不得含 NUL；不把 HTML 当作可执行内容 | 以 Markdown 结构渲染；禁用原始 HTML；远程图片和其它远程嵌入资源不自动加载 |
| `svg` | `image/svg+xml` | 完整 bytes 可按 UTF-8 严格解码；根元素为 SVG；通过下文主动内容拒绝清单 | 作为图片资源按容器等比缩放，不把 SVG 注入页面 DOM，不作为可导航文档或脚本上下文打开 |
| `image` | `image/png` | PNG 固定签名字节匹配 | 作为图片资源等比缩放 |
| `image` | `image/jpeg` | JPEG SOI 与有效结束标记匹配 | 作为图片资源等比缩放 |
| `image` | `image/gif` | `GIF87a` 或 `GIF89a` 头匹配 | 作为图片资源等比缩放 |
| `image` | `image/webp` | RIFF/WEBP 容器头匹配 | 作为图片资源等比缩放 |
| `image` | `image/avif` | ISO BMFF `ftyp` 及 AVIF/AVIS 品牌匹配 | 作为图片资源等比缩放 |

manifest media type 与实际识别结果必须同时匹配；不根据 `filename` 后缀修正、猜测或扩大类型。HTML、PDF、XML、YAML、代码、音视频、压缩包、可执行文件、`application/octet-stream` 和其它未列类型保持 `unsupported`，不得自动退化为文本、iframe、浏览器导航或下载。

## 来源、完整性与资源边界

1. 请求必须先解析并验证选定管辖项目；项目 ID 只可命中已验证登记，不能作为文件系统路径。
2. 对象 ID 必须匹配 FileAsset 稳定身份格式；只读取 `ldvh-base/file-assets/<object_id>/file-asset.yaml` 与同目录固定 `payload`，不得接受调用方提供路径或成员名。
3. 对象必须字段级可读且 `status=active`；`deleted`、not found、unreadable、身份不一致或成员闭集不成立时不读取 payload。
4. manifest 和 payload 必须是不经最终 symlink 的普通文件；读取 payload 时使用 no-follow 能力，并在返回前确认读取到的完整 bytes 未超 4 MiB（4194304 bytes）、实际长度等于 `size_bytes`、SHA-256 等于 `content_sha256`，且读取前后的文件身份与长度没有漂移。
5. 任何范围、读取、完整性、稳定性、内容识别或安全检查失败都不得返回部分 payload；对象 API 中已经出现的 manifest 值不能替代当次实际 payload 检查。

## SVG 与 Markdown 主动内容边界

SVG 只接受用于静态图片呈现的保守子集。出现以下任一结构时返回 `unsafe`：DOCTYPE 或实体声明；`script`、`foreignObject`、`iframe`、`object`、`embed`、`audio`、`video`、`image`、`use`、`style`；任何 `on*` 事件属性；`href` / `xlink:href`；CSS `url()`、`@import`；`javascript:`、`data:text/html` 或其它外部/可执行资源引用。通过检查的 SVG 仍只作为图片加载，并带有禁止脚本、导航、外部连接和内容嗅探的响应头。

Markdown 使用结构化 Markdown renderer，不启用原始 HTML。链接可以作为明确导航呈现，但预览不得自动打开；图片只允许同一 Markdown 文本中的安全 `data:image/*` 内联资源，HTTP(S)、协议相对地址、项目路径和其它外部资源不自动请求。Web 不执行 Markdown 中的 HTML、脚本、iframe、对象或事件属性。

## 预览结果与失败状态

成功响应只返回当次 payload bytes，并以已经确认的 media type、inline 文件名、安全缓存策略和内容安全响应头呈现；不返回绝对路径、读取句柄、manifest 全量副本或新的对象字段。客户端只在次级阅读面板显示，不自动保存到磁盘或新开页面。

失败使用以下稳定分类；Human 文案可以本地化，但不得把类别折叠成空白预览：

| status | 含义 |
|---|---|
| `not_found` | 当前项目中没有该 canonical FileAsset |
| `unavailable` | 对象 deleted、载体不可读、范围或稳定读取能力不可用 |
| `integrity_failed` | 实际 size/hash 或读取期身份不匹配 |
| `unsupported` | media type 不在首批闭集，或声明类型与确定性内容识别不匹配 |
| `unsafe` | SVG 或其它主动内容命中拒绝规则 |
| `too_large` | payload 超过 4 MiB 上限 |

失败响应不得包含 payload 片段。面向 Human 的提示只说明预览为什么不可用，不把失败扩大为 FileAsset 内容错误或事实对象整体无效。

## 次级阅读呈现

FileAsset 详情以“预览文件”或等价明确入口打开次级阅读：宽屏使用右侧阅读面板，窄屏沿用现有底部伸展阅读。Markdown 保持标题、列表、表格、代码和链接结构；SVG 与 raster 图片在可用宽高内居中、等比缩放并保留替代文字。切换对象、关闭面板或卸载预览时必须释放浏览器对象 URL，不保留上一个项目的 payload。

## 契约验证

Web tests 至少覆盖：有效 Markdown；Markdown 原始 HTML 不执行且远程图片不自动加载；有效 PNG/JPEG/GIF/WebP/AVIF；有效静态 SVG；SVG script、事件属性、外部 href、foreignObject、style/url 拒绝；media type 与 magic bytes 不匹配；deleted；not found；payload symlink；manifest/payload size 或 SHA-256 不匹配；读取期漂移；4 MiB 边界内成功和超限拒绝；失败不返回 payload；响应不暴露绝对路径；宽屏右侧与窄屏底部次级阅读入口保持同一内容身份。
