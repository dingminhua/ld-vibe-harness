# LDVH V4

本仓库正在从唯一已接受的根规范重新建立 LDVH V4。V4 不以兼容迁移 V3 为目标；除 `specs/00-理念与构成.md` 外，既有规则、实现和测试均未自动获得 V4 身份。

## 当前入口

- [`00-理念与构成.md`](specs/00-理念与构成.md) 是当前唯一已接受的 V4 正式规范。
- [`V4-架构重建基线.md`](docs/v4-architecture/V4-架构重建基线.md) 记录本轮重建范围、非继承边界和资产处置原则。
- [`V3 全景理解与 V4 重建问题基线`](docs/v4-architecture/V3-全景理解与V4重建问题基线.md) 记录当前调查结论和后续处置方法。
- [`archive/v3/`](archive/v3/) 保存 V3 历史资产，不是 V4 规则源、实现或验收契约。

## 资产边界

- `web/` 和 `icons/` 作为既有产品资产冻结保留，不在本轮重构范围内，也不因仓库进入 V4 而自动获得 V4 验证结论。
- V3 的 Code、tests、hooks、事实对象、技能材料和顶层运行配置已经整体移入 `archive/v3/`，只能用于调查和选择性重新设计。
- `archive/v4-seeds/` 保存非规范的定位校准种子；`archive/v4-experiments/` 保存已暂停的 V4 早期设计试验。二者都不具备规则效力。
- `docs/v4-architecture/` 只保存重建期调查和决策记录，不是规则源。

## 使用状态

当前没有已接受的 V4 Helper CLI、Code、tests、事实模型或行动模板。它们只有在依据 V4 规范重新设计、实现、接入并验证后，才能按实际证据声明相应状态。
