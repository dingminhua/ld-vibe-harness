## 1. 定位

本文承载 05 授权的 Confirm UI 字段表。

## 2. 字段表

| 字段 | 要求 |
|---|---|
| Gate 触发原因 | 说明为什么需要 Human 介入 |
| 确认对象 | 指向对象、文件、操作或候选事项 |
| 影响范围 | 说明会影响哪些事实源、流程、页面或结果 |
| 确认依据 | 展示事实源、证据、验证或候选方案 |
| 风险 | 展示可能后果和残留不确定性 |
| 可替代方案 | 必要时展示取消、暂缓、修改或替代路径 |
| 用户选择 | 至少区分确认、取消、暂缓和修改反馈 |
| 确认人和时间 | 使用环境可提供的确认来源或等价记录 |
| 执行动作 | 说明确认后触发什么动作 |
| 验证结果 | 展示已验证、失败、未验证或等价验证 |
| 回写位置 | 说明长期记录进入哪个事实源或字段 |
| 残留风险 | 说明未覆盖范围和后续补齐位置 |

## 3. 边界

Confirm UI 可以展示或收集 Human 选择，但不得把 UI 状态、缓存或数据库记录提升为最终事实源。需要长期追溯时，应通过受控写入链路回写到对应事实源。
