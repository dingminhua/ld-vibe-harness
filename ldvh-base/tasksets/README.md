# TaskSet 实例目录

本目录存放 TaskSet（任务集）事实模型实例。

## 文件命名规则

```text
taskset-{NNNN}-short-title.yaml
```

- 编号从 `0001` 起递增，固定 4 位
- 英文短标题使用小写短横线命名
- 每个项目独立编号

## 准入条件

当一组任务满足以下条件时，应考虑形成 TaskSet：

1. 具有相同目标或主题
2. 需要统一归类和追踪
3. 任务间存在关联关系
