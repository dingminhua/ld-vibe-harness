## 1. 定位

本文承载 05 授权的页面与 API 映射矩阵。

## 2. 映射矩阵

| 页面或区域 | 主要 API/数据来源 | 必须展示 | 不得越界 |
|---|---|---|---|
| Dashboard | 对象摘要、WorkCase 态势、验证摘要 | 当前事实态势、风险、待确认项、来源 | 看板状态替代事实源 |
| ObjectList | 事实对象 DTO | 类型、状态、来源、筛选依据 | 新对象类别 |
| ObjectDetail | 事实源原文、字段 DTO、关联提交 | 字段来源、关系、证据、提交追溯 | 字段写入 |
| ProjectFiles | Git 文件、Code/后端读取 | 文件路径、读取错误、只读边界 | 任意文件编辑 |
| Validate | Code 诊断、测试状态 | 诊断、降级、来源命令、修复线索 | 自动修复、自动关闭 |
| Gate | 候选待确认事项、Human Gate 信息 | 确认对象、影响范围、风险、选项 | 直接完成 Gate |
| Changelog | Git history、07 派生规则 | commit token、body、文件列表、对象关联 | 手写提交事实 |
| KnowledgeMap | 04 知识地图投影 | 节点、边、source refs、diagnostics、degraded | 补写关系 |
