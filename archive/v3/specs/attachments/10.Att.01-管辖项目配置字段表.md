> 文件状态：active；本文只承载 10 授权的管辖项目配置字段、Git 身份字段和 target resolution 输出字段。

根字段:

| 根字段 | 要求 | 说明 |
|---|---|---|
| `product_name` | 必填非空字符串 | 配置所属产品名 |
| `product_description` | 必填非空字符串 | 配置用途说明 |
| `projects` | 必填列表 | 管辖项目条目列表；没有项目时使用空列表 |

项目字段:

| 项目字段 | 要求 | 说明 |
|---|---|---|
| `id` | 必填非空字符串且全配置唯一 | 管辖项目稳定 ID |
| `path` | 必填非空字符串 | 项目根路径；相对路径以配置文件所在目录为基准 |
| `name` | 可选非空字符串 | Human-facing 项目名 |
| `description` | 可选非空字符串 | Human-facing 项目说明 |
| `git` | 可选对象 | Git 身份线索对象 |

Git字段:

| Git字段 | 要求 | 说明 |
|---|---|---|
| `common_dir` | 可选非空字符串 | Git common-dir 身份线索；用于 worktree 匹配 |
| `remote_url` | 可选非空字符串 | Git remote 证据线索；不得单独决定管辖项目命中 |
| `default_branch` | 可选非空字符串 | 默认分支说明 |

resolution字段:

| resolution字段 | 要求 | 说明 |
|---|---|---|
| `target` | 必填字符串 | 输入 target 原文 |
| `normalized_path` | 必填字符串 | Code 归一化后的路径 |
| `source` | 必填字符串 | target、cwd-fallback、cwd-subproject 或环境来源 |
| `status` | 必填枚举 | `governed`、`not_governed` 或 `ambiguous` |
| `scope_status` | 聚合 resolution 顶层必填枚举 | `governed_single`、`non_governed`、`scope_unknown`、`governed_target_unknown`、`declared_multi_governed` 或 `mixed_scope` |
| `governed_project_id` | 条件字符串 | 命中管辖项目时填写项目 ID |
| `governed_project_path` | 条件字符串 | 命中管辖项目时填写项目根路径 |
| `governed_via` | 条件枚举 | `path` 或 `git.common_dir` |
| `git_common_dir` | 可选字符串 | target 或 cwd 的 Git common-dir |
| `unknown_reason` | 条件字符串 | 未命中或不确定时说明原因 |
