## 1. 定位

本文承载 05 授权的提交记录展示矩阵。

## 2. 展示矩阵

| 场景 | 展示要求 | 不得越界 |
|---|---|---|
| Changelog | 使用 Git history 或 Code DTO；`/changelog` 只是路由名 | 创建手写 change 对象 |
| Commit body | 作为提交说明优先展示 | 改写 body 语义 |
| 改动文件 | 默认可收起，保留可展开查看 | 用文件列表替代验证结论 |
| 对象详情关联提交 | 展示由 07 派生的关联提交 | 手写 `related_changes` |
| 复制给 AI | 保留原始 commit token、body、hash、来源 | 只复制页面摘要 |

## 3. 边界

提交展示本体归 05，commit message 契约、type/scope/body 规则和 Git 追溯归 07。Web 展示不得把提交记录描述为工作对象生命周期状态。
