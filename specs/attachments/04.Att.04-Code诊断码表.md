## 1. 定位

本文承载 04 授权的 Code 诊断字段和等级。

## 2. 诊断字段

| 字段 | 含义 |
|---|---|
| `severity` | `error`、`warning` 或 `info` |
| `code` | 稳定诊断码 |
| `message` | 人类可读诊断说明 |
| `source_refs` | 来源路径、章节、对象、字段或 commit 回指 |
| `suggested_owner` | 建议归口；无法判断时可为空，但必须通过降级说明暴露 |

## 3. 使用规则

诊断只暴露缺口、冲突、漂移、降级和建议回写方向，不直接关闭问题，不替代 Human Gate。`--fail-on-diagnostics` 的失败边界由具体命令实现和测试确认。

| 诊断码 | 命令或范围 | 等级 | 含义 |
