> 文件状态：active；本文只承载 01 授权的安装回滚检查项。表中 `evidence` 字段名沿用既有 schema 时，语义按 01 理解为当次可观察依据；除非来源规范另行要求，不表示必须长期留存、写入事实源或标记安装状态。

| 检查项 | 要求 | 证据入口 |
|---|---|---|
| `target_scope` | 明确安装影响的 repo、worktree、管辖项目或外部环境范围 | install/status 命令输出 |
| `entry_kind` | 明确入口是 Git hook shim、LDVH 环境插件 / 扩展包 Hook、package 还是 runtime adapter | 01.Att.03、status 命令 |
| `trigger_point` | 明确自动触发事件和失败处理方式 | Hook 或 adapter 文档 |
| `session_start_evidence` | 目标环境新开、恢复或等价 lifecycle 事件真实自动触发，并产生 read_plan、receipt、event、session_id、cwd 或 target 当次输出 | 目标环境 Hook 输出、运行时 receipt、环境事件日志 |
| `pre_tool_use_negative` | 写入类或等价高影响工具调用前真实自动触发，缺 read_plan、target unknown 或等价负例能阻断 / deny | 目标环境 Hook 输出、deny 记录、diagnostic |
| `pre_tool_use_positive` | 已满足 read_plan / target 条件的正例或只读动作不被误阻断 | 目标环境 Hook 输出、allow 记录、diagnostic |
| `completion_claim_evidence` | Stop、completion 或等价 lifecycle 事件真实自动触发，能输出完成检查、验证缺口或残留风险提示，且不误阻断环境正常停止 | 目标环境 Hook 输出、completion diagnostic |
| `payload_contract` | 明确 payload 字段、缺字段处理和兼容边界 | 01.Att.05、测试 |
| `runtime_cache_disclosure` | 若环境入口需要 session-scoped runtime receipt cache，必须在安装、升级或验证前告知写入目录、TTL、权限、清理方式、可关闭方式和非事实源边界 | 安装方案预览、01.Att.05、运行时输出 |
| `evidence_check` | 可重复检查安装与接入依据、路径、插件或扩展 manifest、信任依据和是否由 V3 管理 | status 命令、插件或扩展清单 |
| `shim_boundary` | 项目、插件、扩展包或环境中的入口只定位并调用 LDVH，不复制 specs、事实源、校验逻辑或 Human Gate 判断 | hook 文件、插件或扩展 Hook 配置、环境入口配置 |
| `rollback` | 可卸载或恢复原状态，且不会覆盖未知用户资产 | uninstall 或回滚步骤 |
| `rollback_evidence` | 卸载后已移除或禁用 LDVH 指向，恢复或保留原有用户 Hook / 环境配置，并清理或说明已过期的 LDVH runtime receipt cache | uninstall/status 输出、cache 清理输出 |
| `no_cross_environment_claim` | 当前环境不能真实触发目标环境 lifecycle Hook 时，不得声明目标环境 integrated | 环境审计输出、目标环境回传的当次依据 |
| `verification` | 安装、失败阻断、成功路径和回滚均有验证命令 | tests 或手动验证记录 |

| runtime cache 授权与清理要求 | 序号 | 内容 |
|---|---|---|
| 安装前提示 | 1 | 安装或启用环境 Hook 前，必须提示用户该入口可能在 OS runtime / temporary / cache 目录写入短期 receipt cache；该 cache 不写 repo、不写 specs、不写 Spark、不写受管项目。 |
| 告知内容 | 2 | 告知必须包含当前平台解析出的目录、默认 TTL、权限边界、可关闭方式和清理方式。 |
| 验证输出 | 3 | 验证输出必须说明本次是否写入 runtime cache、写入路径、是否命中、是否过期或被清理。 |
| 卸载清理 | 4 | 卸载、禁用或回滚环境入口时，应删除 LDVH 创建的未过期 receipt cache；无法删除时必须说明原因，并说明 TTL 到期后不再采信。 |
