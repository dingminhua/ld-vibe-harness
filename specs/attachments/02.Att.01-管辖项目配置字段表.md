## 配置根字段

| 字段 | 要求 | 含义与边界 |
|---|---|---|
| `product_name` | 必填非空字符串 | 当前 LDVH 工作区或管理实例的 Human 可读名称 |
| `product_description` | 必填非空字符串 | 当前工作区用途说明，不产生项目事实或规则效力 |
| `projects` | 必填列表 | 管辖项目条目；没有登记项目时使用空列表 |

根字段使用闭集，不得增加安装状态、验证状态、环境接入状态、Human Gate 状态或项目事实字段。

## 项目字段

| 字段 | 要求 | 含义与边界 |
|---|---|---|
| `id` | 必填非空字符串；全配置唯一 | 管辖项目稳定 ID，不使用当前编号、路径或分支名代替 |
| `path` | 必填非空字符串；规范化后全配置唯一 | 项目根路径；相对路径以配置文件所在工作区根目录为基准；验证和消费时必须能复核为有效 Git worktree |
| `name` | 可选非空字符串 | Human 可读项目名称 |
| `description` | 可选非空字符串 | 项目用途说明，不替代项目事实 |
| `git` | 可选映射 | Git 身份线索；字段缺失时 Code 必须从项目路径复核 Git 身份，不能据此接受非 Git 项目 |

项目字段使用闭集。不得加入 `status`、`initialized`、`integrated`、`verified`、`audit_state`、事实源路径或运行时状态。

## Git 身份字段

| 字段 | 要求 | 含义与边界 |
|---|---|---|
| `common_dir` | 可选非空字符串 | Git common-dir 身份线索，用于识别共享仓库的 worktree；匹配前必须解析为可比较的实际路径 |
| `remote_url` | 可选非空字符串 | Git remote 辅助线索，不能单独决定管辖项目命中 |
| `default_branch` | 可选非空字符串 | 默认分支说明，不决定当前分支、规则效力或完成状态 |

Git 身份字段使用闭集。配置值是待复核线索，不替代当次 Git 可观察依据。

## 逐对象解析字段

| 字段 | 要求 | 含义与边界 |
|---|---|---|
| `locator` | 必填字符串或映射 | 原始工作对象定位符或其可回指表示 |
| `resolved_identity` | 条件非空字符串或映射 | 能够复核时记录工作对象的实际身份或边界 |
| `identity_evidence` | 必填列表；`governed` 或 `not_governed` 时非空 | 支持工作对象身份、边界和项目关系判断的当次可观察依据 |
| `source` | 必填非空字符串 | 定位符来自显式输入、当前操作或 `cwd` 回退 |
| `status` | 必填枚举 | `governed`、`not_governed` 或 `unknown` |
| `governed_project_id` | `governed` 时必填 | 唯一命中的管辖项目 `id` |
| `governed_project_path` | `governed` 时必填 | 从当前配置解析得到的项目绝对路径 |
| `governed_via` | `governed` 时必填枚举 | `path` 或 `git.common_dir` |
| `git_common_dir` | 可选非空字符串 | 当次工作对象实际解析到的 Git common-dir |
| `source_refs` | 必填非空列表 | 配置、定位符和身份依据的来源回指 |
| `unknown_reason` | `unknown` 时必填非空字符串 | 配置、身份、冲突或能力缺口原因 |

## 聚合解析字段

| 字段 | 要求 | 含义与边界 |
|---|---|---|
| `workspace_root` | 条件非空字符串 | 已确认时记录本次选定工作区根的绝对路径 |
| `config_path` | 条件非空字符串 | 已发现时记录实际读取的 `LDVH-GOVERNED-PROJECTS.yaml` 绝对路径 |
| `config_status` | 必填枚举 | `valid`、`missing`、`invalid` 或 `conflict` |
| `scope_status` | 必填枚举 | `governed_single`、`multiple_governed_projects`、`non_governed`、`scope_unknown` 或 `mixed_scope` |
| `object_resolutions` | 必填列表 | 逐对象解析结果，不得只保留聚合布尔值 |
| `source_refs` | 必填列表 | 工作区根、配置和当次输入的来源回指；配置缺失时可以为空，但必须提供诊断 |
| `gaps` | 必填列表 | 未解决配置、对象身份、匹配或能力缺口；没有缺口时为空列表 |

聚合解析结果不得增加与 `scope_status` 重复的顶层 `governed: true/false`，也不得包含行动授权、规则命中、Human Gate 完成、能力可用、环境接入或工作完成字段。
