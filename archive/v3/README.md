# V3 历史资产归档

本目录保留 V3 的规范、Code、tests、hooks、事实对象、技能材料及顶层运行配置，供历史追溯、问题分析和选择性设计参考。

它不属于 V4 当前规则源、实现或验收契约。文件中的 `active` 状态、结构契约、迁移规则、实现行为、测试结果和路径引用均不自动适用于 V4；只有被 V4 重新裁决并在相应正式资产中明确表达的内容，才能获得 V4 身份。

本归档原则上冻结。除修复归档完整性或补充来源说明外，不在此继续演进规则、实现或测试。归档移动保留 Git 可追踪历史，但不承诺旧相对路径、导入、Hook 或运行命令在归档位置仍然可用。

| 路径 | 历史身份 |
