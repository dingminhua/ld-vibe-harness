# Task 实例目录

本目录存放 Task（任务）事实模型实例。

## 文件命名规则

```text
task-{NNNN}-short-title.yaml
```

- 编号从 `0001` 起递增，固定 4 位
- 英文短标题使用小写短横线命名
- 每个项目独立编号

## 准入条件

当一个工作单元满足以下条件之一时，应考虑形成 Task：

1. 有明确目标
2. 有可验证的验收标准
3. 有来源（Intent 或用户直接指示）
4. 可在单次或有限次执行轮次内完成
