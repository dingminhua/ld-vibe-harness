> 文件状态：active；本文只承载 01 授权的安装回滚检查项。

| 检查项 | 要求 | 证据入口 |
|---|---|---|
| `target_scope` | 明确安装影响的 repo、worktree、管辖项目或外部环境范围 | install/status 命令输出 |
| `entry_kind` | 明确入口是 Git hook shim、LDVH Codex plugin 环境 Hook、manual entrypoint、adapter 还是 repo instruction | 01.Att.03、status 命令 |
| `trigger_point` | 明确自动触发事件和失败处理方式 | Hook 或 adapter 文档 |
| `payload_contract` | 明确 payload 字段、缺字段处理和兼容边界 | 01.Att.05、测试 |
| `status_check` | 可重复检查安装状态、路径、插件 manifest、信任状态和是否由 V3 管理 | status 命令、插件清单 |
| `shim_boundary` | 项目、插件或环境中的入口只薄引用 LDVH，不复制 specs、事实源、校验逻辑或 Human Gate 判断 | hook 文件、插件 Hook 配置、环境入口配置 |
| `rollback` | 可卸载或恢复原状态，且不会覆盖未知用户资产 | uninstall 或回滚步骤 |
| `rollback_state` | 卸载后已移除或禁用 LDVH 指向，恢复或保留原有用户 Hook / 环境配置 | uninstall/status 输出 |
| `verification` | 安装、失败阻断、成功路径和回滚均有验证命令 | tests 或手动验证记录 |
