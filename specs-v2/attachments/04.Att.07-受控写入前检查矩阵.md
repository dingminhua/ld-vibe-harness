## 1. 定位

本文承载 04 授权的受控写入 preflight 检查矩阵。

## 2. 检查矩阵

| 检查项 | 标准 |
|---|---|
| 授权位置 | 写入目标是对应规范、事实模型、行动编排、Code、Web、运行时扩展、测试或事实源授权位置 |
| 字段与状态 | 字段、状态、枚举、路径和锚点符合对应规范 |
| Human Gate | 高影响写入、状态流转或权限扩大已识别 Human Gate |
| Git 追溯 | 需要 Git commit records 追溯时已提示 |
| 同步影响 | 跨规范、Web、运行时扩展或测试同步影响已暴露 |
| 失败归口 | 检查失败时能回到规范、对象、行动编排或 Human Gate |

## 3. 使用规则

检查通过不等于授权写入。真正写入必须由对应事实模型、行动编排、Human Gate、07 事实源规则和 Git 追溯共同授权。
