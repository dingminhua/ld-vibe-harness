| 字段 | 要求 | 说明 |
|---|---|---|
| `event` | 必填枚举 | 使用 `01.Att.01` 的消费时机闭集；环境 adapter lifecycle payload 当前只暴露 `session_start`、`pre_tool_use`、`completion_claim`，`acknowledge_read_plan` 由手动 CLI / validator runtime receipt 承接 |
| `trigger_source` | 必填字符串 | `manual`、`git.commit-msg`、外部 adapter 或环境来源 |
| `session_id` | 可选字符串 | 会话或外部调用标识 |
| `target_path` | 条件字符串 | 涉及工作对象、写入、提交或事实源回写时填写 |
| `operation` | 条件枚举 | `read`、`write`、`edit`、`apply_patch`、`commit` 或等价操作 |
| `task` | 条件字符串 | 会话入口或行动指南需要当前任务时填写 |
| `acknowledged_paths` | 条件列表 | 写入前检查需要的已读路径集合 |
| `verification_evidence` | 条件字符串 | 完成声明检查需要的验证证据、未验证范围或残留风险 |
| `source_refs` | 可选列表 | payload 自带来源回指 |
