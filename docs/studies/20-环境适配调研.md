## 2. 快速输入“按你计划执行”的平台适配调研

### 2.1 调研问题

用户希望了解在不同平台上，如果想快速输入固定指令“按你计划执行”，应通过什么机制实现。本轮只研究 Trae Work CN 与 Codex App。

本轮结论是不建设 LDVH 功能，不写入正式环境入口规范，仅作为参考调研保留。

### 2.2 结论摘要

| 平台 | 推荐判断 | 证据状态 | 说明 |
|---|---|---|---|
| Trae Work CN | 可使用自定义 Commands 作为快捷触发 | 官方文档确认 | Trae Commands 用于快速执行重复性任务，可封装常用 Prompt |
| Codex App | 未确认存在等价的用户自定义 Commands | 官方证据不足 | 搜索到的 slash commands 多为内置会话管理指令，不应写成可自定义固定 Prompt 命令 |
| macOS 系统层 | 可使用自定义短语 / 文本替换 | Apple 官方文档确认 | 可把短码替换为完整短语，但需在具体 App 输入框实测 |
| Windows 系统层 | 不声明原生等价能力 | 官方证据不足 | 可考虑输入法短语、AutoHotkey 或第三方文本扩展工具，但不是本轮 LDVH 功能 |

### 2.3 Trae Work CN

Trae 官方 Commands 文档将命令定义为一种快捷方式，用于在对话中快速执行重复性任务。自定义命令可以封装常用指令或操作，用于复用常用 Prompt、规范输出格式和自动化常见开发流程。

Trae 自定义命令包含命令名称、描述和说明。使用时在对话框输入 `/` 或点击命令图标，从菜单中选择命令后发起对话。

如果未来需要在 Trae Work CN 中快速触发“按你计划执行”，候选做法是创建自定义 Command，例如：

```text
/continue-plan
```

候选说明内容：

```text
按当前已确认计划继续执行。执行前检查是否存在未完成 Human Gate；执行中维护 Todo；完成后运行必要验证并汇总结果。不得扩大范围，不得跳过用户确认。
```

该方案的边界：

1. Command 需要用户显式触发；
2. Command 不是 Hook；
3. Command 不能自动替用户在任意时刻发送固定短语；
4. Command 是否适合进入 LDVH 正式环境入口规范，需要后续结合实际使用频率和治理价值评估。

### 2.4 Codex App

联网搜索未找到 Codex App 官方支持“用户自定义 slash command / 自定义 Commands”的明确证据。搜索结果中出现的 `/plan`、`/diff`、`/review`、`/compact` 等更接近内置会话管理指令，不能据此声明 Codex App 支持用户自定义固定 Prompt 快捷命令。

因此，Codex App 中不应把“快速输入按你计划执行”写成平台内置自定义 Command 能力。

较稳妥的候选做法是：

1. 使用系统层文本替换或输入法短语，把短码展开为“按你计划执行”；
2. 使用 Codex 用户级 instructions、AGENTS 或 rules 将短语别名解释清楚，例如把“继续”“按计划”“执行”限定为“在当前已确认计划和 Human Gate 边界内继续执行”；
3. 不使用 Hook 自动改写用户输入，除非后续有明确官方证据、风险评估和 Human Gate。

该方案的边界：

1. 系统层文本替换不是 Codex App 环境入口能力；
2. 用户级 instructions、AGENTS 或 rules 只能解释短语语义，不能让输入更快；
3. Hook 自动改写用户输入属于高风险候选，不作为默认方案；
4. 本轮不建设 Codex App 快速输入功能。

### 2.5 macOS 系统层

Apple 官方支持文档说明，macOS 可以创建自定义短语，将某些文本自动替换为其他文本或符号。入口为系统设置中的键盘自定义短语。

候选示例：

```text
;ap → 按你计划执行
```

该方案的边界：

1. 自定义短语是操作系统输入辅助能力，不是 Trae Work CN 或 Codex App 的平台能力；
2. Apple 文档说明自定义短语并非在所有 App 中都可用，因此需要在具体输入框实测；
3. 该方案不需要进入 LDVH 正式环境入口规范，除非未来决定治理个人环境特别要求或个人输入习惯。

### 2.6 Windows 系统层

本轮联网搜索未找到 Microsoft 官方明确说明 Windows 系统原生提供与 macOS 自定义短语等价的通用文本替换能力。

Windows 侧只保留候选方向：

1. 输入法短语；
2. AutoHotkey；
3. 第三方文本扩展工具；
4. 其他 Microsoft 官方工具若后续确认支持，再补充证据。

该方案的边界：

1. 不声明 Windows 原生系统文本替换能力；
2. 不把第三方工具写成 LDVH 默认要求；
3. 不为快速输入固定短语新增 LDVH 功能。

### 2.7 暂不纳入正式功能的原因

本轮不做该功能，原因是：

1. “按你计划执行”属于用户输入效率问题，不是 LDVH 当前环境入口适配的核心阻塞；
2. Trae Work CN 已有官方 Commands 机制，但引入 LDVH 自定义 Command 需要进一步评估命名、触发边界和是否会鼓励跳过 Human Gate；
3. Codex App 未确认存在等价自定义命令机制，不能为了统一体验而虚构平台能力；
4. macOS 文本替换属于个人系统设置，不适合上升为 LDVH 通用要求；
5. Windows 侧证据不足。

### 2.8 后续可能去向

如果未来决定继续推进，可考虑以下去向：

| 去向 | 条件 | 说明 |
