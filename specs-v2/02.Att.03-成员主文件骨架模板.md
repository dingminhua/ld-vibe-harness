## 3. 骨架模板辅助核对表

骨架模板辅助核对至少包括：

| 核对项 | 标准 |
|---|---|
| 身份块完整 | 同时包含 `v2_spec` 和 `v2_fact_model_member` |
| 上位依据完整 | `basis` 包含 00、01、02 |
| 必要章节完整 | 保留 01 和 02 要求的事实模型成员必要章节 |
| 不适用有说明 | 不适用章节保留标题并说明理由、替代承载位置或待补齐事项 |
| 不越界 | 模板未定义对象特有状态机、字段契约、事实源边界或 Human Gate 内容 |

本核对表用于发现骨架模板缺失和模板越界；核对结论不能替代 02 主文档规定的高影响确认。
