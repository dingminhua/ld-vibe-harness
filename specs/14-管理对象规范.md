## 五、管理对象分类

### 5.1 分类说明

14 号文档只管理核心管理对象（业务实体），不包括框架基础设施。

### 5.2 核心管理对象（11 个）

| 分类 | 对象 | 一句话定位 |
|---|---|---|
| **核心执行实体** | Task | 最小可执行、可追踪、可验证、可关闭对象 |
| **核心执行实体** | TaskSet | 承载任务集合背景信息的文档对象 |
| **意图和入口** | Intent | 人的目标、范围、成功标准和约束 |
| **意图和入口** | Memo | 尚未任务化但有保留价值的输入、发现和提醒 |
| **决策和风险** | ADR | 已确认、后续应遵守的决策记录 |
| **决策和风险** | Risk | 已识别的不确定因素 |
| **决策和风险** | Dependency | 前置条件或外部约束 |
| **支撑和记录** | Evidence | 执行摘要、验证结果、关闭证据和验收记录 |
| **支撑和记录** | Artifact | 可引用产物 |
| **支撑和记录** | Checklist | 检查事项及检查结果 |
| **支撑和记录** | Change | 对事实源产生影响的实际修改 |
| **支撑和记录** | Pitfall | 已解决且具有复用价值的踩坑经验 |

> 注：Task Set 不是独立对象，通过 Task 的 `parent` 字段实现编组。

### 5.3 初始化检查项

| 检查项 | 标准 |
|---|---|
| 对象定位 | 明确该对象承载业务事实 |
| 准入条件 | 已定义清晰的准入条件 |
| 状态机 | 已定义稳定的状态流转路径 |
| 字段契约 | 已定义业务字段和引用字段 |
| 载体 | 明确存放位置 |
| 对象关系 | 明确与其他对象的转化、依赖、引用关系 |
| Human Gate | 已定义触发点 |
| 验收标准 | 已定义完成标准和验收要求 |

### 5.4 审计检查项

| 检查项 | 标准 |
|---|---|
| 状态流转合规 | 状态流转符合规则 |
| Human Gate 执行 | 关键操作已触发 Human Gate |
| 引用完整性 | 引用的其他对象存在且有效 |
| 证据完整性 | 关闭证据完整 |
| 单一事实源 | 未在多个位置重复维护 |
| 变更记录 | 变更已记录 |
| 验收完成 | 符合验收标准 |

### 5.5 对象关系

| 关系类型 | 说明 |
|---|---|
| Task → TaskSet | Task 引用 TaskSet（requirement_doc） |
| Task → ADR | Task 引用 ADR 作为决策依据 |
| Task → Risk | Task 关联风险 |
| Task → Dependency | Task 关联依赖 |
| Task → Evidence | Task 产生验收证据 |
| Task → Artifact | Task 产生产物 |
| Task → Checklist | Task 包含检查清单 |
| ADR → Rules | 决策可升级为规则 |
| Memo → Task | Memo 可转化为 Task |
| Intent → TaskSet | Intent 可转化为 TaskSet |
