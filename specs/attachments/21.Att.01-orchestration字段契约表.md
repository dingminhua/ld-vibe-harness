Boundary:

| item | boundary |
|---|---|
| `orchestration.execution_items` | WorkCase 内部执行项，不得成为独立事实对象、独立编号段或一级 Web 入口 |
| `orchestration.plan_review` | 归口执行前方案复核和 Human 执行确认，不写入执行结果关闭结论 |
| `orchestration.result_review` | 归口执行后自检、结果复核和 Human 关闭确认，不替代 `verification_evidence`、`closure_evidence` 或 Git commit records |
| Web | 可以展示本附件登记字段和可追溯派生状态，但不得把 Web 表单字段反向写成新的 WorkCase schema |
| Code | 可以使用本文进行字段存在性、未知字段、关键嵌套结构和状态条件诊断；是否自动阻断历史实例迁移由对应行动模板或 Human Gate 决定 |
