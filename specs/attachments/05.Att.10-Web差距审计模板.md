## 1. 定位

本文承载 05 授权的 Web 只读差距审计模板。

## 2. 审计模板

Web AI 或并行 AI 承接 Web 工作前，应按页面或 API 列出：

| 字段 | 要求 |
|---|---|
| 页面/API | 当前被审计的入口 |
| 事实源来源 | Git 文件事实源、Code 输出、Human 输入或实现文档 |
| 派生状态 | fresh、stale、degraded、error 或 conflict |
| Human Gate | 是否涉及确认、授权、验收或高影响判断 |
| 写入白名单 | 是否在 05.Att.03 内 |
| 测试归属 | `tests/web/`、等价验证或人工降级检查 |
| 错误态 | 当前错误、空态、降级或冲突处理 |
| Human 决策项 | 需要 Human 选择或确认的事项 |
| 不得直接实现项 | 需要先改 specs、事实模型或 Human Gate 的事项 |

## 3. 边界

差距审计是只读输入，不是执行授权。审计发现需要扩大白名单、改变事实源、改变 Human Gate 或声明完整支持时，必须暂停并等待 Human 确认。
