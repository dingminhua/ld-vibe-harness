# ObjectList 对象列表

> 路由：`/objects/:type`
> 源码：`web/src/pages/ObjectList.tsx`
> API：`GET /api/objects/:type?status=xxx`

## 1. 页面目标

让用户浏览和筛选某一类型的所有事实对象，快速定位目标对象。

## 2. 布局结构

```
┌─────────────────────────────────────────┐
│ 类型标签页                               │
│ [意图] [任务] [ADR] [BUG] [备忘] [画像] │
├─────────────────────────────────────────┤
│ 状态筛选（如状态 > 1 种才显示）          │
│ [全部] [活跃] [已关闭] [计划中] ...     │
├─────────────────────────────────────────┤
│ 对象卡片网格                             │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│ │ ID       │ │ ID       │ │ ID       │ │
│ │ 状态徽章 │ │ 状态徽章 │ │ 状态徽章 │ │
│ │ 标题     │ │ 标题     │ │ 标题     │ │
│ │ 更新时间 │ │ 更新时间 │ │ 更新时间 │ │
│ └──────────┘ └──────────┘ └──────────┘ │
│ grid: sm:2 lg:3                         │
└─────────────────────────────────────────┘
```

## 3. 区域详细设计

### 3.1 类型标签页

- 固定 6 种类型：intent / task / adr / pitfall / memo / profile
- 标签文案：中英双语（意图/Intents, 任务/Tasks, ...）
- 当前选中：`bg-ldvh-accent/15 text-ldvh-accent`
- 未选中：`text-ldvh-text-secondary`，hover 时 `bg-ldvh-border/50`
- 点击：切换类型，重置状态筛选

### 3.2 状态筛选

- 条件：仅当该类型下有 2 种以上状态时显示
- "全部"按钮 + 各状态 pill
- 当前选中：`bg-ldvh-accent/15 text-ldvh-accent`
- 状态文案：通过 `getStatus()` 中英切换
- 点击：按状态筛选列表

### 3.3 对象卡片

- 网格布局：`grid gap-3 sm:grid-cols-2 lg:grid-cols-3`
- 每张卡片：
  - 左上：ID（等宽小字）
  - 右上：状态徽章
  - 中间：标题（中英切换，hover 变 accent 色）
  - 底部：更新时间（等宽小字）
- 点击整张卡片跳转到详情页
- hover：边框变为 `border-ldvh-accent/40`

### 3.4 空态

- 无对象：`未找到 {type} 对象 / No {type} found`
- 加载中：旋转动画
- 加载失败：错误信息

## 4. 交互

| 操作 | 行为 |
|---|---|
| 点击类型标签 | 切换类型，重置状态筛选，刷新列表 |
| 点击状态 pill | 按状态筛选列表 |
| 点击对象卡片 | 跳转到 `/objects/{type}/{id}` |
| 语言切换 | 标签页文案、状态文案、标题跟随切换 |

## 5. API 数据结构

```typescript
interface ObjectItem {
  id: string;
  type: string;
  title: string;
  title_en?: string;
  title_zh?: string;
  status: string;
  created: string;
  updated: string;
}
```

## 6. 已知问题与改进方向

- [ ] 卡片缺少类型颜色标识（只有状态徽章，没有类型色条）
- [ ] 没有搜索功能，对象多时难以定位
- [ ] 没有排序选项（按时间/状态/ID）
- [ ] 更新时间显示为原始字符串，未使用相对时间
- [ ] 缺少分页或虚拟滚动，对象多时性能可能下降
