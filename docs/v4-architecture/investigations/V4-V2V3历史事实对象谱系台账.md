## 4. 后续评估单位与边界

167 条来源输入仍须全部取得可回读处置结论，但语义评估可收敛为 92 个 V3 历史单元：

1. 对 75 个有前身的 V3 单元，先读 V3，再比较其唯一 V2 前身的差异；同一结论必须分别回指 V2 与 V3 两个来源输入；

3. 对每个单元形成“建立当前 V4 事实、已由 V4 承接、仅保留 archive、已经过时”之一的建议；
4. 只有 Human 确认仍具当前价值且需要继续推进的最小内容，才进入 V4 Spark 或 WorkCase 的创建判断。

该收敛不以“V3 已有后继”替代 V2 的评估，也不把 V3 的历史状态或正文自动带入 V4。
