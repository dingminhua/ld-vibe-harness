## 1. 定位

本文承载 01 授权的 v2 术语条目、推荐表达、术语边界和术语辅助核对表。

01 正文定义术语归口、术语应用关系和变更治理；本文只能维护这些已授权的术语条目、术语状态和诊断辅助信息，不得单独改变术语治理原则、术语归口、术语应用关系规则或跨规范权威边界。

术语条目只定义名称、推荐表达、边界和误用边界，不定义事实模型字段契约、状态机、流程 Gate、事实源回写规则、Code 输出 Schema、Web 页面契约或运行时扩展适配细则。

## 2. 术语条目结构

术语表使用以下结构：

| 字段 | 含义 |
|---|---|
| `术语` | 推荐中文表达 |
| `类别` | 术语所属范围 |
| `含义` | 术语本体定义 |
| `边界` | 不应混同或不得用于指代的内容 |
| `迁移来源` | 对应 v1 术语来源或本轮新增来源 |
| `状态` | `draft`、`confirmed`、`needs_review` 或 `removed` |

术语状态闭集如下：

| 状态 | 含义 |
|---|---|
| `draft` | 已列入 v2 术语表草稿，但尚未完成单篇核对 |
| `confirmed` | 已经 Human 在 v2 写作语境下确认；是否 active 仍随父规范生效状态判断 |
| `needs_review` | 边界、推荐表达、迁移来源或影响范围需要继续核对 |
| `removed` | 不再作为推荐术语维护；必须说明替代表达或移除理由 |

本文中的术语状态和表格字段只约束本附件内部术语维护，不得扩展为其它规范的字段契约、对象状态机、行动流程状态或 Code 输出 Schema。

## 4. 术语变更影响辅助核对

新增、改名、废止或改变术语边界时，应辅助核对：

1. 是否影响 00 的存在理由、AI 第一服务对象、六类构成要素、事实源底层原则或 V1-V10；
2. 是否影响 01 的规范身份、附件授权、知识地图关系、引用纪律或消费关系；
3. 是否影响事实模型、行动编排、Code、Web、运行时扩展、事实源、Git 追溯或测试验证规则；
4. 是否需要同步 `attachments/01.Att.08-规范表达清单.md`、Code 常量、知识地图节点类型或 Web 展示文案；
5. 是否触及 01 主文档定义的暂停确认边界。

## 5. 术语辅助核对表

术语辅助核对至少包括：

| 检查项 | 标准 |
|---|---|
| 术语归口 | 术语定义进入 01 和本文；其他规范只说明应用关系 |
| 状态闭集 | 术语状态属于本文定义范围 |
| 术语边界 | 术语条目说明推荐表达、含义和不得混同对象 |
| 表达联动 | 术语变更已检查是否需要同步 `attachments/01.Att.08-规范表达清单.md` |
| 上位一致 | 未反向改写 00 的最高价值锚点 |

本核对表用于发现术语漂移、术语边界缺口和上位概念冲突；核对结论不能替代 01 主文档规定的高影响确认。
