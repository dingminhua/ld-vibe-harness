## 1. 定位

本文承载 05 授权的受控轻写入白名单。

## 2. 白名单表

| 能力 | API | 写入目标 | 允许字段 | 固定写入 | 必须验证 |
|---|---|---|---|---|---|
| Spark 快速创建 | `POST /api/sparks` | Spark 事实实例 | `title`、`description`、`priority` | `status: pending`、`source: web` | 写后读取、字段存在、无 `status_history` |

## 3. 禁止接口

Web 不得提供：

1. 通用 `PATCH`、`PUT`、`DELETE`；
2. 任意 YAML 编辑器；
3. 白名单外对象字段写入；
4. WorkCase、ADR、Pitfall、Study 状态或关系写入；
5. specs、Rules、Skills、Agents、Hooks、Code 或 Web 文件写入。

## 4. 错误分类

Spark 快速创建 API 必须区分成功、字段错误、路径冲突、写入失败和写后验证失败，不得用缓存或临时页面状态伪装创建成功。

## 5. 待补齐事项
