## 关系类型

| 类型 | 含义 | 典型来源 |
|---|---|---|
| `inherits` | 子规范继承父层规则 | `parent_spec`、上位依据 |
| `refines` | 下位规范细化上位规则 | `relation`、正文说明 |
| `authorizes_attachment` | 父规范授权附件 | `related_specs`、附件 identity |
| `consumes` | Code、Action Guide 或下游规范消费来源 | `code_consumption`、相关规范 |
| `produces` | Code 生成派生输出 | Code 规范、schema |
| `validates` | 测试或检查验证某契约 | 测试入口、schema |
| `blocks` | 某条件触发暂停或 Human Gate | Human Gate、stop 条件 |
| `supersedes` | 替代旧规则或旧附件 | deprecated 关系 |

## 使用规则

1. 每条关系必须有 source ref；
2. 关系用于导航和影响判断，不自动授权行动；
3. `blocks` 只能表达候选停止条件，不代表 Runtime 已阻断；
4. 跨项目关系必须携带项目命名空间，不能用裸对象 ID 合并。

## 不进入关系图的内容

1. 对话中的临时推理；
2. 未写入事实源的工具输出；
3. 无身份块、无来源或状态不可判断的文件；
4. 仅为表达建议且不影响行动的散文。
