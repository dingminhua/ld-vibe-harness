---

## 一、本文定位

本文定义多角色思考行动模型的功能初始化检查与动作。功能初始化用于判断多角色思考行动是否具备可执行基础，包括主规范、执行文件、规则入口、Skill 计划、Agent 前提、Tools 辅助计划、展示计划和 Change 记录。

本文不自动创建 Rules、Skill、Agent、Tools 辅助或 Web 功能。涉及规则、Skill、Agent 或工具实现变更时，必须按对应规范评估 Human Gate。

---

## 二、初始化目标

多角色思考功能初始化的目标是确认：

1. 41 主行动模型存在且被 40 索引引用；
2. 41.01-41.07 执行文件存在或有明确规划；
3. 主上下文轻量模式可执行；
4. Skill 辅助模式有设计边界；
5. Agent 增强模式有前提检查和降级规则；
6. Tools 辅助和展示层有边界规划；
7. 输出回写和 Change 记录要求明确；
8. Human Gate 触发点明确。

---

| 检查项 | 标准 | 结果处理 |

| Agent 执行文件 | `41.03-Agent.md` 存在或 planned | 缺失则补齐规划或创建 |
| Tools 执行文件 | `41.04-Tools.md` 存在或 planned | 缺失则补齐规划或创建 |
| 展示执行文件 | `41.05-Web.md` 存在或 planned | 缺失则补齐规划或创建 |

| Change | 初始化变更已记录 | 缺失则创建 Change YAML |

---

## 四、允许自动完成的动作

在用户已确认创建执行文件的前提下，可以自动完成：

1. 创建 41.01-41.07 执行文件；
2. 更新执行文件中的 planned 状态说明；
3. 创建 Change YAML；
4. 执行 Markdown 基础结构检查；
5. 执行 YAML 解析检查；
6. 执行关键内容一致性检查。

---

## 五、必须 Human Gate 的动作

以下动作必须暂停确认：

1. 创建、修改、删除或重命名实际 Skill 实体；
2. 创建、导入、启用、修改或删除 Agent；
3. 修改 L0、L1 或 L2 规则文件；
4. 新增Tools 实现或 Web 实现；
5. 改变事实源权威位置；
6. 将多角色思考输出升级为 ADR、规则、规范或长期行动边界。

- Web 展示：仅规划 / 已实现

## 七、检查要求

| 检查项 | 标准 |
|---|---|
| 完整性 | 41 主文件和执行文件规划完整 |
| 可执行性 | 主上下文轻量模式可执行 |
| 降级 | Agent 前提不满足时有降级路径 |
| 边界 | 未自动创建 Skill、Agent、Tools 辅助或 Web 实现 |
| Gate | 高影响动作已识别 Human Gate |
| Change | 初始化相关文件变更已记录 |
| 验证 | Markdown/YAML/关键内容检查已执行 |
