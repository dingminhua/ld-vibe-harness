# V4 Web 浏览器表现基线

> 记录性质：当前 Web 行为保持型重构的实现依据，不是规则源或产品契约。
> 观察日期：2026-07-13

## 1. 观察范围

当次使用本地 Vite `127.0.0.1:5173` 与 Express `127.0.0.1:3001`，通过 Codex 应用内浏览器实际读取 DOM、可视区域和路由结果。代表性视口为：

- 桌面：1280 × 720；
- 窄屏：390 × 844。

本记录只覆盖下列实际观察，不将浏览器工具、视口数值或单张截图提升为产品契约。当次没有修改 `web/src/`、`web/api/`、样式、路由或视觉资产。

## 2. 已观察的桌面表现

### 2.1 Dashboard

- 页面 title 为 `LDVH Dashboard`，主内容 H1 为“仪表盘”或 `Dashboard`；
- 左侧固定导航包含 Dashboard、Files、Sparks、Work Cases、ADRs、Pitfalls、Studies 和 Commit Records；
- 页面主体使用深色背景，展示五张对象数量卡、待推进区、最近提交和最近活动；
- 当次数据中五类对象均为 0，待推进显示“所有事项已完成”，最近活动为空；
- 不在已知路由表中的 URL 会重定向 `/`。

### 2.2 Project Files

- H1 为“项目文件”或 `Project Files`，页面显式标记“只读”；
- 项目选择器当次默认指向 `LD Vibe Harness v3`，这是现有 Web 配置的观察结果，不证明 V4 管辖配置已接入；
- 页面先呈现加载状态，随后显示文件、待提交与提交历史数量，当次为 11 / 0 / 80；
- 文件视图可显示目录、文本、Markdown、隐藏文件选项、路径复制和文件预览空态；
- 语言切换后，导航、标题、说明、标签、视图和文件类型从中文切换为英文。

### 2.3 Object List 与错误态

- Spark 列表在当次数据下显示 Pending、Routed、Discarded、All 四个筛选和 `No spark found` 空态；
- 页面仍显示 `Create Spark` 入口，打开后可观察到 Title、Description、Priority 和创建按钮。当次没有提交表单；该入口只是 V3 产品实现存在的基线，不使其获得 V4 写入权威；
- 打开不存在的对象详情时，主内容显示 `Failed to load` 和 `API error: 404 Not Found`。

### 2.4 Changelog

- 页面提供最新 50 / 100 / 200、提交类型和 scope 筛选；
- 每个提交卡显示类型、scope、描述、时间、复制上下文与详情入口；
- 当次 DOM 中未观察到明确页面 H1，作为后续可访问性核对项保留，本轮不修改。

## 3. 窄屏观察

- Dashboard 改为单列卡片，对象数量、待推进和最近提交纵向排列；
- 窄屏 DOM 和可视区域中都没有桌面侧栏、导航、语言切换、主题切换或等价移动导航入口；这是现有产品表现和已知缺口，不在当次基线工作中修复；
- Spark 列表窄屏下保留四个状态筛选、创建入口和空态，未观察到页面 H1。

- 未观察浅色主题、真实写入、表单校验、复制板内容、全部对象详情与所有项目选择结果；
- 只检查了代表性桌面和窄屏，不声明全部浏览器、系统字体、缩放比例或中间断点表现一致；
- 当次控制台未观察到 error 或 warning，但这不替代 lint、网络失败、真实部署或长时运行检查。
