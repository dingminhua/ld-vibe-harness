## 5. 必须保留的下游审核清单

以下内容有明确归口，但尚未完成 V4 设计内容覆盖。任何一项都不得因十项通用或基础责任存在而标记为已覆盖、available、integrated 或 completed。

### 5.1 具体事实类型

| 候选类型 | 必须审核 |
|---|---|
| Spark | 是否比普通 backlog/docs 更有跨会话净价值；准入、分流和退出 |
| WorkCase | 目标、范围、成功标准、稳定状态、验证与关闭；排除过程编排 |
| ADR | 决策、理由、替代方案和吸收位置；不得取得规则补丁效力 |
| Pitfall | 已观察条件、证据、适用边界和复发价值 |
| Study | 来源、观察时间、结论状态和是否值得对象化 |

每种类型必须先按未来事实模型定义的类型准入、对象化净价值和共同边界判断，再比较普通资料、现有规范章节、具体事实类型来源和授权附件。只有需要新建普通规范或实质改变已有规范责任时，才执行 01 §13。授权附件只能承载父规范正文已定义并授权的字段、枚举或关系矩阵，不能独自定义事实类型核心语义。结果可以是不建立、合并到普通资料、使用现有来源、建立新的具体来源或由正文授权附件表达既有结构；不能预设恰好恢复五份 V3 规范。

### 5.2 具体行动模板与项目强制规则

至少重新审核：安装配置与验证、Git 提交、环境插件编写与更新、并行委派、独立复核、记录对象分流与召回。行动模板基础规范只定义共同结构，不授予具体步骤、格式、Human Gate、Hook 阻断或提交规则。

Git commit message、push、远端 ref 写入和项目特定强制要求必须进入符合 01 的正式规则来源；可复用操作过程归行动模板；当前可变偏好只有通过事实模型准入后才成为偏好事实；具体校验归 Code/tests。不得用未定义的“项目策略”建立非正式规则源，Code、validator 和 tests 也不得自行恢复 V3 行为。

### 5.3 具体环境 adapter

Codex、WorkBuddy 和未来环境的受支持事件、必需输入、安装接口、真实触发和回滚证据必须逐环境核验。形成稳定外部契约时，另行判断正式来源或授权附件；纯实现字段、路径和 shim 留在 Code/tests 与实现说明。

### 5.4 AI 角色、Skill 与委派

专项 §13 复核确认不建立独立“AI 角色规范”或“能力资产总规范”：

1. 模板如何声明执行资源、所需能力、输入、工具、写入范围、输出、证据、再委派、主控回收和交还，由行动模板共同规则承接；
2. 何时选择 worktree、线程或子 Agent，以及如何并行、等待、验证、提交、合并和处理冲突，由具体委派型行动模板承接；
3. 当次平台能力和缺口由 Helper 发现并报告；
4. Skill/Agent 中的平台无关行动步骤、进入条件、失败处理和交还归具体行动模板；平台 metadata、触发、安装、sandbox、approval、权限映射、配置文件和事件归环境接入及实现；
5. 当次写入或再委派授权来自 Human 当前指令及适用来源规则；
6. 长期协作偏好只有通过事实模型准入后，才可成为可启停事实；
7. 子 Agent 中间过程、轮询状态和 receipt 属于当次信息。

移除上述承接后没有剩余独有规则，不满足 01 §13.2(2)–(7)，因此不新增第十一项通用责任。未来若出现无法由行动模板自然承接、能够独立适用和独立失败的稳定对象，再重新执行 §13。

### 5.5 Helper、Web 与测试的内部漏项检查

1. Helper 草案必须覆盖任务脉络、关系投影、渐进读取、来源回指、能力缺口和部分结果，不能把 V3 Action Guide 缩成只有 CLI envelope；
2. Web 草案必须覆盖观察时间、来源版本、派生视图是否过期以及与当前来源的差异、受控操作回读和未完成范围；`Cache-Control: no-store` 不能替代这些语义；
3. V3 `sparks.ts` 由 Web 自行定义 ID、字段、初始状态和 `source` 并直接写文件；V4 必须改为由具体事实来源定义契约、由实际 Code 能力执行，Web 只请求受控操作并呈现回读、失败和未完成范围；
4. Web 不得继续由其它 API 或前端定义 Spark、WorkCase、事实类型、状态闭集和管辖解析；
5. Web 设计系统当前缺少组件、页面、视觉、键盘、屏幕阅读器和响应式测试，且移动端导航文档存在冲突；必须先确定唯一实现设计入口、消解冲突，再按实际证据保留实践成果；
6. 认证与远程多用户安全在 V3 没有形成已证明的独立责任；未来真实部署范围扩大时再按 §13 审核；
7. 测试工程归 Code，但每项规则的成立条件、证据和可证明范围仍必须由对应来源规范定义。
