# 规范关系类型表

```yaml
ldvh_attachment:
  attachment_key: "spec-relation-types"
  attachment_id: "04.Att.03"
  title: "规范关系类型表"
  status: "active"
  canonical_path: "specs/attachments/04.Att.03-规范关系类型表.md"
  parent_spec: "specs/04-规范体系基础规范.md"
  relation: "authorized_by"
  supersedes: []
```

> 文件状态：active；本文只承载规范体系中由当前载体主动声明的关系类型和承载位置。

| 关系 | 方向 | 承载位置 | 含义 | 不用于 |
|---|---|---|---|---|
| 上位语义依赖 | 下位 Spec → 上位 Spec | `basis` | 理解、判定或维护本规范所必需的直接上位语义依据 | 编号相邻、下游消费、Code 实现、测试覆盖 |
| 结构归属 | 子 Spec → 父 Spec | `parent_spec` + `relation` | 子 Spec 与唯一直接父 Spec 的细化、成员或实例关系 | 代替 `basis`、构造虚假层级 |
| 附件授权 | 附件 → 父 Spec | `parent_spec` + `relation=authorized_by`，父侧使用 `authorized_attachments` | 附件由唯一父 Spec 授权承载特定结构化内容 | 承载核心原则、Human Gate、Stop Conditions 或行动流程 |
| 普通引用 | 当前载体 → 被引用对象 | 正文显式路径或来源回指 | 只表示引用所在语句明示的上下文关系 | 暗示权威、依赖、授权或替代 |
| 替代关系 | 新载体 → 同类型旧职责 | `supersedes` 中的旧 `spec_key` 或 `attachment_key` | 说明实质拆分、合并或替代后的职责去向 | 表示同一职责的改名、改号或移动，代替迁移证据 |

| `relation` 值 | 适用对象 | 含义 |
|---|---|---|
| `refines` | 细化直接父 Spec 的标准规范 | 在父 Spec 授权的职责下细化可独立变化的规则 |
| `member_of` | 规范族成员 | 是父 Spec 治理的具体成员规范 |
| `instance_of` | 行动模板 | 是行动模板基础规范治理的具体模板 |
| `authorized_by` | 附件 | 由 `parent_spec` 指向的父 Spec 授权承载附属结构化内容 |

| 反向或派生关系 | 处理方式 |
|---|---|
| 哪些 Spec 依赖当前 Spec | 由 Code 反向派生 `basis` 入边 |
| 哪些 Code、Web、tests 或环境入口消费当前 Spec | 由实现引用、源码索引或验证输出派生 |
| 哪些资产受当前变更影响 | 由正向关系、实际引用和当次变更范围派生 |
| 哪些测试验证当前 Spec | 由测试与规则的源回指派生，不写成上位语义依赖 |
