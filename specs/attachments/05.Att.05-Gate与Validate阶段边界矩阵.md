## 1. 定位

本文承载 05 授权的 Gate 与 Validate 阶段边界。

## 2. 阶段边界

| 阶段 | 可以展示 | 不得执行 |
|---|---|---|
| Gate | 待确认项、确认对象、影响范围、风险、选项 | 直接完成行动 Gate、自动授权、自动回写 |
| Validate | 验证结果、错误态、降级说明、来源命令、修复线索 | 自动修复、自动关闭任务、自动写入验证结论 |
| Gate 升级写入 | Human 选择、回写目标、风险说明 | 未补齐白名单、对象规范和证据落点前写入事实源 |
| Validate 升级写入 | 验证声明候选、失败诊断 | 绕过 08 验证声明或 07 回写边界 |
