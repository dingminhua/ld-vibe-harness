## 3. 使用规则

资产文件自身的自描述是实例事实权威；06 附件或派生索引只能读取、展示或诊断，不得反向维护资产状态。

固定 Rules 资产的 `source_specs` 与 `sync_triggers` 必须能支持 specs 变化后的影响评估。若 Code 尚不能解析这些字段，维护者应人工核对对应 Rules 文件，不得因为工具缺口跳过评估。

Code 尚不能解析自描述字段时，应执行临时核对动作，并把 Code 缺口分流为 WorkCase、Spark 或 Code 需求。
