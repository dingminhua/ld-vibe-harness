# Profile 实例目录

本目录存放 Profile（项目画像）事实模型实例。

## 文件命名规则

```text
profile-{NNNN}-project-name.yaml
```

- 编号从 `0001` 起递增，固定 4 位
- 英文短标题使用小写短横线命名
- 每个项目独立编号

## 准入条件

当一个项目满足以下条件时，应考虑创建 Profile：

1. 项目已接入 LDVH 规范体系
2. 需要记录项目基本信息和配置路径
3. 需要跨项目治理或产品化
