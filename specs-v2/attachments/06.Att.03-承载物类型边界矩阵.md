## 1. 定位

本文承载 06 授权的 Rules、Skills、Agents、Hooks 类型边界矩阵。

## 2. 类型边界矩阵

| 类型 | 允许承载 | 不得承载 |
|---|---|---|
| Rules | 入口路由、STOP 点、最小读取顺序、事实源边界、恢复后重读要求 | 完整 specs、长期状态、工作对象事实、偶发任务细节、环境命令策略 |
| Skills | 可复用执行流程、标准输入输出、失败处理、验证入口和主控交还 | 新增规范规则、默认调度 Agent、绕过 Human Gate 或 Code 校验 |
| Agents | 隔离上下文分析、专项审查、并行视角、复杂争议和权限边界差异判断 | 输出直接生效、无限分派子 Agent、独立事实源状态、越权写入 |
| Hooks | 生命周期检查入口、提交前后检查提示、工具调用前后检查提示、会话停止检查提示和降级提示 | 替代 Code 校验、替代 Human Gate、替代长期记忆、替代 Git commit records |

## 3. 同名机制分流

Codex `.rules`、sandbox、approval、permission profiles、MCP 授权、插件安装状态、Claude path rules、Git Hook 管理器配置和 CI branch protection 属于环境接入、运行约束、工具能力或部署事实，不自动成为 LDVH 固定运行时扩展承载物。
