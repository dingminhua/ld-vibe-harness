# Memo 实例目录

本目录存放 Memo（备忘）事实模型实例。

## 文件命名规则

```text
memo-{NNNN}-short-title.yaml
```

- 编号从 `0001` 起递增，固定 4 位
- 英文短标题使用小写短横线命名
- 每个项目独立编号

## 准入条件

当一条输入满足以下条件时，应考虑形成 Memo：

1. 有保留价值但尚未任务化
2. 不满足 Task 的准入条件（如缺少明确验收标准）
3. 可能在未来转化为 Task 或 ADR
