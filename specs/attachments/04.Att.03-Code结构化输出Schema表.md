## 1. 定位

本文承载 04 授权的 Code 通用结构化输出字段。

## 2. 通用字段

| 字段 | 含义 |
|---|---|
| `tool` | 工具或命令名称 |
| `schema_version` | 输出 Schema 版本 |
| `generated_at` | 生成时间 |
| `input_scope` | 输入范围 |
| `project_namespace` | 项目命名空间 |
| `degraded` | legacy 兼容标记，不作为 active 正式问题概念 |
| `diagnostics` | 诊断列表 |
| `source_refs` | 来源回指 |
| `data` | 命令主体结果 |

Hook dispatcher 类输出应在适用时包含 `cwd`、`target_paths`、`target_resolutions`、`governed_subject`、`governed_via`、`governed_project_id`、`governed_project_path`、`blocked`、`required_paths` 和 `next_action`。`target_resolutions` 应逐 target 记录 normalized path、Git common-dir、project_id、governance status、source 和 unknown reason，用于审计多目标、worktree 和混合目标写入边界。

## 3. 使用规则

具体命令可以输出字段子集，但必须能说明哪些字段未实现、问题原因、来源回指是否完整。`v2-check` 当前输出 active specs 诊断和只读知识地图预览子集，不得伪装成所有 Code 命令统一 Schema 或完整知识地图运行时已经完成。
