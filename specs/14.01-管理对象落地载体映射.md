## 映射说明

### 事实源载体

事实源载体列标注该对象的权威事实源位置。"—"表示该对象不独立承载，由其他对象字段或动态组织得出。具体目录命名和格式契约由 10 定义，对象实践文档（20-49）声明该对象的扩展字段。

### Rule

Rule 列标注该对象是否需要 Rule 约束。需要 Rule 约束的对象，其 Rule 应约束创建条件、状态流转、关闭规则和 Human Gate 触发点。Rule 的具体内容由 11 定义，对象实践文档声明该对象的 Rule 适配。

### Skill

Skill 列标注该对象是否可以通过 Skill 整理生成。Skill 可以将对话、审计发现或踩坑经验整理为对象，但必须先判断对象类型和准入条件。Skill 的具体设计由 11 定义，对象实践文档声明该对象的 Skill 适配。

### Agent

Agent 列标注该对象是否适合由 Agent 围绕独立分析。Agent 不得成为对象事实源，只能围绕对象进行读取、分析和建议。Agent 的具体设计由 11 定义，对象实践文档声明该对象的 Agent 适配。

### 程序

程序列标注该对象是否需要程序辅助。程序可以解析、校验、聚合和受控写入对象事实源，但不得维护第二事实源。程序的具体能力由 12 定义，对象实践文档声明该对象的程序适配。

### 工具

工具列标注该对象是否需要工具展示。工具可以展示对象状态、关系、缺口和待确认事项，但不得维护第二事实源。工具的具体展示方式由 13 定义，对象实践文档声明该对象的工具适配。
